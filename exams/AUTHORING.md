# 문제은행 작성 규칙 (exams/bank_*.md)

새 장의 문제은행을 쓸 때 이 파일을 그대로 따른다. 사람이 쓰든 에이전트에게 맡기든 같다.

## 0. 쓰기 전 점검 (사전 조건)
1. `tools/_textbook_audit_2026-11-26.json`에서 그 장(`chapter`)의 미처리 지적을 찾는다. 사실 문제(`suspected-fact-error`, `deck-conflict`, `internal-conflict`)는 **1차 출처로 확인해 교과서·덱·Anki를 먼저 고친다**. 고치기 전 사실로 문제를 만들면 틀린 정답이 문제은행에 박힌다(58.195 "긴 쪽" 사례).
2. 확인 못 한 사실(`?`, "(확인 필요)")은 정답 키로 쓰지 않는다. 오답 선지의 소재로만 쓰고, 해설에서 단정하지 않는다.
3. 기준일 2026-09-01 이후 사건은 "기준일 이후·시험 비적용"으로만 다룬다.

## 0.5 파일 단위
- 문제은행 파일은 **덱 단위**다: `bank_<덱 id>.md`(예: `bank_Ch17.md`, 이틀짜리 장은 `bank_Ch23_1.md`·`bank_Ch23_2.md`, Phase 2는 `bank_P2_OTP.md`). `build_data.py`가 덱 id와 대조한다.
- 이틀짜리 장: 교과서는 한 파일(`textbook/Ch23.md`)이고 덱은 `_1`(개념·구조)·`_2`(세부 규정·상황형) 둘이다. `_1` 문제은행은 `cards/Ch23_1.md`의 주제(교과서 "덱 카드와의 연결" 표에서 `_1` 카드가 걸린 절)를, `_2`는 `_2`의 주제를 중심으로 쓴다. 사실 출처는 교과서 전체 + 두 덱.

## 1. 내용
- 사실 출처는 `textbook/<장>.md` + `cards/<장>*.md`(검증 메모 ✔/○)뿐이다. 새 숫자 금지. 계산 문항은 교과서 상수로만 계산한다.
- 덱 카드 20장당 60~68문항. 같은 사실을 여러 각도로 묻는 변형 문항을 허용한다(시나리오·참/거짓 판별·"틀린 것 고르기"·날짜 계산).
- 유형 비율 R ~35% / A ~50% / An ~15%. Domain I~V를 고르게(장 성격상 치우치면 III·IV·V를 시나리오로 보강).

## 2. 형식 (`tools/build_data.py`가 검증)
```
### Qnn [R|A|An][Domain I–V] — 짧은 제목
영문 지문(한 단락)

A. 영문 선지 (한 줄)
B. …
C. …
D. …

**정답:** X

**해설**
- X: 정답 이유(조문·가이드라인 번호)
- Y: 오답 이유
- Z·W: 오답 이유(묶을 수 있음)

---
```
- 지문·선지는 **영어만**(한글 0). 해설은 한국어 평서문, 규제 용어는 영어 원어. 비유·영어 차용어 금지.
- 해설은 선지 글자를 **글머리(`- B:`)로만** 가리킨다. 본문에서 "B는…" 식으로 글자를 쓰지 않는다(정답 재배치 스크립트가 글머리만 바꾼다).

## 3. 찍기 단서 금지 (측정해서 맞춘다)
- 정답 선지를 짧게 쓰고, 오답에 **교과서상 틀린** 그럴듯한 근거를 붙여 길이를 맞춘다. 오답 근거에 사실일 수도 있는 새 주장을 넣지 않는다.
- 절대어(always/never/only/every/automatically)를 오답에만 몰지 않는다.
- 근접 오답을 쓴다: 시작점 차이(filing vs receipt), 숫자 바꿔치기(2 vs 5년, 30 vs 50일), 역할 뒤바꿈(SD vs QAU), 지역 뒤바꿈(US vs EU), 단계 혼동(Step 4 vs 5), 범주 혼동(PAS·CBE-30·AR, IA·IB·II).
