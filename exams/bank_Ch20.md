### Q01 [R][Domain III] — Type A timeframe
Under the PDUFA VII formal meetings guidance (2023), what is FDA's timeframe for a Type A meeting?

A. 30 days
B. 60 days
C. 75 days
D. 50 days

**정답:** A

**해설**
- A: Type A는 **30일**이다. 막힌 개발을 푸는 회의라 가장 짧다.
- B: 60일은 Type B다.
- C: 75일은 Type C와 INTERACT다.
- D: 50일은 Type D다.

### Q02 [R][Domain III] — EOP2 classification
A sponsor requests an end-of-Phase 2 meeting for its lead product. How does the 2023 PDUFA VII guidance classify this meeting and what is the timeframe?

A. Type C, 75 days, as a general development meeting
B. Type B, 60 days, like a pre-IND meeting
C. Type B(EOP), 70 days, since EOP1 and EOP2 meetings form their own category
D. Type A, 30 days, because it gates Phase 3

**정답:** C

**해설**
- C: EOP1(특정 제품)·EOP2는 Type B가 아니라 **Type B(EOP)** 이고 시한은 **70일**이다.
- A: Type C는 다른 유형에 들지 않는 질문용이다.
- B: Type B(60일)는 pre-IND, pre-NDA/BLA 등이고 EOP 회의는 빠진다.
- D: Phase 3로 가는 관문이라는 이유로 Type A가 되지 않는다. Type A는 clinical hold·dispute 같은 막힌 상황이다.

### Q03 [A][Domain III] — clinical hold
FDA has placed an IND on clinical hold. The sponsor has new data it believes addresses the hold issues and wants to discuss a path to lifting the hold as quickly as possible. Which meeting type fits?

A. Type A, 30 days, since lifting a clinical hold is a listed Type A case
B. Type D, because just two narrow questions will be asked
C. Type B, because the meeting concerns the IND stage
D. Type C, because hold discussions fall outside defined milestones

**정답:** A

**해설**
- A: clinical hold 해제 협의는 **Type A**(30일)의 대표 사례다.
- B: Type D는 좁은 쟁점 ≤2개용이고, 막힌 개발을 푸는 사례로는 Type A가 정해져 있다.
- C: Type B는 pre-IND·pre-NDA/BLA 같은 이정표 회의다.
- D: hold는 Type A 사례로 명시되어 있어 Type C로 갈 이유가 없다.

### Q04 [A][Domain III] — pre-IND package timing
A company is requesting a pre-IND meeting for a monoclonal antibody. The regulatory lead asks when the meeting package must reach FDA. What is correct?

A. With the meeting request, as for the other formal meeting types
B. 50 days before the meeting, because the product is a biologic
C. 30 days before the meeting, as the Type B rule requires
D. 5 days before the meeting, together with the preliminary responses

**정답:** C

**해설**
- C: pre-IND는 **Type B**이고 패키지는 **회의 30일 전**이다.
- A: 요청과 함께 내는 것은 A·C·D·INTERACT이고, Type B는 예외다.
- B: 50일 전은 Type B(EOP)다. 제품이 생물의약품인지는 시점을 바꾸지 않는다.
- D: 5일 전은 일부 유형의 preliminary response 시점이고 패키지 기한이 아니다.

### Q05 [A][Domain III] — EOP2 package and preliminary responses
A sponsor schedules an EOP2 meeting to agree on its Phase 3 design. Which combination of package deadline and expected preliminary-response timing is correct?

A. Package 50 days before the meeting; preliminary responses 5 days before
B. Package 50 days before the meeting; preliminary responses 2 days before
C. Package 30 days before the meeting; preliminary responses 2 days before
D. Package with the request; preliminary responses 5 days before

**정답:** A

**해설**

- B: preliminary response 2일 전은 A·B다. Type B(EOP)는 5일 전이다.
- C: 30일 전·2일 전은 Type B(pre-IND, pre-NDA/BLA) 조합이다.
- D: 요청과 함께 내는 것은 A·C·D·INTERACT이고 Type B(EOP)는 아니다.

### Q06 [R][Domain III] — Type D
Which statement describes a Type D meeting under PDUFA VII?

A. An early meeting on CMC and nonclinical questions held before pre-IND, typically once per product
B. A meeting on a narrow set of no more than two issues, with a 50-day timeframe and package with request
C. A meeting for any number of follow-up questions, provided the package arrives 30 days before
D. A meeting reserved for disputes, with a 30-day timeframe and package with the request

**정답:** B

**해설**
- B: Type D는 PDUFA VII에서 새로 생긴 유형으로 **좁은 쟁점 2개 이하**(후속 질문·특정 CMC)를 **50일**에 다룬다. 패키지는 요청과 함께다.
- A: pre-IND 전 초기 CMC·비임상 질문은 INTERACT다.
- C: 쟁점 수가 2개 이하로 묶여 있고, 패키지도 요청과 함께다.
- D: dispute는 Type A(30일)다.

### Q07 [R][Domain III] — INTERACT
Which description fits the INTERACT meeting?

A. A 75-day meeting on early CMC and nonclinical questions before pre-IND, usually once per product
B. A 50-day meeting limited to two CMC questions, available repeatedly at any stage
C. A 60-day meeting held after IND submission to agree on Phase 2 dose selection and the safety monitoring plan
D. A 30-day meeting used when a sponsor disagrees with an earlier FDA position

**정답:** A

**해설**
- A: INTERACT는 pre-IND보다 앞선 **초기 CMC·비임상** 질문을 다루고 **75일**, 보통 **제품당 1회**다.
- B: 50일·쟁점 2개는 Type D다.
- C: 60일·IND 이후 회의는 INTERACT의 특징이 아니다.
- D: 30일·이견 해결은 Type A다.

- A: 서로 얽힌 여러 쟁점은 Type D의 범위(2개 이하)를 넘는다.

### Q13 [A][Domain II] — cancelling after preliminary responses
FDA's preliminary responses for a scheduled Type C meeting fully answer all of the sponsor's questions. The team sees no need to meet. What may the sponsor do?

A. Cancel the meeting before it occurs; the preliminary responses then serve as the official minutes
B. Hold the meeting anyway, because preliminary responses cannot replace a formal meeting record
C. Cancel the meeting, but the preliminary responses lack formal status and a new Type D request is needed for the record
D. Convert the meeting to a WRO, which restarts the 75-day timeframe from the cancellation date

**정답:** A

**해설**
- A: preliminary responses가 질문에 충분히 답하면 스폰서가 회의 전에 통보하고 **회의를 취소**할 수 있고, 그 응답이 **공식 회의록**이 된다.
- B: 회의를 꼭 열어야 한다는 규정은 없다.
- C: 취소해도 응답이 공식 기록으로 남는다. 별도 회의 요청은 필요 없다.
- D: WRO는 요청 시점부터 서면 응답만 받는 방식이다. 취소 시점에서 기한이 다시 시작되지 않는다.

### Q14 [R][Domain II] — WRO
Which statement about a written response only (WRO) is correct?

A. WRO responses come within half the normal timeframe for the meeting type
B. Sponsor may request it or FDA may convert to it; the timeframe matches the meeting type
C. A WRO is issued after FDA itself has cancelled a scheduled face-to-face meeting
D. WRO is reserved for Type D meetings, because their issues are narrow enough for writing

**정답:** B

**해설**
- B: **WRO**는 요청 시점부터 서면 응답만 받는 방식이다. FDA가 WRO로 전환할 수도 있고 응답 기한은 **회의 유형과 같다**.
- A: 기한은 유형과 같다. 반으로 줄지 않는다.
- C: WRO는 처음부터 서면 응답을 요구하는 방식이다. 회의 취소 후 preliminary responses를 회의록으로 받는 것과 다르다.
- D: Type D 한정이라는 근거는 없다.

### Q15 [A][Domain II] — minutes error
FDA's official minutes from a Type B meeting state that the sponsor committed to a 24-month study, but the sponsor committed to a 12-month study. What should the sponsor do?

A. Ignore the error, because minutes are informal and carry little weight in later review
B. Request a new Type B meeting to renegotiate the duration from the start
C. Note the discrepancy in the next annual report, which supersedes the minutes
D. Promptly request a correction in writing, citing the passage and the basis

**정답:** D

**해설**
- D: 회의록은 **FDA가 쓰는 공식 기록**이다. 틀린 문구와 근거를 적어 즉시 **서면 정정 요청**을 낸다.
- A: 공식 기록이라 이후 심사·분쟁의 근거가 된다. 방치하면 24개월이 사실상 약속이 된다.
- B: 합의 내용은 12개월이었다. 새로 협상할 일이 아니라 기록을 고칠 일이다.
- C: 연차 보고는 회의록을 고치는 수단이 아니다.

### Q17 [R][Domain II] — core of a briefing package
What is the central element of an effective FDA meeting briefing package?

A. A narrative development history, placed before any questions so that reviewers understand the full context
B. A list of clear, answerable questions, each followed by the sponsor's position and supporting rationale
C. A complete set of full study reports, so FDA can answer any question it chooses
D. An executive summary of the product's commercial strategy and anticipated market

**정답:** B

**해설**
- B: briefing package는 **질문이 전부**다. 분야별로 묶은 답할 수 있는 질문과 각 질문 아래 **스폰서 입장·근거·데이터 요약**이 핵심이다.
- A: 배경은 질문을 이해하는 데 필요한 만큼만 쓴다.
- C: 전체 보고서는 부록으로 돌리고 배경은 요약 위주다.
- D: 상업 전략은 패키지 구조에 들어가지 않는다.

### Q18 [A][Domain II] — fixing a weak package
A draft Type C package has hundreds of pages of appended study reports followed by one question: "Does FDA have any comments on our program?" The regulatory lead must revise it before submission. Which revision best fits FDA expectations?

A. Ask specific questions by discipline, each with the sponsor's position; summarize the background
B. Remove the question and let FDA pick its own topics from the background material in the appendices
C. Split the package into one Type D request per report, each with a single open-ended question
D. Keep the open question but append more reports, so FDA has the complete dataset for broad comments

**정답:** A

**해설**
- A: 질문을 **명확·답 가능한 형태로 분야별**로 쓰고, 각 질문 아래 **스폰서 입장·근거**를 붙인다. 배경은 요약하고 전체 보고서는 부록이다.
- B: 질문이 패키지의 핵심이라 지우면 안 된다.
- C: Type D는 좁은 쟁점 ≤2개 회의다. 보고서마다 쪼개는 방식이 아니다.
- D: 열린 질문은 답할 수 있는 형태가 아니다. 자료를 늘려도 고쳐지지 않는다.

### Q19 [A][Domain V] — pre-BLA package content
A sponsor is preparing a pre-BLA meeting package. Which set of topics matches what this package should cover?

### Q20 [An][Domain III] — dispute route
FDA's review division rejects a sponsor's proposed primary endpoint. Informal discussions with the division have not resolved the issue. The sponsor wants a formal review of the decision above the division. Which route is correct?

A. Submit an SPA request, since a 45-day SPA review overrides the division's position
B. Request an advisory committee under 21 CFR 14, whose vote then binds the review division's decision
C. File formal dispute resolution under 21 CFR 10.75 with the division's supervisor, step by step
D. Request a Type D meeting, because the disagreement involves a single narrow issue on one endpoint

**정답:** C

**해설**
- C: **FDRR**은 **21 CFR 10.75**에 따라 결정을 내린 부서의 **상급자**에게 순차적으로 서면 재심을 요청하는 절차다. Type A(30일)로 협의하는 길도 있다.
- A: SPA는 프로토콜 설계 합의 절차다. 결정 재심 수단이 아니다.
- B: advisory committee는 FDA 재량이고 투표는 권고일 뿐이다.
- D: 상급자 재심을 구하는 상황이라 FDRR이나 Type A가 맞다.

### Q24 [A][Domain IV] — advisory committee transparency
An advisory committee meeting is scheduled for a sponsor's BLA. The sponsor's communications team asks when the briefing documents become public and what the committee's vote will mean. What is correct?

A. FDA's own document alone is released 30 days before, and a unanimous vote binds FDA
B. Documents are released after the meeting, and the vote binds FDA on efficacy questions
C. Both briefing documents are made public 2 business days before; the vote is advisory
D. Documents stay confidential until approval, and the committee's vote decides the application

**정답:** C

**해설**
