### Q01 [R][Domain II] — current FDA DMF types
Which list matches the Drug Master File types that FDA currently accepts?

A. Type II drug substances, Type III packaging, Type IV excipients, Type V reference information.
B. Type II drug substances, Type III excipients, Type IV packaging, Type V FDA reference information.
C. Type I facilities, Type II drug substances, Type III packaging, Type IV excipients.
D. Type I drug substances, Type II intermediates, Type III packaging, Type IV excipients.

**정답:** A

**해설**
- A: 현재 유형은 **Type II**(원료의약품·중간체·그 제조 원료 또는 완제), **Type III**(포장재), **Type IV**(부형제·착색제·향료), **Type V**(FDA가 승인한 참조정보)다.
- B: 포장재와 부형제의 번호가 뒤바뀌었다. 포장재가 Type III, 부형제가 Type IV다.
- C: **Type I**(제조소·시설·절차·인력)은 폐지됐다.
- D: Type I은 원료의약품 유형이 아니었고 지금은 폐지됐다. 원료의약품과 중간체는 함께 Type II다.

### Q02 [R][Domain II] — fate of Type I information
Type I DMFs covered manufacturing sites, facilities, operating procedures and personnel. Where does FDA now obtain this kind of information?

A. Through a Type V DMF that each site files once and updates in its annual report.
B. Through establishment registration and inspection, since the Type I DMF has been abolished.
C. Through the Type II DMF, which must now carry a full facility section for each site.
D. Through the referencing ANDA, which must describe each supplier site in Module 3.

**정답:** B

**해설**
- B: Type I은 **폐지**됐고 시설 정보는 **등록·사찰**로 간다.
- A: Type V는 FDA가 승인한 참조정보 유형이다. 시설 정보를 대신 받는 장치가 아니다.
- C: Type II는 원료의약품·중간체 유형이다. Type I의 시설 정보를 옮겨 담는 구조가 아니다.
- D: 교과서는 시설 정보의 행선지를 신청서가 아니라 등록·사찰로 둔다.

### Q03 [A][Domain II] — container supplier
A bottle and closure manufacturer wants generic applicants to reference its proprietary resin formulation without disclosing it. Which DMF type fits?

A. Type III, which covers packaging materials.
B. Type II, which covers intermediates and their materials.

D. Type IV, which covers excipients, colorants and flavors.

- C: Type V는 FDA가 승인한 참조정보다. 포장재는 전용 유형이 있다.
- D: Type IV는 부형제·착색제·향료다. 용기·마개는 포장재다.

A supplier of a novel coating colorant wants several NDA applicants to rely on its confidential composition data. Which DMF type should it file?

### Q05 [R][Domain II] — DMF is not approved
Which statement describes how FDA handles a Type II DMF?

A. FDA reviews it once, and the result binds each later application that references it.
B. FDA approves the DMF on its own, and referencing applications then rely on that approval.
C. FDA approves the DMF once it passes the Completeness Assessment, and lists it as approved.
D. FDA reviews it only in connection with an application that references it, with no standalone conclusion.

**정답:** D

**해설**
- D: DMF는 **승인되지 않는다**. 참조하는 신청(NDA/ANDA/IND)의 심사와 함께 검토되고 결론은 그 신청에 대해 내려진다(21 CFR 314.420).
- A: DMF에는 독립 결론이 없다. 각 신청의 심사 안에서 평가된다.
- B: DMF 단독 승인이라는 절차는 없다.
- C: Completeness Assessment 통과는 "Available for Reference" 목록 게시이지 승인이 아니다.

### Q06 [A][Domain II] — letter of authorization
An ANDA applicant buys API from a supplier that holds a Type II DMF. The supplier refuses to share process details. What does the applicant place in the ANDA?

A. A copy of the letter of authorization (LOA) issued by the DMF holder.
B. A written confirmation from the authority of the supplier's country.
C. The supplier's CEP together with a QP declaration on GMP compliance.
D. A Letter of Access and the Applicant's Part, both supplied by the holder.

**정답:** A

**해설**
- A: 보유자는 **LOA(letter of authorization)** 로 참조 권한을 주고, 신청자는 **LOA 사본**을 신청서에 넣는다(21 CFR 314.420).
- B: 수출국 당국의 written confirmation은 EU Art 46b의 수입 요건이다.
- C: CEP와 QP declaration은 EU 장치다. FDA는 CEP를 인정하지 않는다.
- D: Letter of Access와 Applicant's Part는 EU ASMF의 용어다.

### Q07 [A][Domain V] — holder obligations after a change
A Type II DMF holder changes one synthesis step. What are the holder's obligations?

A. File a supplement under 21 CFR 314.70 on behalf of the applicants that reference the DMF.
B. Notify FDA at the next annual report alone, because a DMF is not an approved document.
C. Submit a DMF amendment, notify each referencing applicant, and cover it in the annual report.
D. Obtain prior approval from FDA for the change, then let each applicant decide whether to report.

**정답:** C

**해설**
- C: 보유자는 **DMF 개정**을 내고, 영향받는 **모든 참조자에게 통지**하고, **annual report**에 반영한다(21 CFR 314.420).
- A: 314.70 보충은 신청자의 의무다. 보유자가 대신 내지 않는다.
- B: annual report만으로 끝나지 않는다. 개정 제출과 참조자 통지가 함께 간다.
- D: DMF는 승인 대상이 아니므로 보유자가 받을 사전 승인이 없다.

### Q08 [A][Domain V] — applicant obligations after a DMF change
The applicant receives notice that its API supplier amended its DMF for a new synthesis step. What must the applicant do?

A. Request a new letter of authorization, which replaces any supplement to the application.
B. Nothing further, because the holder's DMF amendment already updates the referencing ANDA.
C. Wait for FDA to complete its review of the amendment and then submit an annual report.

**정답:** D

**해설**

- A: LOA는 참조 권한이다. 변경 보고를 대신하지 않는다.
- B: DMF 개정이 신청자 의무를 대신하지 않는다.
- C: 카테고리는 영향 평가로 정한다. annual report로 미리 정해져 있지 않다.

### Q10 [R][Domain II] — nature of the Completeness Assessment
Under GDUFA, what is the Completeness Assessment (CA) of a Type II API DMF?

A. A pre-approval inspection of the API site, scheduled before the DMF is listed.
B. A full scientific review of the process that FDA reuses across each ANDA.
C. A review of the LOA and fee records, made after the first ANDA is approved.
D. A check that the DMF is complete, not a scientific review of its adequacy.

**정답:** D

**해설**
- D: CA는 **완결성 점검**이다. 과학적 적정성 심사가 아니다.
- A: 사찰은 CA의 내용이 아니다.
- B: CA는 과학적 전체 심사가 아니고, DMF의 과학적 평가는 참조 신청과 함께 이뤄진다.
- C: CA는 참조 전에 통과해야 목록에 오른다. ANDA 승인 뒤에 하는 절차가 아니다.

### Q11 [A][Domain II] — ANDA references a DMF that failed CA
An API supplier paid its GDUFA DMF fee, but its Type II DMF has not passed the Completeness Assessment. A generic firm submits an ANDA that references it. What is the main regulatory risk?

A. FDA converts the DMF into a Type V file until the Completeness Assessment is done.
B. FDA approves the ANDA on condition that the supplier passes the Completeness Assessment later.
C. The ANDA risks refuse-to-receive, as the DMF is not on the Available for Reference list.
D. The ANDA is reviewed normally, and the DMF is assessed in the first review cycle.

**정답:** C

**해설**
- C: Type II API DMF는 CA를 통과해 **"List of Type II DMFs Available for Reference"** 에 올라야 ANDA가 참조할 수 있다. 미통과면 **refuse-to-receive** 위험이 있다.
- A: Type V로 바꾸는 절차는 없다.
- B: 조건부 승인 구조는 교과서에 없다.
- D: CA 미통과 DMF를 참조하면 접수 단계가 문제다.

### Q13 [An][Domain IV] — why GDUFA added a fee and CA
DMFs are never approved, yet GDUFA added a one-time DMF fee and a Completeness Assessment. What is the best explanation?

A. The fee and CA turn the DMF into an approved file, which lets FDA skip the quality review of the referencing ANDA.
B. Incomplete DMFs delayed ANDAs, so the CA screens completeness before reference without creating an approval.
C. The fee aligns FDA with EDQM, so that a DMF passing the CA is accepted in place of a CEP by EU authorities.
D. The CA replaces foreign inspections of API sites, which FDA could not fund before user fees were collected.

**정답:** B

**해설**
- B: ANDA 지연의 큰 원인이 **불완전한 DMF**였다. 수수료로 자원을 확보하고 CA로 참조 전 완결성을 걸러, "승인"을 만들지 않으면서 품질 문턱을 세웠다.
- A: CA를 통과해도 DMF는 승인되지 않고, ANDA 심사도 그대로다.
- C: CA와 CEP를 잇는 장치는 없다. 지역 간 상호 인정 근거도 교과서에 없다.
- D: CA는 완결성 점검이다. 사찰을 대신하지 않는다.

### Q15 [A][Domain II] — sequence before referencing under GDUFA
A new API maker plans to supply several generic firms in the US. In what order should it prepare so that ANDAs can reference its Type II DMF?

A. File the DMF, pay the one-time fee, pass the CA, and then issue LOAs to customers.

- C: FDA는 CEP를 인정하지 않는다. ANDA 사본 제출은 근거가 없다.
- D: GDUFA DMF 수수료는 1회다. 고객별 연간 수수료가 아니다.

### Q16 [A][Domain IV] — US use of an API that has only a CEP
A US applicant wants to use an API whose supplier holds an EU CEP but no US DMF. What is the regulatory path?

- D: CEP는 미국에서 DMF를 대신하지 않는다.

### Q22 [A][Domain I] — new substance without a monograph
A supplier makes a new active substance for which no Ph. Eur. monograph exists. It wants to protect its process in an EU MAA. Which route fits?

A. An ASMF, the general route for confidential substance data.

**정답:** A

**해설**
- A: **ASMF**는 모노그래프가 없는 신규·특수 API에도 쓰는 **일반 비밀보호 경로**다.
