# Ch.29 — 시판 후 의무: 미국은 "법적 근거 조항"으로, EU는 "연구 목적·승인 유형"으로 분류한다

> **덱:** Ch29_1(개념·구조) + Ch29_2(세부·상황형), 40장. 이틀 분량 한 장.
> **검증 메모(2026-11-22):** PMR vs PMC 정의; FDORA AA 확증·6개월 보고·506(c)(3); Reg 507/2006 SO·1년 갱신; Art 14(8) 연 재평가 — 두 덱 메모 기준. PMR 법적 근거 4종, 506B(60일, 7범주), 505(o)(3) 조건, 2011 guidance, PAES Reg 357/2014(Art 21a/22a), PASS GVP VIII·PRAC 프로토콜, Annex II A–E, 502(z)·303(f), 107n 60일·107p 12개월, RMP Part III category 1/2/3, Art 23은 ○. 506B 범위(임상 안전성·임상 효능·임상약리·비임상 독성 PMR/PMC만, CMC·안정성 PMC는 314.81(b)(2)(viii)) — 21 CFR 314.81(b)(2)(vii)–(viii)·601.70, FDA 505(o)(3) guidance 2011 (2026-11-28 원문 확인).

## 학습 목표
1. **PMR 4종 법적 근거**와 **PMC**를 구분하고, **505(o)(3) 요구 조건**(기존 체계로 불충분·관찰 연구 우선)을 적용한다.
2. **506B annual status report**(60일, 7범주), 승인서 기한·연장·미이행 결과(502(z))를 안다.
3. EU **Annex II A–E**, **PASS(21a/22a, GVP VIII, PRAC 60일·최종 12개월)·PAES(357/2014)·SO(507/2006)**, **RMP Part III category 1/2/3**를 쓴다.
4. 미국↔EU 의무를 **짝짓고**, 조건부 승인의 조건 미이행 결과를 비교한다.
5. 하나의 **등록부 프로토콜**로 FDA PMR·EU PASS·SO를 동시에 충족하는 설계를 말한다.

## 1. 미국 — PMR vs PMC
| | **PMR**(postmarketing requirement) | **PMC**(commitment) |
|---|---|---|
| 성격 | 법·규정이 **요구** | **서면 약속**(승인서 기재) |
| 근거 | ① **505(o)(3)** 안전성(known serious risk 평가 / signal 평가 / unexpected serious risk 식별) ② **506(c)(2)(A)** AA 확증 ③ **505B** PREA 연기 소아 ④ **314.610/601.91 Animal Rule** 현장 연구 | 그 외(DDI PK, 특수집단 PK, CMC 안정성·방법, 효능 보조, 품질 개선) |
| 제재 | 미이행 → **misbranded(502(z))**, 민사 벌금(**303(f)**), 공개 | 없음 — 공개·신뢰 비용 |

- **505(o)(3) 조건**: FDA가 ① **FAERS·Sentinel 등 기존 체계로 충분히 평가 불가**하다고 판단하고 ② 목적이 세 가지 중 하나일 때만; **임상시험은 관찰 연구(study)로 불충분할 때만**(505(o)(3)(D)). FDA가 RCT를 제안하면 스폰서는 **claims-DB 연구의 타당성**(노출·결과 정의, confounding, 검정력)을 논증 → 협의·서면 의견 → 승인서 최종 문구 전 합의, 불일치 시 FDRR.
- **왜 PMC가 남아 있나**: 505(o)(3)는 안전성 목적 + 요건으로 **범위가 제한** → 요구할 수 없는 연구를 스폰서가 약속하면 PMC로 기록·추적해 투명성 확보. 단 506B 보고 대상은 임상 안전성·임상 효능·임상약리·비임상 독성 PMC뿐이고, CMC·안정성 PMC는 314.81(b)(2)(viii)로 annual report에 보고한다(아래 2절).
- **왜 FDAAA 2007이 PMR을 만들었나**: PMC 이행률이 낮고 강제 수단이 없어 안전성 연구가 수년 지연(Vioxx 등) → §901이 505(o)(3) 요구 권한·기한·502(z) 제재·506B 보고를 붙여 "약속"을 "의무"로.

분류 예: 간독성 약물역학 연구 → **PMR 505(o)(3)** / DDI PK → **PMC** / 연기 소아 연구 → **PMR 505B** / AA 확증 → **PMR 506(c)(2)(A)**. 모두 506B 대상.

## 2. 추적과 집행 — 506B
- **506B annual status report**: 승인 기념일 **60일 내**, annual report(314.81(b)(2)(vii), eCTD **1.13**)에 포함 — 각 PMR/PMC의 **상태 7범주**: **pending / ongoing / delayed / terminated / submitted / fulfilled / released**, 지연·중단 사유, 마일스톤(protocol 제출·완료·보고 제출) 예정·실제 날짜. FDA **공개 DB** 게시.
- **506B 범위(2026-11-28 원문 확인)**: 314.81(b)(2)(vii)(BLA는 601.70)는 **임상 안전성·임상 효능·임상약리·비임상 독성**에 관한 PMR과 서면 PMC만 대상으로 한다. **CMC PMC와 모든 안정성 연구 약속**은 506B 연구가 아니고, NDA는 **314.81(b)(2)(viii)**("other postmarketing studies")로 annual report에 상태를 보고한다(FDA 505(o)(3) guidance 2011-04 각주 9). 공개 DB에도 CMC 같은 독점 정보 약속은 올리지 않는다. "모든 PMC = 506B"는 틀린 일반화다.
- **승인서(approval letter)** 에 각 의무의 설명·**기한**(final protocol submission, study completion, final report submission) 고정. **연장**은 **기한 전 서면 요청**(사유·수정 일정·완화 조치) → FDA 서면 합의 → 다음 506B에 반영. 일방 지연은 **delayed** 공개, "good cause" 없는 미이행은 **misbranding**(505(o)(3)(E)–(F), 502(z)). 이미 놓쳤다면 즉시 서면 통지·연장 요청, 506B에 사유.
- **PMC 해제**: 서면으로 **release 요청**(과학적 정당화) → 동의 시 "released"; 일방 중단은 "terminated".
- **PMR/PMC가 아닌 시판 후 의무**(추적표엔 넣되 506B 범주 밖): **REMS assessment**(505-1(g): 18개월·3년·7년 — REMS 목표 달성 평가, 위험 크기 평가인 505(o)(3) PMR을 대신 못 함) · **소아 deferral 연 상태 보고**(505B(a)(4)) · **AA 6개월 진행 보고**(506(c)) · periodic safety·annual report(314.80/.81).
- **Animal Rule PMR**(314.610(b)/601.91(b)): 사용 상황(위협 노출) 발생 시 현장 안전성·효능 연구 — **사건 의존적** PMR; 라벨 제한·판촉 사전 제출(314.640).

## 3. 결과는 의사결정 입력이다
PMR 관찰 연구에서 중증 간독성 2배 → 보고 → FDA **505(o)(4) SLC** 통지(30일) 또는 스폰서 선제 **CBE-0** 경고 → 필요 시 **REMS 신설·수정**(505-1(g)) → 추가 PMR(기전·위험 인자) → 506B "submitted/fulfilled". 심하면 철회 논의. PMR/PASS는 "연구"가 아니라 라벨·위험관리의 입력.

## 4. EU — 조건은 Annex II에, 연구는 세 종류
### 4.1 Annex II (중앙집중 승인서)
| 절 | 내용 |
|---|---|
| **A** | 제조자(활성물질·배치 출하 책임자) |
| **B** | 공급·사용 조건·제한(처방 지위) |
| **C** | MA의 기타 조건·요건 — **PSUR** 제출 요건(EURD) (2026-11-28 검증) |
| **D** | 안전·효과적 사용 조건·제한 — **RMP·추가 위험 최소화(aRMM)**, 시판 후 의무 |
| **E** | conditional MA **및 exceptional circumstances MA**의 **specific obligations**(완료 기한) |

### 4.2 연구 의무 3종
| | **PASS** | **PAES** | **SO** |
|---|---|---|---|
| 목적 | 안전성(위험 식별·특성화·위험 최소화 효과) | 효능 — 초기 B/R 불확실이 **승인 후 해소 가능**할 때: 대리 종점 확인, 하위군 **이질성**, **장기 효능**, 병용·의료관행 변화, 일상 진료 효과 | CMA 포괄 데이터 |
| 근거 | Dir 2001/83 **Art 21a**(승인 조건) / **22a**(승인 후), **GVP Module VIII**, Arts 107m–q | **Art 21a/22a** + Delegated Reg (EU) **357/2014** | Reg **507/2006**, Annex II.E |
| 절차 | **Imposed 비개입 PASS**: 프로토콜 **PRAC 제출 → 60일 내 의견**(107n), 승인 후 시작(반대 상태 시작은 위반 → 수정 재제출), 중대 수정도 PRAC, **최종 보고 데이터 수집 종료 후 12개월 내**(107p) → PRAC 평가 → variation/referral. **Voluntary** PASS: RMP category 3, 기록만 | 당국 프로토콜 평가, 결과 variation(SmPC 5.1·4.1); 효능 없음 → 적응증 제한·조건 추가·Art 116 | 갱신(만료 6개월 전)에서 진척 평가; **기한 변경·삭제는 Type II variation**(Annex II.E) |

- 왜 imposed만 PRAC 승인인가: 당국이 B/R 판단의 전제로 요구한 연구라 설계 부적절이면 규제 결정이 흔들림 → 사전 품질 통제. 함의: imposed로 전환될 수 있는 연구는 처음부터 **GVP VIII 수준·ENCePP 등록**으로.
- **RMP Part III(PV 계획)**: **category 1** = MA 조건으로 **부과된 연구**(imposed PASS/PAES) · **category 2** = CMA·exceptional의 **specific obligation** · **category 3** = 법적 부과 아닌 RMP상 **요구되는 추가 PV 활동**. 1·2는 Annex II에, 3은 RMP에만. category 3 등록부가 PRAC 결정으로 조건이 되면 → **22a 부과 → Annex II.D 추가(variation) → 프로토콜 PRAC 승인 → 12개월 보고 → RMP 갱신**.
- **CMA 갱신 시 SO의 운명**: ① 완료 → Annex II.E 삭제(Type II), 모두 끝나면 표준 MA 전환 ② 진행·정당한 지연 → 갱신 + 기한 변경 ③ 미이행 → 갱신 거부(실효)·조건 강화·Art 116.
- **Exceptional circumstances**(Art 14(8)): 매년 **B/R 재평가**(특정 의무 이행·새 데이터 제출, 조건은 Annex II) — PASS가 아니라 연 재평가가 의무.
- **Art 23**: 조건으로 부과되지 않았어도 MAH는 과학·기술 진보 반영 + B/R 영향 정보 즉시 제공(제3국 조치 포함) — imposed 의무가 "특정 질문", Art 23이 "그 외 전부"를 포괄하는 **일반 의무**.
- **투명성**: 미국 506B DB는 **상태·기한 공개**(지연 즉시 노출), EU는 Annex II·EPAR·RMP 요약·**EU PAS Register(ENCePP)** 로 문서 공개, 개별 진척 DB는 없음(CMA 갱신·PSUR 평가 보고서에서 드러남).

## 5. 미국 ↔ EU 짝짓기
| EU | 미국 |
|---|---|
| **SO**(확증 데이터) | **506(c)(2)(A)** AA 확증 PMR |
| **Imposed PASS**(장기 안전성) | **505(o)(3)** PMR |
| **PAES**(대리 종점 확인) | AA 확증 PMR 또는 PMC(미국엔 "PAES" 범주 없음) |
| **Annex II.D aRMM** | **REMS** |
| **PSUR 주기(C)** | 314.80 periodic / PBRER |

같은 연구가 EU에선 PAES, 미국에선 PMC일 수 있다 → 추적표에 **지역별 법적 성격·기한을 따로**. **조건부 승인의 조건 미이행**: 미국 AA → **506(c)(3) 신속 철회**·misbranding; EU CMA → **갱신 거부**(1년 주기)·Art 116 — 일반 PMR/PASS보다 무겁다(승인 존속 조건).

## 7. 흔한 혼동
1. **PMC도 misbranding?** 아니다 — PMR만.
2. **505(o)(3)로 DDI PK 요구?** 안전성 목적·조건 밖 → PMC.
3. **FDA가 바로 RCT 요구?** 관찰 연구로 불충분할 때만.
4. **REMS 평가 = PMR 충족?** 다른 질문(목표 달성 vs 위험 크기).
5. **Voluntary PASS도 PRAC 승인?** imposed 비개입만.
6. **SO 기한을 서신으로 연장?** Type II variation.
7. **Exceptional = PASS 의무?** 연 1회 재평가.
8. **EU에 506B 같은 상태 DB?** 없음 — 문서 중심.
9. **PAES = 미국 어디?** 1:1 없음.

## 8. 네 분야에 올려놓기
세포·EV 제품엔 **장기추적(5–15년) PMR/PASS + 등록부**가 거의 항상 붙고, RMAT이면 AA 확증을 등록부로(506(g)(7)), EU CMA면 SO·PASS 중첩. **하나의 등록부 프로토콜**: 모든 치료 환자 전향 등록 · 사전 정의 **효능 종점**(AA 확증·EU SO/PAES) · **장기 안전성 종점**(종양원성·면역·2차 악성 — 505(o)(3) PMR / imposed PASS) · **aRMM 효과 지표**(REMS 평가 / Annex II.D) · 데이터 소스·결측·통계 계획(GVP VIII·ENCePP) · 지역별 보고 일정(506B·CMA 갱신·PSUR) 매핑 · 독립 과학위원회; FDA 합의 + **PRAC 승인**. **3년차 자가면역 클러스터**: 미국 중간 결과 보고 → CBE-0(5 W&P) 또는 505(o)(4) SLC, REMS 검토, 추가 PMR; EU PASS 진행 보고 → PRAC 신호 평가 → variation(4.4/4.8) + RMP 갱신, 심하면 referral; 공통 CCDS·DHPC·프로토콜 수정(PRAC). **12개월 달력**(PMR 3·PMC 2·CMA SO 2·imposed PASS 1): 미국 annual report + 506B(5건)·마일스톤·사전 연장·AA 6개월 보고; EU CMA 갱신(만료 6개월 전) + SO 진척·PASS PRAC 프로토콜/진행/최종 보고·PSUR(EURD)·RMP. **갱신 dossier**: eAF, SO 진척(등록·중간 데이터), B/R 요약, RMP, 기한 variation, SmPC/PL안 — 미국 506B엔 같은 확증시험을 **506(c)(2)(A) PMR "ongoing"** 으로 마일스톤 일치시켜 기재.
