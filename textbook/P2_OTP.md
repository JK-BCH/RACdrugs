# Phase 2 ① — CBER OTP: 세포·유전자치료의 단일 창구, "제품 = 공정"이라는 전제

> **덱:** P2_OTP (20장). Phase 2 특화 주제 1/6.
> **검증 메모(2026-11-22):** FDA **CGT FAQ 최종 guidance FR 2026-08-20**(기준일 직전 → 시험 범위 안); CBER **CMC 유연성 성명 2026-01-11**; **Potency Assurance 최종 2026-11-02 → 기준일 이후**(현행 = 2011 Potency Tests + 2023-12 초안); **Manufacturing Changes & Comparability 초안 2023-07**(2026 agenda); **Platform Technology Designation**(506K) 초안 2024-05, 첫 지정 Sarepta AAVrh74 2025-06 → 2025-07 철회, Krystal HSV-1 2025-10; **Expedited Programs for RMT 초안 2025-09-20**(+ 2025 가을 CGT 초안 3종); 동종세포 안전성 시험 초안 2024-04 → 2025-01-23 DB 삭제; **RPD PRV 재승인 2026-02-03 → 2029-09-30**; AMT designation 최종 2025-01 — 덱 메모 기준. OTP 조직(2023 super office)·CTGTAC·TRG·INTERACT 75/pre-IND 60/IND 30·312.42·210.2(c)·CMC guidance 목록·21 CFR 610·601.2·600.14/.80·1271 C·D·CPGM 7345.848/7341.002·START pilot·EMA/CAT/22473/2025는 ○. OTP 산하 office 6개(아래 OTP 항목; FDA CBER 조직 페이지) (2026-11-28 원문 확인).

## 학습 목표
1. **OTP**가 무엇이고(2023 super office), 법적 틀(**PHS 351 + 600/601/610 + 312 + 1271 + 210/211**)과 자문·분류 기구(CTGTAC·TRG·RFD)를 안다.
2. **INTERACT 75 → pre-IND 60 → IND 30 → hold(312.42) → Phase 1(210.2(c)) → EOP2 → BLA(601.2·610) → PAI → 승인 후** 경로와 CGT hold가 CMC에서 나오는 이유를 설명한다.
3. 2026-09-01 기준 **guidance 지도**(최종/초안/성명)를 외운다.
4. **610 표준**(potency·sterility·purity·identity·lot release)을 짧은 유효기간 제품에 적용한다.
5. 가속 도구·LTFU·전임상 2013·사찰·expanded access를 CGT 맥락으로 연결하고, **미국 OTP vs EU CAT/CHMP**를 비교한다.

## 1. OTP — 무엇을, 누가
- **OTP(Office of Therapeutic Products)**: 2023 CBER 재조직에서 **OTAT**를 격상한 **super office** — 세포치료·유전자치료·치료용 조직공학·351 HCT/P·조합(CAR T, AAV·렌티 유전자치료, 유전체 편집, 동종·자가 세포, 종양용해 바이러스, 치료 백신, 미생물군 일부). 산하 office **6개**: Office of **Gene Therapy CMC** · Office of **Cellular Therapy and Human Tissue CMC** · Office of **Plasma Protein Therapeutics CMC** · Office of **Clinical Evaluation** · Office of **Pharmacology/Toxicology** · Office of **Review Management and Regulatory Review**(2023-02-26 시행) (2026-11-28 원문 확인).
- **법적 틀**: **PHS 351 BLA + 21 CFR 600/601/610 + 312(IND) + 1271(공여자·cGTP) + 210/211**. 자문위 **CTGTAC**. 분류: **Tissue Reference Group**(CBER-CDRH 비공식·비구속, 361/351·기기 경계) vs **RFD**(Part 3, OCP, **60일**, 구속). 초기 소통 **INTERACT**(2018~).
- **"제품 = 공정"**: 세포·EV·벡터는 분석으로 완전 규정 불가 → 품질은 **공정 통제의 산물** → 변경마다 comparability, 역가는 **matrix**(2011), 무균은 **대체 신속법**(610.12), 짧은 유효기간은 **조건부 출하**.

## 2. 개발 경로와 clinical hold
| 단계 | 내용 |
|---|---|
| **INTERACT**(비공식, **75일**) | IND-enabling 설계 **전** — 전임상 POC·CMC 개념·독성 계획이 있을 때; 질문 3–5개(어떤 독성 패키지가 Phase 1을 뒷받침하나, LTFU 범위 등). 보통 제품당 1회 |
| **pre-IND Type B**(**60일**) | 완성 전임상(2013 guidance)·Phase 1 CMC 초안·프로토콜·1271 공여자 적격 |
| **IND → 30일**(312.40) | 통지 없으면 개시; Phase 1 CMC는 **210.2(c)** 211 면제(2008 Phase 1 CGMP: 통제 환경·기록·QC; **cGTP는 면제 안 됨**) |
| **Clinical hold**(312.42) | CGT 흔한 사유: ① **CMC 정보 부족**(무균·외래성 인자·마이코플라즈마·엔도톡신, 세포 은행 특성, **역가/정체성 시험 부재**, 안정성) ② 비합리적 위험(벡터 RCR·삽입 돌연변이, 용량 근거, 독성 부족) ③ IB·프로토콜 결함 → complete response 후 FDA **30일** |
| EOP1/EOP2(Type B 70일) → pre-BLA(60일) → **BLA**(601.2, 610 표준, 610.2 lot release 재량) → **PAI**(7345.848) → 승인 후 600.80·BPDR 45일·LTFU | — |

**왜 CGT IND는 CMC hold가 많은가**: 제품 = 공정(공정 통제가 안전 근거) / 최종 멸균 불가·짧은 유효기간 / 역가 정의 난제(작용기전 다중) / 원료 변동(공여자·배지·벡터) / 세포·벡터 은행 미완 / 자가는 환자별 배치. **2026-01-11 CMC 유연성 성명**: 임상 개발 중 **경미 제조 변경은 과도한 comparability 없이** 비교성 데이터로 수용, 승인 후 **상업 규격 재평가**, 공정 검증 유연 → "Phase 1 전에 공정 다 잠가라" 압력 완화. **CGT FAQ 최종(2026-08-20)**: IND 소통·CMC(언제 어떤 시험)·전임상·임상 설계 FAQ로 예측 가능성. 타협 없는 것: 무균·외래성 인자·마이코플라즈마; 역가는 최소 **개발 계획 + 대리지표**. 전략: INTERACT에서 CMC 질문 먼저, FAQ로 hold 체크리스트 자가 점검.

## 5. BLA에서 세포 제품만 갖는 것
**Module 3**: 공여자 적격 기록(1271 Subpart C) · **세포 은행**(MCB/WCB — 정체성·순도·외래성 인자·마이코플라즈마·종양원성, 610.18) · 원료·보조 물질(혈청·사이토카인·배지 — BSE/TSE, 공급자 적격) · 공정 검증(PPQ, 자가/동종 배치 정의) · **comparability 이력**(Phase 1 → 상업, Q5E·2023 초안) · **역가**(610.10, 2011 matrix) · 무균·엔도톡신·마이코플라즈마(신속법 검증) · 안정성(동결보존·해동 후 사용 시간·운송) · 용기·냉동 체인 · **lot release 프로토콜 제안**(610.2). **Module 1**: 356h, PLR 라벨, REMS 여부, **LTFU 계획**, PMR/PMC, 추적성(1271.290 10년), 시설 목록(PAI). **Module 4**: 2013 틀(POC·생체분포·종양원성). **Module 5**: 단일군·소규모 정당화, 장기 추적.

## 6. 가속 도구, LTFU, 전임상
- **도구**: Fast Track(506(b), 60일) · BTD(506(a), 예비 임상 증거로 **상당한 개선**, 60일) · **RMAT**(506(g): RMT + 중증 + 예비 임상 증거로 **미충족 수요 가능성**, 60일; BTD 혜택 + AA·승인 후 유연) · Priority Review(6개월) · **AA**(506(c), FDORA: 확증 시험 승인 전 착수 요구 가능·6개월 보고·**506(c)(3) 신속 철회**) · **RPD → PRV**(529, 2026-02-03 재승인 → 2029-09-30) · Orphan(7년; **GT sameness 2021**: 벡터 + 전이유전자 같으면 같은 약) · **Platform(506K, 초안)** · AMT(2025-01). **BTD vs RMAT**: 둘 다 신청 흔함(각 60일); 기존 치료 있고 효과 크면 둘 다(BTD 거부돼도 RMAT 유지), 기존 치료 없음·단일군이면 RMAT 우선(FY2025 거부 22/91).
- **AA 확증 설계**: endpoint 합의(EOP2) → 확증 시험 승인 전 등록 시작(FDORA) → **506(g)(7) 레지스트리·RWE** 확증(비교군·결과·분석 사전 합의) = PMR = EU SO = HTA RWE → AA 판촉 사전 제출(601.45, 30일) → 철회 위험 시 expanded access·소통 계획.
- **LTFU(2020)**: 추적 기간은 **지연 위해 위험**에 비례 — 통합 벡터(감마레트로·렌티)·유전체 편집 **15년** / AAV 등 비통합 **최대 5년** / 비지속 제품 위험 기반 단축 / 세포 제품은 유전적 변형·지속성으로. 내용: 임상 방문 → 설문·전화, 지연 AE·악성·신경·혈액, 사망 시 부검, IND 단계부터 계획, BLA에 LTFU 프로토콜(PMR·레지스트리 가능). EU: GTMP guideline 2018·follow-up 2009(≥5년), RMP missing information·장기 PASS, 추적성 **30년**(Reg 1394/2007 Art 15). 비통합 EV·세포는 짧은 LTFU 논증 가능.
- **전임상(2013 Preclinical Assessment)** — 동종 MSC(신생아 폐): ① POC(고산소 BPD 모델, 용량 반응·경로) ② 생체분포·지속성(Alu qPCR·영상) ③ **GLP 독성**(관련 종, 임상 경로·용량 배수, 급성 주입 반응·혈전·폐 색전, 장기) ④ 종양원성·이소 조직(핵형·연한천·면역결핍 마우스) ⑤ 면역원성 ⑥ 소아 특이성(S11, 신생아 동물) ⑦ 벡터 아니면 RCR·삽입 불필요; **임상 제품과 동일 공정 로트**, 정지 규칙 도출. EU: **EMA/CAT/22473/2025**(2025-07-01, 임상단계 ATMP 통합, 위험 기반) + S6(R1).

## 7. Comparability — 2023 초안 vs 2026 성명
개발 중 변경(배지 무혈청화·자동화 폐쇄 시스템·규모·사이트)은 **효능 데이터 연결성**을 끊을 위험 → FDA는 피벗 전 공정 고정 선호. **2023-07 초안**(보수적): 전후 다수 로트·확장 특성·역가 상관, 임상 데이터 필요 가능성, 보고 카테고리 상세. **2026-01-11 성명**(유연): Phase 1 → 효능 시험 전환 시 경미 변경은 과도한 데이터 없이 수용, 승인 후 규격 재평가, 공정 검증 유연. 실무: **변경 위험 등급화 + 역가 상관 데이터 축적 + 사전 합의**(Type C / comparability protocol 601.12(e)). 상세는 P2 ⑤.

## 8. 사찰, expanded access, PDUFA VII
- **사찰**: **Team Biologics**(CBER + ORA/OII) — CPGM **7345.848**(211 + 600–680 + 610, 시스템 기반) · PAI(7346.832 틀 + CBER 제품 전문가, **OAI → CR**) · HCT/P **7341.002**(1271, 사전 통지 없이 가능) · surveillance(FDASIA 705) · 위반 → 483 → **601.5/601.6 license 정지·철회**(공중보건 위험 시 사전 통지 없이 정지) · MRA 인체용 범위 중 ATMP·CGT 적용은 EMA Q&A 확인. 준비: 공여자 기록·세포 은행·무균 공정(Annex 1 유사 기대)·DI·chain of identity.
- **Expanded access vs Right to Try(CGT 제약)**: 312.310 개별(긴급 전화 승인 → 15일 서면, Form 3926) / .315 중간 / .320 treatment IND — FDA·IRB·동의, 비용은 **312.8**(직접 비용, FDA 사전 승인); **Right to Try(2018)** Phase 1 완료·개발 중 제품을 FDA·IRB 없이 제조사 동의로, 제조사 의무 없음, 연 1회 FDA 보고. CGT: 자가는 환자별 제조 슬롯·벡터 제한, 동종은 로트 소진, 임상 공급 우선, 어떤 공정 로트인지 명시, LTFU 포함, 안전성은 312.32; Cures §3032 expanded access 방침 공개. EU: Art 83 compassionate use + named-patient; ATMP hospital exemption은 별개.
- **PDUFA VII·CBER 프로그램**: CGT FAQ(초안 2024-09 → 최종 2026-08-20) · CMC 유연성 성명 · **START pilot**(2023-09 → 2024-05 CBER 3·CDER 3 선정, 고빈도 비공식 소통) · INTERACT 확대 · RDEA pilot · FDORA: **506K Platform**(90일 응답), AMT 최종 2025-01, AA 개혁 · Cures: RMAT · RPD PRV 재승인 · OTP 재조직.

## 9. 미국 OTP vs EU CAT/CHMP
| | 미국 | EU |
|---|---|---|
| 창구 | **OTP 단일** — 분류(TRG/RFD)·IND·BLA·사찰 연계 | **CAT**(ATMP 전문위: 분류 권고 Art 17 **60일**, 평가·의견 초안) → **CHMP** → EC; 초기 ITF·PRIME |
| 분류 질문 | "351인가 361인가"(HCT/P 4기준) | "ATMP인가 생물의약품인가"(세포 함유·실질적 조작·비동종 / 재조합 핵산) |
| EV | 세포 아니어도 **351 생물의약품**, OTP | 세포·핵산 없음 → 보통 **ATMP 아님 → 생물의약품**(CHMP 단독, Part I GMP·Annex 2), CAT 분류로 확정 |
| 소통 | INTERACT 한 번에 전체 그림 | 분류 → ITF → SA 단계적 |
| 함의 | — | ATMP 여부가 **GMP(Part IV vs I)·수수료 감면·JCA 시점(2025 vs 2030)·CAT 관여**를 바꿈 → 글로벌 CMC는 더 엄격한 쪽(Part IV·Annex 1·610) 기준 |

## 11. 흔한 혼동
1. **OTAT가 현재 명칭?** 2023부터 OTP.
2. **현행 potency guidance = 2026 최종?** 기준일 이후 → 2011 + 2023 초안.
3. **Expedited RMT 현행 = 2025 초안?** 2019 최종.
4. **Phase 1 면제면 cGTP도 면제?** cGTP(1271 D)는 유지.
5. **610.2 lot release는 모든 생물의약품?** CBER 재량, CGT 다수 면제.
6. **14일 무균 시험 결과 후 출하?** 짧은 유효기간은 신속법 + 조건부 출하.
7. **LTFU는 전부 15년?** 통합·편집 15년, AAV 최대 5년, 위험 기반.
8. **INTERACT는 IND 직전?** IND-enabling 설계 전; IND 직전은 pre-IND.
9. **EV는 EU ATMP?** 보통 아님 — CAT 분류로 확정.
10. **Platform 지정은 영구?** 철회 가능(Sarepta).
