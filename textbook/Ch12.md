# Ch.12 — 원료의약품의 글로벌 등록: DMF · ASMF · CEP, 그리고 Art 46b

> **덱:** Ch12 (20장).
> **검증 메모(2026-11-23):** FDA DMF 유형(Type I 폐지), GDUFA Completeness Assessment(60일 목표), Dir 2001/83 Art 46b(2013-07-02), ICH Q3C(R9)(Step 4 2024-01-24), EDQM CEP(5년 후 1회 갱신 → 무기한, CEP 2.0 2023-09-01), ASMF 구조(CHMP/QWP/227/02 Rev 4), Q7·Q11·Q3D(R2), WHO APIMF — Ch12 덱 메모 기준.

## 학습 목표
1. 원료의약품 등록의 핵심 문제 — **제조자의 영업비밀을 신청자에게 숨기면서 당국은 보게 하는 방법** — 에 대한 세 지역의 답(DMF·ASMF·CEP)을 비교한다.
2. DMF가 **승인되지 않는다**는 사실과 GDUFA **Completeness Assessment**의 역할을 안다.
3. CEP의 수명주기(5년 → 무기한, CEP 2.0)와 **QP declaration**이 왜 따로 필요한지 설명한다.
4. **Art 46b written confirmation**, **Q7 적용 시점·Q11 starting material**, **Q3C/Q3D** 숫자를 쓴다.

## 1. 문제: 비밀은 지키고, 심사는 받게

API 제조자는 공정 상세를 완제 신청자에게 보여주고 싶지 않다. 그러나 당국은 봐야 한다. 세 지역은 각자 장치를 만들었다.

| | 미국 **DMF** | EU **ASMF** | EU **CEP** |
|---|---|---|---|
| 누가 평가 | FDA — **참조하는 신청(NDA/ANDA/IND)과 함께** | 회원국/EMA — **MAA와 함께**(EU-ASMF worksharing으로 평가 공유) | **EDQM이 독립적으로** 평가·인증 |
| 독립 결론 | **없음**(승인 아님) | 없음 | **있음**(MAA 밖에서 유효) |
| 비밀 보호 | 신청자는 **LOA(letter of authorization)** 만 받음 | **Applicant's Part(공개) + Restricted Part(당국만)**, Letter of Access | 인증서가 3.2.S 데이터를 **대체** |
| 갱신 | 없음(annual report) | 없음 | **5년 후 1회 갱신 → 무기한**(dossier 최신 유지) |

## 2. 미국 DMF (21 CFR 314.420)
- **유형**: **Type II** 원료의약품·중간체·그 제조 원료(또는 완제) · **Type III** 포장재 · **Type IV** 부형제·착색제·향료 · **Type V** FDA 승인 참조정보. **Type I**(제조소·시설·절차·인력)은 **폐지** — 시설 정보는 등록·사찰로 간다.
- **승인되지 않는다.** 참조 신청의 심사와 함께 검토되고 결론은 그 신청에 대해 내려진다. 보유자는 **LOA**로 참조 권한을 주고 신청자는 LOA 사본을 넣는다. 보유자가 공정을 바꾸면 DMF 개정 + **모든 참조자 통지** + annual report; 신청자는 영향을 평가해 **314.70 카테고리**(PAS/CBE-30/AR)로 보충 — DMF 개정이 신청자 의무를 대신하지 않는다.
- **GDUFA**: Type II API DMF는 **수수료(1회)** 를 내고 **Completeness Assessment(CA)** 를 통과해야 "**List of Type II DMFs Available for Reference**"에 오른다. CA는 **완결성 점검**이지 과학적 심사가 아니다(FDA 목표: 90%를 **60일** 내). 미통과 DMF를 참조한 ANDA는 **refuse-to-receive** 위험. 왜 이런 장치인가 — ANDA 지연의 큰 원인이 불완전한 DMF였고, "승인"을 만들지 않으면서 품질 문턱을 세운 설계다.
- **FDA는 CEP를 인정하지 않는다.** EU CEP만 있는 API를 미국에 쓰려면 공급자가 **Type II DMF**를 내거나 신청자가 **3.2.S 전체를 직접 제출**해야 한다 — 공급 계약에 DMF 제출 의무를 넣는다.

## 3. EU ASMF와 CEP
- **ASMF**(CHMP/QWP/227/02 Rev 4): **Applicant's Part**(규격·분석법·안정성 요약 등 공개) + **Restricted Part**(제조 공정 상세, 당국만). 보유자가 **Letter of Access**를 주고 당국엔 전체 제출. 모노그래프가 없는 신규·특수 API에도 쓰는 **일반 비밀보호 경로**.
- **CEP**(Certificate of Suitability, EDQM): 해당 API(또는 TSE 위험 물질)가 **Ph. Eur. 모노그래프로 품질 관리가 적절히 됨**을 인증 → MAA에서 **3.2.S 상당 부분 대체**(ASMF 불요). **최초 발급 5년 후 1회 갱신**(약 4.5년 시점 신청 권고) 후 **무기한**(dossier 최신 유지 조건), **CEP 2.0**은 2023-09-01 시행 — 갱신 시 2.0으로 전환. 보유자의 CEP 개정(revision)은 MAA variation과 연동. 모노그래프가 있고 고객이 많으면 CEP(평가 1회·재사용), 신규 물질·모노그래프 없음·공정이 범위를 벗어나면 ASMF.
- **QP declaration**: CEP는 **품질(Ph. Eur. 적합)** 을 인증하지 **GMP 준수를 보증하지 않는다**. Dir 2001/83 **Art 46(f)**(제조허가 보유자의 API GMP 준수·감사 의무)·**Art 8(3)(ha)**(MAA에 첨부하는 확인서 = QP declaration) (2026-11-28 검증)에 따라 **완제 제조·수입 허가 보유자의 QP**가 API 제조소의 GMP 준수를 선언(감사 근거)한다. CEP가 있어도 QP declaration은 따로 간다.

## 4. 제3국 API 수입 — Art 46b
**2013-07-02**부터(Dir 2011/62 falsified medicines) 제3국에서 제조된 API는 **수출국 당국의 written confirmation**(제조소별·물질별: EU 동등 GMP 적용, 정기·엄격 사찰·집행, 부적합 정보 신속 통보)이 동반돼야 EU에 수입된다. EU가 규제 체계 동등성을 인정한 **listed 국가**(Art 111b: 미국·일본·스위스·호주·브라질·이스라엘·**한국** 등)는 **면제**된다 — 그래서 **한국 API는 식약처 확인서가 필요 없다**. 확인서가 필요한 것은 목록 밖 국가(예: 중국·인도) 제조소다. 단일 중국 공급원의 위험을 비교하면 — EU는 Art 46b 확인서·Art 46(f) 감사·EudraGMDP 비준수 성명, 미국은 해외 사찰·**Import Alert**·DMF CA, 공통으로 **506C 공급 중단 보고** 위험 → 이중 공급원 자격화가 전략이다.

## 5. 글로벌 공통어 — Q7·Q11·Q3C·Q3D·M4Q
- **ICH Q7**(API GMP): **API starting material 도입 시점부터** GMP 적용, 단계가 진행될수록 엄격(Q7 표 1). starting material 지정은 **신청자 제안·당국 평가**.
- **ICH Q11**: starting material 선정 원칙 — "상업적 입수 가능"만으론 부족. 충분한 **합성 단계 수**가 GMP 하에 있어 불순물이 제거·통제되는지, starting material의 **불순물 프로파일·규격**이 API 품질에 미치는 영향, 구조적으로 **API의 의미 있는 조각**인지, 공급자 변경 통제. API 두 단계 전은 보통 "짧다"고 판단돼 질문이 온다.
- **ICH Q3C(R9)**: 잔류 용매 — Step 4 **2024-01-24**(분석법에서 **용매 휘발성** 고려 minor revision). Class 1(피할 것)/2(PDE 제한)/3(저독성: 5,000 ppm 또는 50 mg/day) 유지, Q3C(R10) 유지보수 진행 중.
- **ICH Q3D(R2)**: 원소불순물 — 납 등 **Class 1**, 준수는 원료 농도가 아니라 **완제의 1일 노출이 PDE 이하**인지로 보이고(위험평가: 원료·부형제·장비·용기 기여) 3.2.P에 쓴다; 원료 규격 한도는 그 결과.
- **M4Q 3.2.S** 구조가 세 지역 공통. **WHO APIMF**는 PQ 체계에서 ASMF를 본뜬 절차.

## 6. 세포·EV 제품에선 어디에 적용되나
전통적 API DMF 개념은 세포·EV 제품에 직접 맞지 않지만 **공정 재료**에 그대로 적용된다 — 배지·성장인자·시약의 **Type IV/II DMF**, 일회용 백·용기의 **Type III DMF**, 세포 은행 시험 CRO 정보를 LOA로 참조. EU는 공급자 ASMF·CEP(동물 유래 물질 **TSE CEP**)로 대응하고, 공급자 변경은 comparability·variation 이슈가 된다(P2 ⑤).

## 8. 흔한 혼동
1. **DMF 승인?** 안 된다. "참조 가능 목록"은 CA 통과이지 승인이 아니다.
2. **CEP가 있으면 GMP도 끝?** 아니다. QP declaration은 별도.
3. **CEP 갱신 주기 5년마다?** 아니다. 5년 후 **1회** 갱신 후 무기한.
4. **Type I DMF** — 폐지됐다.
5. **FDA가 CEP 받나?** 안 받는다.
6. **Art 46b 확인서를 누가 발급?** **수출국 당국**(예: 중국·인도 당국). **한국을 포함한 Art 111b listed 국가는 면제**다 — "한국 API = 식약처 확인서"는 틀린 답.
7. **Q3D 한도는 원료 농도?** 아니다. 완제 1일 노출 PDE.
8. **starting material = 상업적 입수 가능 물질?** Q11은 그것만으론 부족.
