# Phase 2 ② — HCT/P 분기(PHS 361 vs 351): 조작 정도와 기능 동일성이 "조직 이식"과 "의약품"을 가른다

> **덱:** P2_351vs361 (20장). Phase 2 특화 주제 2/6.
> **검증 메모(2026-11-22):** FDA **enforcement discretion 종료 2021-05-31** → 고위험 우선 집행(동종·정맥·관절강·비동종); *Minimal Manipulation and Homologous Use* 최종 **2017-11**(2020-07 갱신); **exosome/EV = PHS 351 미승인 생물의약품**(2019-12 통지, **WL 12건(2025-10)**, 승인 **0**); RFD 60일; RMAT 범위에서 361 단독 HCT/P 제외 — 덱 메모 기준. 1271.3(d)·1271.10(a)·1271.15·1271.20·Subparts B–F(등록 5일·공여자 검체 7/30일·1271.90 라벨·추적 10년·1271.350 15/45일·1271.440)·PHS 361·TRG·판례(Regenerative Sciences 2014, US Stem Cell 2021)·제대혈 BLA 2011-10-20·Dir 2004/23·Reg 1394/2007 Annex I·**SoHO Reg 2024/1938(2027-08 적용)** 은 ○. ## 학습 목표
1. **1271.3(d)** HCT/P 정의와 **제외 목록**(혈액·분비물·장기·동물·IVD)을 안다.
2. **1271.10(a) 4기준**(최소 조작·동종 사용·비결합·비전신/비대사 또는 자가·혈족·생식)을 사례에 적용하고, **1271.15(b)** 같은 수술 예외의 범위를 안다.
3. 361 시설의 **Subpart B–F 의무**(등록·공여자 적격·cGTP·보고·명령)와 "351 제품에도 C·D는 적용"을 쓴다.
4. 분류 도구(**TRG vs RFD vs pre-IND**), **2017–2021 유예와 집행 자세**, 오분류의 법적 결과를 안다.
5. EU **Dir 2004/23 vs Reg 1394/2007(Annex I)·SoHO 2024/1938**과 비교하고 **EV가 양쪽 어디에도 "조직"이 아닌 이유**를 설명한다.

## 1. 361 경로의 논리
**PHS 361(42 USC 264)** = **전염병의 주간·국제 전파 방지** 권한 → 1271 전체의 근거. 그래서 361 HCT/P는 **시판 전 심사·효능·안전 입증 없이** 유통되되 의무가 전염병 방지에 맞춰져 있다: **등록·목록(B), 공여자 적격(C), cGTP(D), 보고·라벨(E), 사찰·명령(F)**. 생략이 정당한 것은 **국소적·구조적 대체**(골·피부·인대 — 물리적·예측 가능)뿐이다. **전신 효과**나 **살아있는 세포의 대사 활성에 의존하는 1차 기능**(조혈 재구성·호르몬 분비)은 변동성·면역·전파·용량 문제가 커서 351 심사가 필요 → 예외는 **자가**(면역·전파 위험 최소), **1·2촌 혈족**(적합성·노출 공유·골수 전통), **생식용**(생식 의료 체계) 세 가지. 함의: **동종 비혈연 세포 제품은 거의 항상 351**, 자가라도 **최소 조작·동종**은 별도 통과.

## 2. 정의 — 1271.3(d)
**HCT/P** = **인체 세포·조직을 함유하거나 그로 구성**되어 사람 수혜자에게 **이식·주입·전달·전이**되는 물품(골·인대·피부·경막·심장판막·각막·조혈 줄기/전구세포·조작 세포·생식 세포·췌도). **제외**: ① 혈관화 사람 장기(HRSA/OPTN) ② **전혈·혈액 성분·혈액 유래 제품**(→ **PRP**·혈소판·혈장은 혈액 규정·기기) ③ **분비물·추출물**(모유·콜라겐·세포 인자 — **정액은 HCT/P**) ④ 최소 조작 골수(같은 수술 등 조건) ⑤ 동물 유래(이종) ⑥ in vitro 진단 ⑦ 혈관 일부. 정의 밖이면 1271 자체 비적용.

## 3. 4기준 — 1271.10(a)
| 기준 | 내용 |
|---|---|
| ① **최소 조작** | **구조 조직**(골·피부·양막·지방): 재건·수선·대체 관련 **원 특성(original relevant characteristics)** 불변 — 절단·분쇄·형상화·탈회(일부)·동결 = 최소 / **지방 효소 분해 SVF**(쿠션·구조 파괴), 양막 탈세포·분말화(장벽·쿠션 상실) = 초과. **세포·비구조 조직**(조혈세포·정자·췌도): **관련 생물학적 특성** 불변 — 선별·농축·원심분리·동결보존·항생제 세척·밀도 구배 = 최소 / **배양 확장·활성화·분화 유도·유전자 변형·효소 처리** = 초과. 판단은 **공정이 특성에 미친 효과**(의도 아님), 같은 공정도 조직 유형 따라 결론 다름 |
| ② **동종 사용** | 수혜자에서 공여자와 **같은 기본 기능**(장벽·쿠션·구조 지지·조혈 재구성)으로 수선·재건·대체·보충 — **같은 해부학적 위치일 필요 없음**(피부로 다른 부위 피복 = 동종). 양막 상처·화상 피복 = 동종 vs **양막·양수 관절·연골·건 주사 = 비동종** / 피부 피복 = 동종 vs 피부 세포 심근 재생 = 비동종 / 조혈세포 조혈 재구성 = 동종 vs 심장·신경 질환 = 비동종 / 지방 연부 조직 충전 = 동종 vs 관절염·당뇨 = 비동종. 판단은 **라벨·광고·객관적 의도** — "줄기세포 치료" 광고 자체가 비동종 의도 증거 |
| ③ **비결합** | 다른 물품과 결합 없음 — 예외 **물·크리스탈로이드·살균·보존·저장제**(새 임상 안전 우려 없을 때) |
| ④ **(i)** 전신 효과 없고 1차 기능이 살아있는 세포 **대사 활성에 의존하지 않음** **또는 (ii)** 의존하더라도 **(a) 자가 / (b) 1·2촌 혈족 동종 / (c) 생식용** | — |

네 기준 **전부** 충족 → 361 HCT/P(1271만). 하나라도 미충족 → **1271.20**: 의약품·기기·**351 생물의약품**으로 규제(IND·BLA) + **1271 Subpart C·D 계속 적용**.

## 4. 1271.15(b) — 같은 수술 예외
자가 HCT/P를 **같은 수술 절차 중** 회수·이식하고 처리가 **세정·세척·크기 조정·형태 조정(rinsing, cleansing, sizing, shaping)** 에 한정 → **1271 전부 비적용**(진료 행위). 자가 지방을 세척·크기 조정 후 같은 수술에서 유방에 이식 = **면제**. **단순 농축 기기**(원심분리)는 2017 same-surgical-procedure guidance상 해석 가능(원 특성 유지), 그러나 **효소·세포 분리·배양**이면 면제 상실(기기는 별도 510(k)/De Novo 가능). **보관 후 다른 세션 이식** = 같은 수술 아님 → 면제 상실 → 1271 적용 → 4기준: 자가·최소 조작·동종(연부 조직 충전)이면 **361로 등록·cGTP**(공여자 적격은 자가 면제 1271.90, 라벨 "FOR AUTOLOGOUS USE ONLY"·"NOT EVALUATED FOR INFECTIOUS SUBSTANCES"). 예외는 **좁게**.

## 5. 361 시설의 의무 — Subpart B–F
| Subpart | 의무 |
|---|---|
| **B 등록·목록**(1271.21–.25) | 영업 개시 **5일 내** Form **3356**(eHCTERS) + HCT/P 목록(361 주장 여부), **매년 12월** 갱신, 변경 **6개월 내**, 소유·소재 변경 즉시 → 사찰 대상 등재(7341.002, 사전 통지 없이 가능) |
| **C 공여자 적격**(1271.45–.90) | 모든 HCT/P(361·351 공통). **책임자**가 스크리닝(병력·위험 요인·TSE/vCJD·여행 WNV·지카, 신체) + 시험(**HIV-1/2, HBV(HBsAg·anti-HBc), HCV, 매독** + 백혈구 풍부 제품 **HTLV-I/II·CMV** + 생식 **클라미디아·임질** + WNV·세균) 후 적격 판정. **검체 시점(1271.80(b)): 회수 전후 7일**, 말초혈 조혈·골수·난자 공여자는 **30일 전**까지. **예외(1271.90)**: 자가, 성적 파트너 생식, 혈족 일부, 긴급 — 라벨 "**FOR AUTOLOGOUS USE ONLY**", 미시험 시 "**NOT EVALUATED FOR INFECTIOUS SUBSTANCES**", 양성 시 경고 문구. 기록 10년 |
| **D cGTP**(1271.145–.320) | 품질 프로그램(1271.160)·인력·절차·시설·환경·장비·공급품·공정 통제·회수(1271.270)·라벨·보관·수령·배포·**추적성 10년(1271.290)**·불만 — 전염병 전파 방지 목적(211 아님) |
| **E 보고·라벨** | **유해 반응 15일**(전염병 관련 치명·생명위협·영구 장애·개입, Form 3500A, 1271.350(a)) / **deviation 45일**(핵심 cGTP·공여자 요건 위반 배포 제품, Form 3486, 1271.350(b)) / 라벨 1271.370(식별 코드·보관·유효기간·적격 요약·문구) |
| **F 사찰·집행** | **1271.400** 사찰, 수입 억류(1271.420), **1271.440 명령 — retention·recall·destruction·cessation of manufacturing**(통지·청문, 긴급 시 즉시); 형사 PHS 368 |

**없는 것**: 시판 전 승인·효능 입증·BLA 수수료·PV(314.80). **첫해 달력**(3/1 개업): ≤3/6 등록·목록 → 12월 갱신 → 변경 6개월 내 → cGTP 품질 프로그램·공여자 SOP·추적 시스템·불만 파일·회수 기관 계약·감사 → 15일/45일 보고 체계 → Part 7 자발 리콜 + 1271.440 가능.

## 7. 분류 도구와 순서
| 도구 | 성격 |
|---|---|
| **TRG**(CBER·CDRH 합동) | **비공식·비구속** 권고 — 361 기준 적용 여부, 수주~수개월, 무료, 연간 공개 요약; **관할(기기 vs 생물) 결정은 아님**; TRIP(2019~) 한정 운영 |
| **RFD**(Part 3, OCP, **60일** 구속) | **PMOA** 기반 센터 배정·조합 제품 여부, ≤15쪽, 데이터 요구 가능 |
| **pre-IND**(Type B 60일) | 분류 확정 뒤 개발 계획 |

탈세포 스캐폴드 + 동종 공여 세포 접종·배양: 배양 초과 + 비혈연 대사 의존 → 361 불가 → 351 또는 조합 → ① 내부 4기준 평가 문서화 ② **RFD**로 PMOA·주관 센터 ③ INTERACT/pre-IND ④ TRG는 361 가능성이 진짜 있을 때만. EU 병행: CAT ATMP 분류(Art 17, 60일 — TEP/combined).

## 8. 집행 — 유예 종료와 그 뒤
- **2017-11 종합 틀**(4 guidance)이 기준을 명확화 → 수백 클리닉(자가 SVF·골수 농축)이 351로 판명 → **36개월 유예**(2020-11 → 코로나 연장 **2021-05-31**), 고위험(동종·정맥·중추신경·안구·비동종)은 즉시 집행. 결과: 전환 소수, 폐업·소송(**US Stem Cell 2021** FDA 승소; 판례 흐름 복잡), WL·untitled·금지명령 다수, 2019 exosome 통지.
- **2021 이후 자세**: ① **위험 기반 우선순위** — 동종, 투여 경로(IV·관절강·척수강), 비동종 광고 ② **"practice of medicine" 항변 불인정**(제조 행위; **Regenerative Sciences, D.C. Cir. 2014**: 배양 MSC = 의약품·생물의약품, 211 적용) ③ 광고 = 의도 증거.
- **오분류의 결과**: 미허가 생물(351(a)) + 미승인 신약(505(a)) → **301(a)/(d)** → WL·**금지명령**·압류·형사(303); IND 없음 → 50/56 위반; 광고 misbranding; 주 의료위 징계; 1271 C·D 위반은 별도 483. 자가라도 최소 조작·동종 미충족이면 동일.
- **정당한 개발자 함의**: 361 주장은 4기준 전부 **문서로**(TRG 권장), 아니면 IND; 임상 데이터 없는 상업화 금지 → RMAT·AA 등 합법 가속 경로; IND 번호·IRB로 클리닉과 차별화; **EV는 361 논증 자체가 없음 → 처음부터 351**.

## 9. EU — 조직·세포 vs ATMP
- **Dir 2004/23/EC**(+2006/17·2006/86): 인체 조직·세포의 **기증·채취·시험·처리·보존·보관·분배** 품질·안전 — **조직 기관(tissue establishment) 인가·사찰**, 공여자 선정·시험, 추적성 30년, 중대 이상 반응 보고, SEC 코드; 의료 행위·장기(2010/53)·혈액(2002/98)은 별도. **SoHO Regulation 2024/1938**: 2024 채택, **2027-08 적용**, 2004/23·2002/98 대체.
- **경계**: 조직·세포가 **(a) 실질적 조작** 또는 **(b) 비동종 기능**이면 **ATMP**(Reg 1394/2007 Art 2: sCTMP·TEP) → 중앙 승인(CAT/CHMP), Part IV GMP. **Annex I 비실질적 조작 목록**(이것만이면 ATMP 아님): 절단·분쇄·형상화·원심분리·항생제/항균 침지·멸균·방사선·**세포 분리·농축·정제**·여과·동결건조·냉동·동결보존·유리화. 배양 확장·활성화·유전자 변형 = 실질적. **Hospital exemption**(Art 28 → Dir 2001/83 Art 3(7)): 비일상·맞춤 ATMP 병원 제조(국가 승인) — 미국엔 없음.

### 미국 vs EU
| 축 | 미국 361/351 | EU 조직/ATMP |
|---|---|---|
| 공통 논리 | 조작 정도 + 기능 동일성 → 배양·유전자 변형·비동종은 양쪽 모두 **의약품** | |
| 열거 방식 | 정의 + guidance 사례 | **Annex I 양성 목록** |
| 추가 기준 | **비결합·비전신/비대사(또는 자가·혈족·생식)** → 동종 비혈연 조혈세포 = **351 BLA** | 최소 조작·동종이면 **조직·세포 체계**(제대혈 은행 인가) |
| 승인 | 351 BLA(CBER) | ATMP는 **중앙 + CAT** |
| 특례 | — | **Hospital exemption** |
| 집행 | FDA 연방·판례 | 회원국 인가·국가 집행 |
| EV | 1271.3(d) 분비물 제외 → **351 직행** | ATMP 정의 밖 → **생물의약품**(CAT 분류) |

개발자 함의: 더 엄격한 분류(의약품)로 설계, 공여자 적격은 **1271 Subpart C + Dir 2004/23** 둘 다, SoHO 2027 전환 추적.

## 11. 흔한 혼동
1. **PRP는 HCT/P?** 혈액 유래 — 제외.
2. **자가면 361?** 최소 조작·동종도 통과해야(SVF 사례).
3. **같은 수술 예외에 효소 분해 포함?** 아니다 — 세정·세척·크기·형태만.
4. **351로 분류되면 1271은 안 본다?** Subpart C·D는 계속 적용.
5. **TRG 답변은 구속?** 비구속; 구속은 RFD.
6. **동종 비혈연 제대혈은 361?** 351 BLA(2011).
7. **양막 관절 주사는 동종?** 비동종(상처 피복만 동종).
8. **EV는 361 HCT/P?** 분비물 제외 → 351.
9. **EU에서 EV는 ATMP?** 보통 아님 — 생물의약품.
10. **2004/23이 현행 끝까지?** SoHO 2024/1938이 2027-08부터 대체.

## 12. 네 분야에 올려놓기
**태반 유래 EV를 미국 "361 최소 조작", EU "조직 제품"으로** 내려는 계획은 둘 다 틀린 자리다. 미국: ① EV는 1271.3(d) 분비물·추출물 → HCT/P 정의 밖 ② 설령 세포·조직 제품이라도 분리·농축·배양 = 초과, 폐 질환 = 비동종, 동종 비혈연 ③ FDA exosome = 351 공표 → **IND·BLA**: 태반 공여자 **1271 Subpart C**(산모 스크리닝·시험), 조직 채취는 2004/23 상당 기준, 세포 은행·EV 공정(211/600/610), MISEV2023 특성화, 역가 대리지표, 전임상(2013), INTERACT → pre-IND → IND, 지정(orphan·RPD·예비 임상 후 RMAT — RMT 해당성 논증, 2025-09 초안 범위 확대 참고). EU: EV는 2004/23의 '조직·세포'가 아님 → Dir 2001/83 Art 1(2) 의약품 → **생물의약품**, ATMP 아님 → **CAT 분류 권고(Art 17, 60일)** 로 공식 확인 → 중앙 절차 의무(생물공학 공정), GMP Part I + Annex 2, 원료 태반은 2004/23 기증·채취 + 조직 기관. 공통: 하나의 공여자 적격·세포 은행·특성화 패키지, EU PRIME·ITF, 미국 RMAT, 글로벌 Phase 1/2.
