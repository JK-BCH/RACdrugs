## 1. RMAT — 법과 혜택
| 항목 | 내용 |
|---|---|
| 근거 | **21st Century Cures Act 2016 §3033 → FD&C 506(g)** |
| 요건 ① | **Regenerative medicine therapy** — 세포치료·치료용 조직공학 제품·HCT/P·그 조합(2019: **유전자치료**도 지속적 세포 변화 유도 시 포함, 종양용해 바이러스는 케이스별); **PHS 361 단독 HCT/P 제외**, 기기 단독 제외 |
| 요건 ② | **중증·생명 위협** 질환을 치료·수정·역전·치유 |
| 요건 ③ | **예비 임상 증거**가 **미충족 의료 수요 해결 가능성** 시사 |
| 요청·결정 | IND와 함께 또는 IND 수정; FDA **60일**(506(g)(3)) |
| 혜택(506(g)(4)–(8)) | **BTD 전부**(집중 지도·조직 약속·rolling·우선 심사 자격) + **AA 자격 명시**(surrogate/**intermediate clinical endpoint**, 소수 사이트·단일군 수용 가능성) + **506(g)(7)** 승인 후 요건을 **대규모 확증 데이터셋·환자 레지스트리·RWE(EHR)·승인 전 시험 환자 추적**으로 충족 가능 |
| 아닌 것 | 승인 기준 완화 아님(substantial evidence 유지), 심사 기간 자동 단축 아님, **철회 가능** |
| 통계 | FY2025 91/50/22/3; 누적 ~370/184; 승인 13 — **지정 ≠ 승인** |

**BTD vs RMAT 문턱**: BTD는 비교 대상이 **기존 치료**(상당한 개선 — 대조·역사적 대조·극적 효과 필요; 기존 치료 없으면 오히려 쉬움), RMAT는 **미충족 수요**(기존 치료 한계를 해결할 가능성이면 충분, 효과 크기 요구 낮음, 단일군·소수 수용) → 부여율 높고(FY2025 55%) 시점 앞당겨짐 → **둘 다 신청**(BTD 거부돼도 RMAT 유지), RMAT 고유 혜택(AA endpoint·레지스트리)이 **승인 설계**를 바꿈 = 지정 전략 = 승인 전략. 부작용: 지정 급증 → FDA 자원 경쟁, 신호 가치 하락(13/184).

## 2. 비교표와 요청 실무
| 도구 | 요건 | 시점 | 시계 | 혜택 |
|---|---|---|---|---|
| **Fast Track**(506(b)) | 중증 + 비임상·임상으로 미충족 수요 가능성 | IND 후 언제든 | 60일 | rolling·빈번 소통 |
| **BTD**(506(a)) | 중증 + 예비 임상 증거로 **상당한 개선** | EOP2 전 | 60일 | 집중 지도·조직 약속·rolling |
| **RMAT**(506(g)) | RMT + 중증 + 예비 임상 증거로 **미충족 수요 가능성** | IND와 함께/수정 | 60일 | BTD 혜택 + AA·승인 후 유연 |
| **Priority Review** | 안전·효능 상당한 개선(또는 PRV) | BLA 제출 | filing 60일 내 지정 | 심사 **6개월**(원 BLA는 filing부터 → 총 8개월) |
| **AA**(506(c)) | 중증 + 의미 있는 이점 + surrogate/intermediate가 임상 편익을 합리적으로 예측 | EOP2 합의 | 승인 조건 | **FDORA**: 확증 승인 전 착수 요구 가능·6개월 보고·506(c)(3) 신속 철회 |

- **요청 시점**: 예비 임상 증거 직후(Phase 1/2 초기 — 소수라도 임상적으로 의미 있는 결과); 너무 이르면(비임상만) 거부, 너무 늦으면(EOP2 후) 혜택 축소. **패키지**(2019): ① RMT 근거(361 아님) ② 중증성 ③ 예비 임상 증거 요약(설계·환자 수·결과·안전) + **왜 미충족 수요를 해결**하는지(기존 치료 한계) ④ 개발 계획. **거부 사유**(FY2025 22/91): 증거 부족·해석 불가(단일 사례·대조 없음·바이오마커만·효과 미미), RMT 밖(361·기기·소분자), 중증 아님, IND와 분리. 거부 후 재요청 가능, Fast Track 병행.
- **철회(rescission)**: Phase 2 1차 endpoint 실패 등 기준 미충족 시 FDA 취소(목록 공개) 또는 자발 철회 → BTD형 혜택·AA/506(g)(7) 전제 상실, IND·기존 합의는 유효(재확인). 대응: 서면 응답(하위집단·2차 endpoint·바이오마커로 가능성 재논증), 새 데이터 후 **재요청**(제한 없음), Fast Track 유지 확인, 투자자 공시, 판촉·웹에서 "RMAT" 제거. BTD도 동일 논리로 rescission(2014 guidance), EU PRIME도 철회 가능.

## 3. AA — FDORA와 506(g)(7) 레지스트리 확증
- **설계**: ① EOP2에서 intermediate endpoint(예: 6개월 기능 점수)가 장기 편익을 합리적으로 예측한다는 근거(질병 생물학·자연사·바이오마커 상관), RMAT로 소수 사이트·단일군 수용 논의 ② **FDORA 506(c)**: 확증 시험 **승인 전 착수** 요구 → 확증 설계(무작위 또는 **506(g)(7) 레지스트리·RWE** — 비교군·결과·분석 사전 합의), 마일스톤 승인서 기재, **6개월 진척 보고**, 506B 연례 ③ 라벨 AA 표기 ④ **판촉 사전 제출**(601.45: 승인 후 120일 내 쓸 자료는 승인 전 심사 기간 중 제출, 그 이후 자료는 첫 사용 ≥30일 전) ⑤ **LTFU**(2020, 통합 벡터 15년)를 레지스트리에 통합 ⑥ EU **CMA**(SO = 같은 확증 연구, 1년 갱신) — 하나의 레지스트리로 두 의무 ⑦ 지불자 CED·OBA.
- **왜 의회는 레지스트리·RWE를 허용했나**: CGT 표적은 희귀·중증·대안 없음, 1회 투여·내구 효과 → 무작위 확증이 비윤리적·비현실적(교차·위약 불가, 환자 수 부족). **위험**: 비교군 부재(자연사·외부 대조 편향), 결과 측정 불균일, 추적 손실, surrogate + 약한 확증 = 철회 지연(FDORA 신속 철회가 보정), 지불자 불신(CED·MEA). **EU CMA**: specific obligation + **1년 갱신**(연간 B/R 재확인) → 미국보다 갱신 압력 강함, 레지스트리 수용은 PRAC/CAT 합의 시(PASS·AbD). 해법: 승인 전 **레지스트리 프로토콜 사전 합의**(FDA·PRAC·HTA), 핵심 결과 표준화, 독립 모니터링.
- **확증 실패 시 506(c)(3)**: ① 철회 의도 통지 ② 회의 기회 ③ 서면 이의 ④ 자문위(요청 시) ⑤ 공개 의견(≥30일) ⑥ 최종 결정·사유 공개 — 종전 Subpart H 청문보다 빠름(수개월). 병행: 라벨·DHCP, 신규 투여 중단, 기존 환자 expanded access·LTFU, 레지스트리 유지, 지불자 통지(MEA). EU: CMA 갱신 거부 또는 Art 116, PRAC·CAT, Art 123(2) 통지. 소통: 동시·일관(환자·HCP·투자자·규제), 재개발 옵션, 법무 협업(III-6).

## 5. EU·일본·영국 대응물과 글로벌 계획

| **일본** | **재생의료등제품**(PMD Act 2014): **조건·기한부 승인**(소규모 시험으로 유효성 추정·안전 확인 → 승인, **기한 최대 7년** 내 확증 → 정규/철회) · **SAKIGAKE**(2015 시범 → 2020 법제화: 우선 상담·6개월 심사) · PMDA 사전 면담 |
| **영국** | ILAP(2021) |

대응: PRIME ≈ BTD/RMAT, CMA ≈ AA, EU AA ≈ Priority Review. **글로벌 계획(동종 MSC, 중증 폐질환)**: 미국 orphan → INTERACT → pre-IND → IND → 예비 증거 후 RMAT ± BTD, FT 병행 → EOP2 AA(surrogate/intermediate) + FDORA 확증(레지스트리) → Priority BLA(소아면 RPD) / EU ITF → CAT 분류 → PRIME → SA → CMA(SO = 미국 확증과 동일) 또는 정규, AA 150일, ATMP면 CAT·PASS·RMP / 일본 재생의료등제품 → SAKIGAKE 또는 조건·기한부. 공통: 하나의 피벗 + 레지스트리로 세 지역 확증, surrogate를 세 당국과 합의(EOP2·SA·PMDA), CMC comparability 동기화, 지정은 조건부.

**CAR-T(희귀 소아 백혈병) 스택 순서**: ① orphan(316, <200,000; 7년·수수료·세액공제; sameness) ② **RPD**(529, 승인 전 → PRV, 2029-09-30까지) ③ INTERACT 75 → pre-IND 60 → IND 30(210.2(c)) ④ 예비 증거 후 **RMAT** ± BTD ⑤ EOP2 AA endpoint(완전 관해율 → intermediate) + FDORA 확증 ⑥ BLA: Priority 6개월 또는 PRV, rolling, **LTFU 15년**, REMS(CRS·신경독성), PAI ⑦ 승인 후 PMR 레지스트리·506B·orphan PREA 면제 ⑧ EU orphan(10년+2)·PRIME·ATMP·CMA·PIP.

## 6. RMAT 숫자를 읽는 법
급증 원인: 파이프라인 성숙(CAR-T·AAV·편집 후속 세대), CBER 친CGT 자세(FAQ·CMC 유연성·START·2025 초안 3종), 낮은 문턱 + 투자 신호, 희귀질환 집중(RPD PRV). **승인 13/184 ≈ 7%**: 지정은 초기 단계에서 주어지고 CGT 개발 실패·자금·CMC 지연이 흔함 → 지정은 **승인 예측자가 아니라 소통 특권**. FDA 자원 부담 → 응답 질 우려. **활용법**: 지정 직후 **로드맵 회의**(CMC·endpoint·AA·레지스트리)로 혜택을 실제 결정으로, 예비 증거가 흔들리면 철회 대비, 지정을 **마케팅 문구로 쓰지 않음**, PRIME·SAKIGAKE와 동기화, 회의 수·CMC 이슈 해소 시간으로 혜택 측정.

## 8. 흔한 혼동
1. **RMAT = BTD?** 문턱(미충족 수요 vs 상당한 개선)·혜택(506(g)(7)) 다름.
2. **361 HCT/P도 RMAT?** 제외.
3. **RMAT 받으면 승인 기준 완화?** substantial evidence 유지.
4. **RMAT가 우선 심사 자동?** 자격만; 지정은 BLA 때 별도.
5. **2025 초안이 현행?** 2019 최종.
6. **Platform 지정은 영구?** Sarepta 철회.
7. **AA 확증은 반드시 RCT?** RMAT는 레지스트리·RWE 가능(506(g)(7)).
8. **506(c)(3) 철회는 청문?** 통지·회의·이의·자문위·공개 의견.
9. **PRIME = AA?** PRIME ≈ BTD/RMAT; CMA ≈ AA.
10. **지정 = 승인 가능성?** 13/184.

## 9. 네 분야에 올려놓기
**MSC-EV(BPD)의 RMAT 적격 논증**: 506(g) 정의는 세포치료·조직공학·HCT/P·조합 — EV는 세포가 아니지만 **세포 유래·세포 기능 매개(paracrine)** 제품으로 "재생·수선" 의도 → 2019 guidance는 범위를 케이스별로, 2025-09 초안은 **범위 확대** → 요청서에 ① 제조·작용이 세포치료의 연장(모세포 기능 전달) ② 조직 수선·재생 기전(폐포 발달·염증 조절) ③ 361 아님(351) 명시; FDA가 RMT 아니라고 보면 **Fast Track·BTD**로 대체(AA는 506(c)로도 가능). 중증성·미충족 수요: BPD = 조산아 만성 폐질환, 승인 치료 없음. 예비 임상 증거: Phase 1/2 신생아 데이터(산소 의존·BPD 중증도·호흡기 입원) 후 요청. **스택**: orphan + **RPD → PRV**(2029-09-30 전) + RMAT + AA(surrogate/intermediate: 36주 PMA BPD 중증도) + FDORA 확증(**신생아 레지스트리** = PMR = EU SO = HTA RWE) + Priority. EU: CAT 분류(생물의약품 가능성) → PRIME → CMA + PIP. 일본: 소아 가산·조건부. 병목 = EV 역가·comparability(P2 ④·⑤).
