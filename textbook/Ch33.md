# Ch.33 — 리콜: 미국은 "규제된 자발", EU는 당국 권한 → MAH 의무 → GMP 절차 세 층, 그리고 네 개의 시계

> **덱:** Ch33_1(개념·구조) + Ch33_2(세부·상황형), 40장. 이틀 분량 한 장.
> **검증 메모(2026-11-22):** FDA *Initiation of Voluntary Recalls Under 21 CFR Part 7, Subpart C* 최종 **2022-03-04**(recall-ready, 조사 완료 기다리지 말 것); *Public Warning and Notification of Recalls* 최종 **2019-02**; **PHS 351(d)(2)** licensed 생물의약품 imminent/substantial hazard → **즉시 회수 명령**(1986 NCVIA, 민사벌금 **일당 최대 $100,000**); EU **Rapid Alert** Class I 국가 조치와 **동시** / II **24시간** / III **미해당**; **DSCSA** 2025-05-27 제조·08-27 도매·11-27 대형 dispenser, 소형 dispenser **2027-11-27**(2026-08 연장); **ESMP** 2025-01-29 가동·**2025-02-02 의무** — 두 덱 메모 기준. 7.3·7.3(m)·7.40–7.59, mandatory recall 근거 목록, 806 10 working days, FAR 3 working days, BPDR 45일, OII 2024-10-01, DSCSA 582 24시간(Form 3911), Dir 2001/83 Arts 117·116·123(2)·117a·81·23a, Ch.8(2015-03-01), 2016/161(2019-02-09), Reg 2022/123, WHO GSMS, 7.41·7.49·7.53·7.55, 806.1(b), 1271.350 15/45일, CTR Art 52·54 7일, 나이트로사민 2020-09/Rev 1 2021-02, Art 5(3) 2020-06, 506C(j), 801(e)는 ○.

## 학습 목표
1. **7.3 정의·Class I/II/III·HHE(7.41)·전략(7.42: depth·공중 경고·effectiveness A–E)** 와 **7.46→7.49→7.53→7.55** 문서 생애를 쓴다.
2. **mandatory recall 근거**(351(d)·518(e)·1271.440·569D…)와 "일반 의약품엔 없음", **7.45 FDA-requested**, 자발이 사실상 강제인 이유를 안다.
3. 리콜과 별도로 도는 **네 시계**(FAR 3 / BPDR 45 / 806 10 / DSCSA 24h)와 **1271.350·CTR Art 52/54**를 배정한다.
4. EU **Art 117/116/117a·123(2)/81/23a·Ch.8·Rapid Alert**와 **supervisory authority·EMA(CAP)** 흐름을 쓴다.
5. **추적성(DSCSA vs 2016/161)·공급 부족(506C·ESMP·MSSG)·글로벌 조율·법적 기록**을 설계한다.

## 1. 미국 — 21 CFR Part 7 Subpart C
### 1.1 정의 (7.3)
| 용어 | 뜻 |
|---|---|
| **Recall** | FDA가 법적 조치(압류 등)를 취할 수 있는 **위법(violative) 제품**의 **제거(removal) 또는 현장 교정(correction)** — 분류·Enforcement Report 공개. **재라벨·유효기간 단축 통지도 correction = 리콜** |
| **Market withdrawal** | 위법 아니거나 **경미해서 법적 조치 대상 아닌** 사유 — 분류·공개 없음 |
| **Stock recovery** | **제조자 직접 통제 하** 미유통 제품 회수 — 리콜 아님 |

### 1.2 등급 (7.3(m)) — HHE(7.41)가 정한다
| Class | 정의 | 예 |
|---|---|---|
| **I** | **중대 건강 피해·사망의 합리적 확률** | 주사제 무균 실패·엔도톡신, 라벨 강도 오류 과량, 위조 성분 |
| **II** | **일시적·의학적으로 회복 가능한 피해**, 중대 피해는 **희박** | 용출 OOS, 나이트로사민 허용치 초과, 안정성 실패 |
| **III** | **건강 피해 가능성 낮은** 위법 | 안전 무관 라벨 인쇄 오류, 품질 무관 용기 결함 |

**HHE 요소**: 이미 발생한 피해 / 취약 집단(소아·고령·수술·면역저하) 노출 / 집단별 심각도 / 발생 가능성 / 즉시·장기 결과 → **센터 의학 평가로 Class 결정**. 등급은 결함 유형이 아니라 **결과 확률** — 용출 OOS가 항경련제면 I, 비타민이면 III; 라벨 강도 오류가 인슐린이면 I, 완하제면 III; 엔도톡신이 척수강 내면 I. 회사의 HHE 품질이 분류 협상의 유일한 무기. **회사는 분류 전에도 개시**(2022 guidance).

### 1.3 전략 (7.42)
① **Depth** — consumer/user · retail · wholesale ② **Public warning** — 중대 위험 + 소비자 수준 유통 + 다른 수단으로 닿기 어려울 때(대개 Class I; **2019 guidance**: 회사가 보도자료·웹 공지를 FDA 검토 기다리지 말고 신속히, 평이한 언어·사진·로트·행동·MedWatch, 홍보 금지; 안 하면 **FDA가 직접**) ③ **Effectiveness checks** — **A 100% / B >10%~<100% / C 10% / D 2% / E 없음**(Class I은 보통 A).

### 1.4 문서 생애
**7.46** 개시 → FDA **즉시** 통지(제품·로트·수량·유통·사유·HHE·전략·통신문 초안; **OII 리콜 조정관**, 2024-10-01 ORA 개편) → 센터 HHE·분류 → **7.49 통신문**(상단 굵게 **"URGENT: DRUG RECALL"**, 제품·NDC·로트·유효기간·사진, 사유·위해, 구체적 조치·sub-recall 지시, **응답 수단**, 홍보 금지; FDA 검토 안 기다림) → **7.53 상태 보고**(FDA 지정, 통상 **2–4주**: 통지 수신처 수·일시·방법, 응답·미응답, 회수·교정 수량, effectiveness 결과, 완료 예상) → **7.55 종결**(FDA가 합리적 노력·제거/교정 완료 판단, 회사 요청 가능, 서면; 수량 대조 출하−회수−소진, 처분 기록, CAPA 효과성) → **Enforcement Report**(주간; 분류 대기도 "not yet classified" 게재). **2022 guidance**: recall-ready(훈련·연락 계획·코딩·유통 기록), 조사 완료 기다리지 말고 개시, 전자 통신.

### 1.5 FDA-requested(7.45)와 mandatory recall
- **7.45 요건 셋**: 건강 위험(또는 중대 위법·사기) + 회사 미개시 + 기관 조치 필요 → 센터 승인 서면 요청(위법·HHE·등급·권고 전략·응답 요구). 수용 → 7.46 절차; 거부 → 압류·금지명령·직접 공중 경고·WL·(생물) 351(d). Enforcement Report "FDA requested". 협상은 **등급·depth·문구**에서.
- **Mandatory recall 근거**: 기기 **518(e)** · 생물 **PHS 351(d)(2)** · HCT/P **1271.440** · 유아 조제 412(f) · 식품 423(FSMA) · 담배 908(c) · 통제물질 **569D**(SUPPORT Act 2018). **일반 의약품(NDA/ANDA/OTC): 없음**.
- **왜 자발이 사실상 강제인가**: 위법 제품은 **압류(304)·금지명령(302)** 대상, 유통 지속은 301 금지 행위·**Park doctrine** → 리콜이 가장 싼 선택; 7.45; 공개 압력(Enforcement Report·FDA 보도); 211.198·Q10 하 결함 대응 자체가 규정 준수(지연은 483/WL); 2022 guidance. '자발' = **개시 주체**가 회사라는 뜻.

## 2. 리콜과 함께 도는 별도 시계
| 보고 | 기한 | 근거 |
|---|---|---|
| **FAR**(NDA/ANDA 품질 결함 — 라벨 혼입·안정성 실패·불순물·규격 이탈, 조사 완료 전이라도) | **3 working days** | 314.81(b)(1)(ii) |
| **BPDR**(BLA 유통 배치 safety·purity·potency 영향 편차) | **45 calendar days** | 600.14 |
| 기기 **806** correction/removal(위험 감소·위법 교정 목적; 예외 806.1(b): 위험 무관 개선·market withdrawal·routine servicing·stock recovery·이미 803/Part 7 보고; 비보고도 806.20 기록) | **10 working days** | 21 CFR 806 |
| **DSCSA** 불법 제품 FDA 통지(Form 3911) + 거래 파트너 통지 | **24시간** | FD&C 582 |
| **HCT/P** 유해 반응(전염병 전파 관련 치명·생명 위협·영구 장애·개입) / deviation | **15일 / 45일** | 1271.350(a)/(b) |
| **IND** safety report | 7/15일(312.32) + 정보 수정 312.31 | 21 CFR 312 |
| 환자 유해 ICSR | 15-day | 314.80/600.80 |

예: 5 mg 정제에 10 mg 라벨, 도매 출하 → FAR 3일 → HHE(절반 용량, 치료 실패; 좁은 치료역이면 I) → 7.46(분류 안 기다림) → retail/consumer depth, effectiveness A/B → 7.49 → 7.53 → 211.130 라인 클리어런스 CAPA·로트 확대 → 수출분 EU Art 123(2). 유효기간 36→24개월(30개월 실패): FAR 3일, 24개월 미경과 재고 **재라벨(correction = 리콜)**·경과 재고 removal, retail depth, 유효기간 단축은 CBE-30 supplement(FDA 2004 Changes guidance XI.B.1), EU Ch.8·Class II Rapid Alert·Q.II.f.1 단축 IA.

## 3. 리콜이 아닌 것, 대안, 금지
- **새 심각 ADR인데 규격 적합**: 제품 결함이 아니라 **B/R 정보 변화** → **라벨 변경**(505(o)(4) SLC·CBE-0 / Type II·USR), **DHCP/DHPC**(GVP XV), REMS/aRMM, 적응증 축소, 극단은 철회·Art 116/117. 경고 누락으로 misbranded(502)가 되면 리콜 논리 가능 → 라벨 변경 + 재고엔 서신. 결정 기록에 **"왜 리콜이 아닌가"**. 과소 대응 노출: 505(o)(4) 30일 미이행·Art 23·제조물 책임(failure-to-warn).
- **회수 제품 제3국 수출**: 불가 — adulterated/misbranded는 **801(e)** 요건(수입국 규격 부합 등) 충족 불가, 802도 품질 전제; EU는 Art 123(2)·117·GMP 위반(QP 인증 불가), CPP 기재로 수입국 거부, WHO GSMS 'substandard'. 폐기·재작업(211.115).

## 4. EU — 세 층과 Rapid Alert
| 층 | 근거 | 내용 |
|---|---|---|
| **당국** | **Art 117** | 공급 금지·시장 철수 사유: 유해·효능 결여·B/R 불리·기재 조성 불일치·시험 미실시·허가 조건 위반(배치 한정 가능) |
| | **Art 116** / **Reg 726/2004 Art 20** | MA 정지·철회·변경 / CAP EC 조치 |
| | **Art 117a**(Dir 2011/62) | 결함·위조 신고 수신 시스템 + **환자 도달 제품도 회수** 보장 |
| **MAH** | **Art 123(2)**(Dir 2012/26) | 철회·정지·회수·MA 미신청 등 조치를 **즉시(forthwith)** 사유와 통지, **제3국 조치 포함** |
| | **Art 81** / **Art 23a** | 공급 지속 / 시판 중단 **2개월 전** |
| **제조자/QP** | **GMP Ch.8**(2015-03-01) | 결함·회수 **지정 책임자**, QRM 기반 절차, 근본 원인("사람 실수" 금지)·확대, 리콜·**비정상 공급 제한** 가능 결함은 **지체 없이** NCA(+CAP은 EMA), 위조·IMP 포함, 유통 기록·환자 도달 제품 회수·격리·처분·대조, **mock recall** 정기, 부족 완화 당국 협의, 기록 |

- **Rapid Alert**(CoCP; PIC/S 동일 채택): **Class I**(잠재적 생명 위협·중대 위험) → **국가 조치와 동시**, 수출 여부 무관 **전 수신처**(EU/EEA NCA·EMA·EC·PIC/S·MRA·WHO) · **Class II**(질병·오치료 가능) → **24시간 내** 전 수신처 · **Class III** → **미해당**(국내). 발신은 **supervisory authority**(배치 출하·제조소 NCA), CAP은 EMA 조정. 위조는 별도 양식 + WHO GSMS.
- **누구에게**: CAP → MAH/제조자가 **지체 없이 EMA + supervisory authority**, Art 123(2). DCP → **supervisory authority**(결함 조사 주도) + **RMS**(variation·Art 116 평가) + 발견국 NCA; Rapid Alert는 supervisory authority 발신, CMS 국내 회수·HCP 서신(국가별 사전 승인 관행), CMDh 공유, 유통업자 Art 80·Art 117a, 종결은 supervisory authority 보고 + CAPA. EU 리콜 서신은 당국 사전 승인·참조번호·국가 언어·DHPC와 구분.
- **Mock recall vs effectiveness check**: effectiveness는 **실제 리콜 중 사후 검증**(Level A–E, 7.53 수치); mock recall(Ch.8 §8.30)은 **리콜 없을 때 절차 시연**(임의 배치 24시간 내 유통 재구성). 둘 다 "회수 가능성"(211.150·Ch.8)을 묻고, 한계 요인은 **추적성**.
- **IMP 회수**: 미국 IND — sponsor 책임(312.50/.56/.57), 사이트 중단·격리·반품, **312.31 정보 수정/312.32 7·15일**, IRB, 맹검 해제 절차, FDA 협의(Enforcement Report 게재 가능). EU CTR — **Art 52 serious breach 7일**(CTIS), **Art 54 urgent safety measures 조치 후 7일**, Art 53 예상 밖 사건 15일, **Delegated Reg 2017/1569**(sponsor·제조자·QP 협력, 맹검 유지 회수), NCA 통지·Rapid Alert 가능.

## 5. 추적성과 공급 부족
| | **US DSCSA**(2013, FD&C 581–585) | **EU safety features**(Dir 2011/62 + Delegated Reg 2016/161, **2019-02-09**) |
|---|---|---|
| 목적 | **추적성 + 위조 방지** | **위조 방지** |
| 수단 | 패키지 serialization + 거래마다 **TI/TH/TS** 교환·6년 보존, **2023-11-27** 전자 패키지 추적(안정화 2024-11-27) → 유예 **2025-05-27 제조·08-27 도매·11-27 대형 dispenser·2027-11-27 소형**; 검증 요청 24h; **불법 제품 24h Form 3911** | **UI(2D) + ATD**, NMVS/EMVS 업로드, **조제 시점 검증·decommission**(도매는 위험 기반); 거래 이력 저장 안 함 |
| 리콜에서 | **유통 경로 재구성** → depth·수량 대조·effectiveness | 환자 도달 패키지 확인·위조 차단; 경로 재구성은 도매 기록(Art 80) |

EMVS "이미 decommission" 경보: 약국 공급 중단·조사(2016/161 Arts 30·36·37, 시스템 오류 배제) → 위조 의심이면 NCA(117a) → MAH 조사·Art 123 → 당국 확인 시 Rapid Alert(위조 양식)+GSMS, Art 117, Europol. 대부분은 데이터 오류 → **false alert 절차** 필수. 미국 대응물은 582 suspect/illegitimate 24h.

**공급 부족**: 미국 **506C**(생명유지·생명구조·중증 예방/치료의 단일/주요 제조자 — **6개월 전** 또는 즉시) + **506C(j) 위험관리계획**(CARES Act 2020) + Drug Shortage Staff 협의(배분·임시 수입·유효기간 연장·우선 심사). EU **Art 23a 2개월 전**, **Art 81**, CAP은 **ESMP**(2025-02-02 의무), **Reg 2022/123 MSSG**(2022-03-01, critical medicines), DHPC. **리콜 vs 부족 균형**(유일 로트 Class II 생명유지 생물): depth wholesale 제한·Dear HCP + 사용 지침·추가 시험 후 조건부 유통·임시 수입, Enforcement Report·shortage list 반영; EU **supply-critical** 경로(추가 통제 조건 제한 공급, MSSG). 원칙: **환자 위해 vs 미치료 위해**를 문서화한 B/R, 임원 승인.

## 6. 글로벌 조율과 용어
- **WHO GSMS**(2013) → Medical Product Alert; **PIC/S** 회원 간 Rapid Alert 공유(비EU 미국·일본·캐나다·호주·한국); MRA 정보 교환; Q9/Q10(불만·리콜 = PQS).
- **용어**: 미국·EU·일본 **Class I/II/III**, 캐나다 **Type I/II/III**, 호주 TGA 행동 유형(recall / product defect correction / alert) + Class. EU Class III는 Rapid Alert 미해당.

- **나이트로사민 사례**: FDA guidance 2020-09, **Rev 1 2021-02**(위험 평가 → 확인 시험 → 완화), NDSRI 2023-08; EU **Art 5(3) referral 2020-06** → call for review 3단계 → variation. 리콜 필요성 = **AI 초과 + 유통 중**(경쟁사 리콜은 트리거 아님) → FAR 3일 → 보통 Class II, 임시 AI·단계적 회수(부족 고려) 협의, 공정 변경 PAS/CBE-30·IB/II.

## 9. 흔한 혼동
1. **Market withdrawal로 이름 붙이면 리콜 아님?** 위법이면 FDA 재분류·공개.
2. **FDA가 의약품 리콜 명령?** 불가(생물 351(d)·기기 518(e)·569D만) — 7.45 요청.
3. **분류 나올 때까지 대기?** 2022 guidance: 먼저 개시.
4. **재라벨은 리콜 아님?** correction = 리콜.
5. **FAR는 리콜 후?** 3 working days, 리콜·조사와 무관하게 먼저.
6. **Class III도 Rapid Alert?** 미해당.
7. **CAP 결함은 EMA만?** EMA + supervisory authority.
8. **2016/161이 유통 경로 추적?** 위조 방지(decommission) — 경로는 DSCSA.
9. **새 ADR = 리콜?** 라벨·DHCP.
10. **회수 제품 수출?** 불가.
11. **경쟁사 나이트로사민 리콜 = 내 리콜?** AI 초과 + 유통 중일 때만.
