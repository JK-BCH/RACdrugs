## 학습 목표
1. **ICH Q5E** 목표·단계(분석 → 비임상 → 임상)·증거량 결정 요소를 쓴다.
2. 미국(**601.12·601.12(e) 2022·2023 초안·2026 성명·312.31**)과 EU(**Q5E·CHMP 2007·EMA Q&A 2019·22473/2025·CTR 실질적 변경·1234/2008 Type II·PACMP**) 틀을 배정한다.
3. **CGT comparability가 어려운 이유**와 보상 도구(split 설계·보존 샘플·역가·통계 사전 설정)를 설명한다.
4. 변경 유형별 **보고 카테고리**(미국/EU)와 **comparability protocol/PACMP 일정 전략**을 세운다.
5. 비임상·임상 bridging 트리거, 누적 변경 계보, 분석법 교체 순서, CTD 위치를 안다.

## 1. ICH Q5E — 원칙
| 항목 | 내용 |
|---|---|
| 목표 | 변경 전후 제품이 **"highly similar"**(동일 아님)하며 기존 지식으로 **안전·효능에 부정적 영향 없음**을 결론 — 품질 속성 차이가 임상 결과에 영향 없음 |
| 단계 | ① **품질(분석) 비교** — 출하 시험 + **확장 특성화**(orthogonal·고분해), 공정 중 통제·공정 성능, **안정성**(실시간·가속·스트레스로 열화 경로 비교) → 차이 없음/설명 가능이면 종료 ② 분석이 임상 관련성을 예측 못 하면 **비임상**(PK/PD·독성·면역원성) ③ 불충분하면 **임상 bridging**(PK/PD·안전·면역원성·효능 하위집단) |
| 증거량 결정 | 변경 **범위·성격**(원료·공정·사이트·규모), **개발 단계**(초기는 임상 데이터로 보완 가능 vs 승인 후 엄격), **제품 지식**(구조-기능·CQA), **분석 능력**(감도·선택성), 안정성 영향 |
| 원칙 | **규격 충족만으론 불충분**(규격은 넓고 추세·분포 변화를 못 봄), 동일 방법·동시 시험·충분 로트, "comparable" ≠ "identical", 개발 중·승인 후 모두 |

## 3. EU 틀
- **가이드라인**: ICH Q5E(CPMP/ICH/5721/03) · **CHMP 2007** 비임상·임상 comparability(언제·설계) · **EMA/CAT ATMP comparability Q&A(2019-12)** — 세포·벡터·공여자 변동, **같은 출발 물질 split**, **역가 중심**, 개발 vs 승인 후, 비임상·임상 트리거 · **22473/2025**(단계 비례) · GTMP 2018·세포 기반 2008·Q12.
- **임상 경로(CTR)**: 품질 영향 제조 변경 = **실질적 변경**(Art 2(13), Annex II — IMPD S/P, 새 제조소, 공정·규격) → CTIS, RMS 평가 **38일** + 결정 **5일**(연장 가능), **승인 전 시행 불가**; 비실질적은 IMPD 갱신·연간.
- **승인 후(Reg 1234/2008)**: 생물의약품 **공정(B.II.b.3)·제조소(B.II.b.1)·규모(B.II.b.4)·시작 물질 제조자(B.I.a.1)·분석법(B.II.d.2)** 대부분 **Type II**(60/90일) — comparability 패키지가 dossier 핵심; **PACMP**(Q12): Type II 승인 → 실행 결과 **IB**. GMP Part IV 변경 관리·QP.

## 4. 왜 CGT는 mAb보다 어렵고, 무엇으로 보상하나
| 어려움 | 보상 도구 |
|---|---|
| **제품 = 공정** — mAb는 서열·글리칸으로 거의 완전 특성화, 세포·EV·벡터는 불완전 → "다르지 않음"을 분석으로 못 보임 | **확장 특성화 패널**(orthogonal·omics)로 감도 확보 |
| **역가 시험 약함**(다중 MOA·변동·시간) → 비교의 축이 흔들림 | **역가 matrix + 대리 상관 조기 개발**(P2 ④) |
| **공여자·출발 물질 변동**이 공정 효과를 가림 | **건강 공여자 split 설계**(한 apheresis를 두 공정에), **같은 세포 은행 출발** |
| 로트 수 적고 비쌈 → 통계력 부족 | **통계 사전 설정**(quality range·TOST·tolerance interval), 시각화 병행 |
| **자가 제품**은 변경 전 물질 없음 | split + **임상 로트 보존 샘플 은행** |
| 참조 물질·표준 부재, 짧은 유효기간·동결보존 | 참조 은행, 안정성 설계 |
| **세포 은행 변경**(새 공여자) = 사실상 신제품 | 다공여자 전략을 처음부터 공정에 |
| 누적 drift | **변경 위험 등급화·순차 도입·계보 로그** |

사전 합의: comparability protocol/PACMP, Type C·SA; 필요 시 PD 바이오마커 임상 bridging. 2026 성명은 **경미 변경**의 부담만 줄인다.

### 통계 — 무엇이 되고 안 되나
**규격 충족** = 필요조건(Q5E 명시 불충분). **TOST**: 사전 동등 구간 내 평균 차 — 엄밀하지만 3 vs 3 소표본·변동 큰 역가엔 검정력 부족·구간 자의성. **Quality range**(참조 mean ± k·SD, k 2–3; 바이오시밀러 관행 — FDA 통계 guidance 2019 철회, 사례별): 직관적·소표본 가능, k 정당화·참조 로트 수 의존. **Tolerance interval**: 분포 기반, 로트 수 요구. **권고**(2023 초안·EMA Q&A): 사전 설정 / 속성별 **중요도 등급**(역가·안전 엄격, 특성화 기술적) / 시각화 + 통계 / 같은 세션·동일 방법 / 차이는 "통계적 유의"가 아니라 **임상 관련성** / 소표본이면 특성화·orthogonal·스트레스로 보완. **함정**: 사후 기준 변경, 분석 변동을 제품 차이로 오독, non-inferior를 comparable로 혼용.

## 5. 변경 유형별 보고 카테고리
| 변경 | 미국(601.12 + 1997 + 2023 초안) | EU(1234/2008 생물의약품) |
|---|---|---|
| 새 제조소(DS/DP) | **PAS** | **Type II**(B.II.b.1; 포장만 IA/IB) |
| 새 MCB/WCB·공여자 세포 은행 | **PAS**(+ 광범위 comparability, 때로 임상) | **Type II**(B.I.a.1/.2) |
| 원료(혈청 → 무혈청, 사이토카인 조성) | **PAS**(조성) / CBE-30(동일 조성 공급자) | **Type II**(조성) / IB(동일 규격 공급자) |
| 규모 | 검증 범위 내 **AR/CBE-30**, 범위 밖·새 바이오리액터 **PAS** | **Type II**(B.II.b.4) |
| 분석법 | 동등 입증 **CBE-30**; **역가·안전 시험 PAS** | **Type II**(B.II.d.2) / IB(사소·동등) |
| 유효기간 연장 | 승인 프로토콜대로 **CBE-30**(또는 AR); 프로토콜 밖 **PAS** | **IB**(B.II.f.1.b) / II |
| like-for-like 장비·편집·규격 강화 | **AR** | **IA** |
| 벡터 생산 시스템(플라스미드·정제) | **PAS**(2023 초안 예시) | **Type II**(B.I.a.1·B.II.b.3) |

원칙: 미국은 **영향 평가로 선택**(FDA 재분류 가능), EU는 **분류표**; 사전 합의로 하향. **'경미' vs '주요'(2023 초안·2026 성명)**: 경미 = 검증 범위 내 파라미터, like-for-like 장비·동일 규격 공급자, 동등 분석법, 포장 → 특성화·추세; 주요 = 공정 원리·단계, 세포 은행·벡터·원료 조성, 규모 밖, 사이트, 자동화 폐쇄 시스템 → 완전 comparability(±bridging). **Q12 EC**: EC 변경은 보고, 비EC는 PQS — **과소 보고**(EC 아니라 했지만 CQA 영향) vs **과대 보고** 위험 → 모든 변경에 Q9(R1) 영향 평가 기록(사찰·PAI 검토); EU는 EC 수용 제한 → CTR 실질적 변경 정의로. '경미'는 **데이터로 증명되는 범주**.

## 6. 연구 설계 사례
- **동종 MSC 2D → 3D 바이오리액터(Phase 2 → 피벗)**: 위험(부착·전단·산소·배지 교환 → 표현형·노화·역가·분비체) = **주요**. side-by-side: 변경 전 **보존 로트 ≥3**(임상 로트 포함) vs 후 **≥3**, 같은 공여자/세포 은행(split 가능하면) → 출하 전부 + 확장 특성화(ISCT + 노화 p16·β-gal·면역 리간드, **핵형·유전적 안정성**, 증식·passage, **역가 matrix**(IDO/PGE2·T세포 억제 — 가장 중요), 분비체 패널, 불순물(잔류 배지·마이크로캐리어), 크기·형태) + 안정성(동결·해동 생존율·역가, 실시간+가속) + 통계 사전 설정 → 차이 시 비임상 PD → 임상 bridging(피벗에 변경 후 제품만, Phase 2 비교는 PD 바이오마커). 미국: **EOP2 Type B** 합의 → **312.31 피벗 사용 전** → 2026 성명 해당 없음(완전 패키지), comparability protocol 사전. EU: **CTR 실질적 변경**(38일+5), SA, 22473/2025.
- **자가 CAR-T 렌티 벡터 생산 공정 변경(승인 후)**: ① **벡터 수준** — 물리·감염 역가(vg/IU), VCN 전달 효율, 순도(플라스미드·숙주 DNA·단백), **RCL 음성**, 서열, **통합 부위 프로파일**, 안정성 ② **제품 수준** — 건강 공여자 **apheresis split**(≥3 공여자, 구·신 벡터): % CAR+, VCN, 생존율, 확장, 표현형(CD4/CD8·기억), 세포독성·IFN-γ 역가, 소진, 사이토카인, 해동 후 안정성 ③ 차이 시 in vivo 종양 모델 → 임상(CAR-T 확장·지속·CRS). 미국 **PAS**(시작 물질 공정; 2023 예시), comparability protocol → CBE-30. EU **Type II**(B.I.a.1·B.II.b.3), PACMP → IB, CAT, Part IV·QP. LTFU 15년 유지, 통합 부위 변화 시 RMP.
- **MSC-EV 초원심 → TFF + SEC(Phase 1 → 2)**: 분리 원리 변경 → 입자 집단·순도(albumin·지단백)·cargo·활성 변화 = 주요. 같은 상층액 **split**(≥3): 입자 수·단백·**단백/입자 비**·회수율 / MISEV2023(크기, 양성 CD63·CD81·CD9·TSG101, 음성 calnexin·albumin·ApoA1, TEM, 단일 소포) / cargo(miRNA·단백 omics + 패널) / 역가(대식세포 TNF-α 억제) / 불순물·엔도톡신·무균 / 안정성 / quality range → cargo·역가 차이면 BPD 모델 PD. 미국 312.31(Phase 2 전) + Type C/EOP1; EU 실질적 변경 38일+5, SA; 3.2.P.2.3.
- **승인 8년 후 MCB 소진 → 새 공여자**: 공여자 = 출발 물질 → **잠재적 신제품**(2023 초안: 세포 은행 변경 = PAS + 광범위, 임상 가능). 접근: 공여자 적격·선정(1271 C/2004/23 + 연령·HLA·초기 역가 스크리닝) → 은행 비교(핵형·안정성·외래성 인자 610.18·성장·표현형) → DP side-by-side(구 보존 vs 신 ≥3: 출하+특성화+ISCT 2016 역가+분비체+안정성) → 차이 시 PD → 임상 bridging(PD·안전 코호트) → **PAS + Type B 사전**(신제품 판정 회피 논증) / **Type II**(B.I.a.1/2) + CAT/CHMP SA. **예방**: 승인 전 **다공여자 전략**(여러 MCB 적격·각 은행 역가 범위)을 공정의 일부로.
- **제2 제조소 이전(18개월) — protocol/PACMP**: 변경 설명·동일성 평가 / Q9(R1) 영향 CQA / 출하 전부 + 확장 특성화·역가 matrix·분비체·불순물·안정성 + 공정 성능(수율·배가) / 합격 기준(TOST/quality range) / 로트 수(신 사이트 ≥3 PPQ = comparability 로트, 구 보존) / 안정성(가속 + 실시간) / 세포 은행 운송·같은 WCB / 분석법 이전 / 카테고리 제안(→ CBE-30) / 실패 조치. 미국 PAS 승인(4–6개월) → 실행 → **CBE-30** + **PAI**(새 사이트). EU **PACMP Type II** → **IB**, 신 사이트 **MIA·Part IV 인증서**, Annex II.A·QP, 비EU면 MRA·수입 QP. 구 사이트 재고로 커버.
- **독일 CMO 이전(기술 이전·PPQ·사찰·QP 통합)**: 공정 지식 패키지(CPP·CQA·실패 모드), 분석법 이전, 세포 은행 운송 적격, 교육, 품질 계약(FDA 2016·Ch.7); **PPQ ≥3 = comparability 로트**; 미국 PAS/comparability protocol + **PAI**(7345.848, 2025 불시 기조; MRA CGT 범위 EMA Q&A 확인); EU MIA(Art 40) + Part IV 인증서(Landesbehörde) + Type II/PACMP → IB + Annex II.A + QP(Annex 16) + 공여자 1271 C + 2004/23 이중; 안정성 착수; 일정 = 사찰·인증서(90일) → 심사 → 시행.

## 7. Bridging, 누적 변경, 분석법 교체, CTD
- **비임상·임상 bridging 트리거**(Q5E·CHMP 2007·2023 초안): 분석에서 **설명되지 않는 차이**(새 불순물·변이체·역가·표현형·cargo) / **분석 능력 부족**(세포 기능·면역원성 예측 불가) / **면역원성 위험 변화**(글리코실화·응집·새 잔류물) / PK/PD 영향(제형·입자·방출) / 제품 지식 부족. 비임상: 동물 PD/효능, PK·생체분포, 독성·면역원성, 종양원성. 임상: PK/PD(확장·지속·바이오마커), 면역원성, 안전 코호트, 드물게 효능 하위집단 — **동시·동일 기준**, 변경 후 제품을 피벗 일부에 포함하는 **내장 bridging**이 효율. ATMP(EMA Q&A): 1회 치료라 임상 비교 불가면 **PD·안전 + 강화된 특성화**. bridging 필요 변경은 거의 항상 **PAS/Type II**.
- **6년간 9회 변경 → 피벗 vs 상업 공정**(누적 평가, 2023 초안): **공정 계보 표**(변경·날짜·위험 등급·결론·사용 시험·로트, IND 수정 번호) → **임상 로트 ↔ 공정 버전 매트릭스**(환자별 공정 → 효능·안전 하위집단) → CQA 추세 그래프 → **보존 샘플 인벤토리** → **양 끝 side-by-side**(피벗 대표 보존 로트 vs 상업 PPQ) → 통계 사전, 차이 시 PD/임상 하위집단 → 3.2.S.2.6/3.2.P.2.3, Q12 PLCM. 교훈: 변경마다 보존 샘플·역가·로트-환자 매핑, 피벗 전 고정, 상업 공정으로 피벗 일부 로트(bridging 내장).
- **comparability + 새 역가 분석 동시**: 제품 비교는 **같은 방법**으로 → ① 신 분석 개발·검증(Q14 ATP·Q2(R2)) ② **방법 브리징**(보존 로트·참조·안정성 샘플을 구·신 병행 ≥n, 상관·편향, 합격 기준 변환, 참조 역가 재할당) ③ 제품 comparability(신 방법 + 가능하면 구) ④ 안정성 연속성(재시험 또는 계수) ⑤ 규격·검증·3.2.P.5. 미국 **역가 시험 변경 = PAS**(같은 PAS 묶거나 선행, Type C); EU **Type II**(B.II.d.2) + B.II.d.1 grouping. 신 방법으로 과거 임상 로트 재해석 가능해야 라벨 용량·기준 유지.
- **CTD·문서**: **3.2.S.2.6 / 3.2.P.2.3**(공정 개발 — 변경 이력·comparability 요약·계보) · 3.2.S.4.5/3.2.P.5.6 규격 정당화 · 3.2.S.7/3.2.P.8 안정성(변경 후·브리징) · 3.2.A 시설 · **3.2.R**(미국 comparability protocol; EU PACMP는 3.2.R/Module 1) · Q12 PLCM(미국 선택, EU 제한). **IND 수정(312.31)**: 변경 설명·근거, 영향 평가, comparability 데이터(또는 계획), 변경 후 제품 사용 시험·시점, 갱신 CMC 섹션, IB 영향. **CTR 실질적 변경**: CTIS 양식, IMPD S/P 갱신, 정당화·comparability 요약, 피험자 영향(Part I), 승인 후 시행. 승인 후 PAS/Type II = 변경 설명(Module 1) + 3.2 갱신 + comparability 보고서 + 안정성 + 규격 정당화 + (해당 시) 비임상·임상.

## 8. EU vs 미국 체계와 글로벌 일정
EU **분류표 고정**(생물 공정·제조소·규모·시작 물질·분석법 = Type II 60일(90 적응증) + clock-stop → 실질 **6–9개월**, 승인 후 시행, PACMP → IB 30일, grouping/worksharing) vs 미국 **영향 기반 자가 분류**(PAS 승인 후 시행 — CMC PAS 4–6개월, CBE-30 30일, AR 사후; comparability protocol 하향; 재분류 위험). EU는 예측 가능·경직('경미'도 IB 30일 대기), 미국은 유연·판단 책임. **글로벌 전략**: ① **PACMP(EU Type II) + comparability protocol(US PAS)** 을 변경 1년 전 동시 제출 ② 실행 데이터 → **EU IB + US CBE-30 같은 날** → 시행일 정렬 ③ 미합의면 Type II·PAS 병행, 구 공정 재고로 커버, 지역별 시행일 차이 시 **공급 이원화**(배치 추적) ④ 역가·안정성 데이터 두 dossier 공용 ⑤ 일본 일괄 변경 신청 일정 포함.

## 10. 흔한 혼동
1. **규격 통과 = comparable?** Q5E 명시 불충분.
2. **comparable = identical?** highly similar.
3. **2026 성명으로 모든 임상 변경이 경미?** 경미 범주의 부담만.
4. **IND 변경은 사용 후 보고?** 품질 영향이면 사용 전 312.31.
5. **CTR 실질적 변경도 시행 후 통지?** 승인 전 시행 불가.
6. **자가 제품은 comparability 불가?** 건강 공여자 split.
7. **새 공여자 MCB = 단순 변경?** 잠재적 신제품.
8. **역가 분석 교체와 제품 비교를 같이?** 방법 브리징 먼저.
9. **TOST면 충분?** 소표본 한계 — 중요도 등급·시각화 병행.
10. **EU에서 Q12 EC로 하향?** 제한적 — 실질적 변경 정의.

## 11. 네 분야에 올려놓기
**MSC-EV 피벗 전: 플라스크 → 바이오리액터 + 새 동결 제형**: 두 변경 **분리·순차**(또는 요인 설계로 귀속 가능하게), 둘 다 주요. ① **모세포 비교성**(2D vs 바이오리액터 MSC — ISCT 표현형·노화·핵형·모세포 역가 IDO/PGE2) ② **EV side-by-side**(≥3 배치, 같은 세포 은행): 입자 수·단백/입자, MISEV2023 마커·오염 마커, 크기, cargo(miRNA·단백 + omics), 기능 역가 matrix(대식세포 TNF-α 억제·내피 보호), 불순물(albumin·지단백·잔류 동결보존제), 무균·엔도톡신 ③ **제형**: 동결·해동 후 응집·역가, 안정성(실시간+가속), 용기 상호작용 ④ 통계(quality range + 역가 TOST) ⑤ 차이 시 BPD 모델 PD. 소통: 미국 **EOP2 Type B** → **312.31**(피벗 전) → 승인 후 대비 comparability protocol; EU **SA** → **CTR 실질적 변경**(38+5) → MAA 3.2.P.2.3 계보. **fallback**: 피벗에 변경 후 제품만 + Phase 2 PD 비교 코호트 / 피벗 내 두 공정 내장 bridging / 최악은 변경 연기(상업 공정으로 피벗). 2026 성명은 해당 없음.
