# Ch.31 — 변경(variation·supplement): 위험에 비례한 보고 수준, 그리고 "언제 시행할 수 있나"

> **덱:** Ch31_1(개념·구조) + Ch31_2(세부·상황형), 40장. 이틀 분량 한 장.
> **검증 메모(2026-11-22):** EU Reg (EC) 1234/2008 + Delegated Reg (EU) **2024/1701**(2024-07-07 발효, **2025-01-01 적용**: Type IA 연 1회 일괄, super-grouping, worksharing 확대, Art 5 확대); **새 EC Variations Guidelines 2026-01-15 적용**; **Type IB 30일**(AR day 20·수용 day 30), **Type II 60일**(적응증·대규모 grouping **90일**, 긴급 안전성 **30일**) — 두 덱 메모 기준. IA/IAIN/line extension/grouping Art 7/worksharing Art 20/Art 5/USR Art 22, 21 CFR 314.70 (b)/(c)/(c)(6)/(d)·601.12, FDA 2004·2014·1997 guidances, SUPAC(IR 1995·MR 1997·SS 1997), comparability protocol 2022(314.70(e)), efficacy supplement 10/6개월, Q12·Q5E는 ○.

## 학습 목표
1. 미국 **PAS / CBE-30 / CBE-0 / annual report**(314.70·601.12)의 정의·예시·시행 규칙·재분류 위험을 안다.
2. EU **IA / IAIN / IB / II / line extension**의 정의·시계·2025 연간 IA·grouping·worksharing·Art 5·USR을 쓴다.
3. 두 체계의 **분류 철학**(자기 평가 vs 분류표)과 **Q12(EC·PACMP)** 의 연결·EU 제한을 설명한다.
4. **comparability protocol/PACMP**로 공급 공백 없이 변경을 순서화한다.
5. 생물의약품·EV 제품 변경을 **두 지역 동시에 분류**한다.

## 1. 미국 — 21 CFR 314.70 / 601.12
| 카테고리 | 정의 | 시행 | 예(소분자 2004 guidance / 생물 601.12(b)(2)) |
|---|---|---|---|
| **(b) PAS** | 제품 특성·안전·효능에 **상당한(major)** 영향 가능 | **FDA 승인 후** | 공정 변경, 규격 **완화**, **무균·생물의약품 제조소** 변경, 라벨 효능 변경(**efficacy supplement**), 무균 용기 밀봉; 생물: 공정·**세포주·세포 은행**·규모(검증 밖)·시설·제형, **승인 안정성 프로토콜 밖 유효기간 연장** |
| **(c) CBE-30** | **중등도(moderate)** | 제출 후 **30일** 경과(FDA 이의 없으면) | 비무균 제조소 변경, 분석법 변경(동등), 비무균 용기, 유효기간 연장 중 **승인 안 된 프로토콜 또는 pilot 배치** 데이터 기반 |
| **(c)(6) CBE-0** | 특정 중등도 | **제출 즉시** | 라벨 안전성 강화(Ch.23) 등 |
| **(d) annual report** | **사소(minor)** | 연 1회 보고 | 편집 라벨, 규격 **강화**, 동일 규격 부형제 공급자, 일부 배치 크기, **승인 프로토콜 + 실생산 배치 전체 유효기간 데이터로 유효기간 연장**(314.70(d)(2)(vi)) |

- **CBE-30 규칙**: 접수 후 30일 내 FDA가 이의(불가 또는 PAS 필요)를 통지하면 시행 불가·보류; 통지 없으면 시행하되 이후에도 재분류·거부 가능. CBE-30으로 시행했는데 FDA가 **PAS로 재분류**하면 → **미승인 변경** → 배치 misbranded/adulterated 위험, **유통 중단·회수**, PAS 승인까지 변경 전 공정 복귀. 예방: 분류 근거 문서화, 애매하면 Type C/D 문의.
- **"시행" vs "준비"**: PAS/Type II는 **승인 전 시행 금지**(검증 안 된 제품을 시장에 두는 것). 준비(검증 배치 생산·데이터·재고 비축, 출하 금지)는 허용, 시행(**상업 출하**·라벨 사용)은 승인 후 — 검증 배치를 승인 후 출하하려면 안정성·보관 기록.
- **Efficacy supplement**: 새 적응증·용법·집단 → PAS, PDUFA **standard 10 / priority 6개월**(receipt 기준), 3년 독점 가능, **PREA 트리거**. 새 강도도 PAS(+BE/용출, 라벨 2·3, PREA, 특허·독점·listing).
- **무균 vs 비무균 제조소**: 2004 guidance는 무균 공정 제조소 변경을 오염·무균 보증에 직접 영향으로 봐 **PAS**, 비무균 고형제는 공정 재현·시험 확인 가능해 **CBE-30**(동일 SOP·검증·사찰 이력 조건) — 위험 비례 분류.
- **SUPAC**(IR 1995 · MR 1997 · SS 1997): 제형·규모·제조소·공정·장비 변경을 **Level 1–3**으로 — scale-up **10배 이하 Level 1**(annual report), **10배 초과 Level 2**(CBE + 용출 비교 + 안정성 1배치). 2014 *CMC Postapproval Manufacturing Changes … Annual Reports*, 1997 *Changes … Biological Products*.
- **Comparability protocol**(314.70(e)/601.12(e), guidance 2022 final = Q12 **PACMP**): 계획 변경의 **시험·분석·합격 기준**을 **PAS로 사전 승인** → 실제 데이터는 **한 단계 낮은 카테고리**(PAS → CBE-30, CBE-30 → AR).
- 용출 규격 **완화**(배치 실패 때문): US PAS / EU Type II(B.II.d.1.b) — 당국은 임상 관련성·공정 능력·근본 원인을 묻고 "실패해서 완화"는 공정 통제 실패로 읽혀 거부 가능성 → CAPA·공정 개선 먼저, Q6A/Q6B 정당화·용출-생체 상관.
- **ANDA**는 314.97로 314.70 준용(색상 변경 CBE-30/AR, 비무균 제조소 CBE-30; RLD 외관 동일성·혼동 평가).

## 2. EU — Reg (EC) 1234/2008 (+2024/1701, Guidelines 2026-01-15)
| 유형 | 정의 | 절차·시계 |
|---|---|---|
| **IA** | 품질·안전·효능 영향 **최소**(분류표 조건 충족) | **"do and tell"** — 시행 후 통지; **2025-01-01부터 연 1회 일괄**(annual update, 12개월 내). 조건 미충족으로 **거부되면 즉시 중단·원상 복구**, 원하면 IB/II 재제출 |
| **IAIN** | IA지만 감독에 필요 | 시행 후 **즉시 통지**(연간 일괄 제외) |
| **IB** | IA·II·LE가 아닌 **기본 범주** | **"tell, wait and do"** — 유효 통지·절차 시작 후 **30일**(AR day 20, 수용 여부 day 30); 질의 시 1회 응답, 불수용이면 철회 또는 Type II 상향 |
| **II** | **주요** 변경 | 평가·승인 후 시행: **60일** 표준 / **90일** 적응증 추가·변경(C.I.6)·합의 대규모 grouping / **30일** 긴급 안전성; RSI clock-stop |
| **Line extension**(Annex I) | 활성물질(염·에스터 등 효능·안전 차이)·**강도·제형·경로** 변경 | **MAA와 같은 절차**·수수료 |

- **2024/1701**(2025-01-01): IA 연간 일괄, **super-grouping**(여러 제품·변경), **의무/자발 worksharing** 확대, **Art 5 분류 권고** 확대, 백신 갱신 간소화, 행정 변경 완화. **새 EC Guidelines(2026-01-15)**: 분류표·절차 상세 갱신. EMA 절차 안내 2025-12까지 갱신.
- **목록에 없는 변경**: ① **Art 5 분류 권고**(CMDh/EMA, 결과 CMDh 웹 공개) ② 기본 **IB**("default IB"), Type II 조건(상당한 영향)이면 **II** ③ 극히 사소면 IA 조건 논증.
- **Grouping(Art 7, Annex III)**: 같은 MA(또는 같은 MAH 여러 MA)의 여러 변경을 하나로 — 그룹 내 **가장 높은 유형 절차**. **Worksharing(Art 20)**: **여러 MAH·여러 MA**의 **동일 변경**을 한 reference authority가 1회 평가(각 MA별 sequence). 같은 CMO 제조소 변경이 MAH 둘·제품 8개 → grouping + worksharing.
- **USR(Art 22)**: 공중보건 위험 시 SmPC 임시 변경 — 통지 후 **24시간 내 당국 미반대 시 시행**, **15일 내** variation. 미국 CBE-0의 긴급 대응물.
- **NAP(MRP/DCP)**: RMS 평가·CMS 검토, **CMDh 절차** 60/90일, 합의 시 CMS **30일 내** 국가 승인 갱신; 이견 CMDh → CHMP referral; 제출은 각 NCA(CESP).
- PI 변경 동반 시 **QRD·linguistic review**가 병목. 적응증 추가 = Type II 90일 + **+1년 시장 보호** 신청(1.5.3, significant clinical benefit) + PIP(Art 8) + RMP; RSI clock-stop 3개월 + EC 결정 ~2개월(번역) → 90일 시계라도 현실 승인 월 8–9.

## 3. 철학과 Q12
- **미국**: 규정은 원칙(major/moderate/minor)만, guidance가 예시 → **신청자가 영향을 평가해 카테고리 선택**, FDA 사후 재분류 가능(유연·책임은 신청자). **EU**: Guidelines 분류표·조건·문서가 사실상 법적 분류 → 예측 가능·경직, 없으면 Art 5.
- **왜 IA는 do-and-tell, IB는 tell-wait-do**: IA는 영향 최소가 조건으로 사전 확정(되돌릴 수 있음); IB는 영향 가능성이 있어 당국이 30일 안에 한 번 볼 기회가 필요하되 전면 평가는 아님 — 침묵 = 수용. 비례성 3단계.
- **Q12**: **EC**(변경 시 보고 필요한 규제 약속; 비EC 정보는 PQS 변경관리) · **PACMP**(= comparability protocol) · **PLCM**. 미국 314.70 틀과 정합. EU는 **Reg 1234/2008이 분류를 법으로 고정**해 "EC 지정으로 카테고리를 낮추는" 접근을 완전히 수용하기 어려움 → PACMP·PLCM만, EC 효과 제한(EU Q12 이행 주석).
- **당국 주도 라벨 변경의 흐름**: 미국 505(o)(4) SLC → 30일 내 CBE-0/PAS/rebuttal(분류를 사실상 FDA가 정함, order로 강제); EU PRAC → CHMP/CMDh → **MAH가 variation 제출**(CAP IB/IAIN/II; NAP 국가) → EC 결정으로 강제.

## 4. 전략 — 공급 공백 없이
- **순서화**: 지금 US comparability protocol(PAS)·EU **PACMP(Type II)** → 승인(US 4–6개월, EU 60일) → 변경 실행·Q5E 데이터 → **US CBE-30 / EU IB를 같은 날 제출** → 30일 후 거의 동시 시행; 심사 기간은 구 공정 재고로 커버. 미합의 시 PAS/Type II 6개월+.
- **소분자 vs 세포 유래 생물의약품**: 소분자는 분석 동등성 → 낮은 카테고리(CBE/IB·IA)·SUPAC 틀; 세포 유래는 "공정이 제품"이라 분석만으로 결론 안 나(Q5E → 비임상/임상 bridging) 대부분 **PAS/Type II**(6개월+) → **사전 합의가 곧 공급 전략**. 500 L → 2,000 L scale-up: 지금 comparability protocol(공정 비교·Q5E 항목·합격 기준·안정성·bridging 기준·CBE-30 하향 제안) → 승인 후 실행 → CBE-30; EU PACMP(II) → 실행 데이터 IB.
- **묶기**: 미국은 한 보충에 관련 변경을 묶되 가장 높은 카테고리; EU grouping/worksharing/super-grouping. 긴급 안전성 변경은 **분리**(30일 시계·USR).
- **변경 통제 SOP 필드**: 변경 설명·근거 · 영향 평가(CQA·EC 여부·Q5E 필요) · **미국 카테고리**(+guidance·SUPAC level) · **EU 카테고리**(+Guidelines 코드) · 타 지역 · **시행 조건**(승인 후/30일 후/즉시/연간) · 제출 일정·sequence · 라벨 영향 · PACMP 여부 · 승인 기록 · 지역별 시행일 차이 시 **재고 계획**.

## 6. 흔한 혼동
1. **CBE-30 침묵 = 영구 승인?** 이후 재분류 가능.
2. **PAS 승인 전 검증 배치 출하?** 시행 금지(준비는 가능).
3. **규격 강화도 PAS?** AR / IA. 완화가 PAS / II.
4. **IA 거부되면 그대로 두고 IB 내면 된다?** 즉시 원상 복구.
5. **IB는 승인 후 시행?** 30일 침묵 후.
6. **목록 없는 변경 = IA?** 기본 IB(또는 II), Art 5.
7. **Type II 90일 = 출시 3개월?** clock-stop·EC 결정으로 8–9개월.
8. **Q12 EC로 EU 카테고리 하향?** 제한적.
9. **Line extension은 variation?** MAA 절차.
10. **무균 제조소 변경 CBE-30?** PAS.

## 7. 네 분야에 올려놓기
EV 제품의 잦은 변경 — **배지 공급자(조성 변경)**: US PAS(601.12(b)) + comparability / EU Type II(B.I.a.x). **유효기간 12→24개월(실시간 데이터, 승인 프로토콜대로)**: US AR(NDA 314.70(d)(2)(vi); BLA도 2021 Certain Biological Products guidance상 AR — 승인 프로토콜·실생산 ≥3로트 전체 유효기간 데이터. 승인 안 된 프로토콜·pilot 배치면 CBE-30) / EU IB(B.II.f.1); 프로토콜 밖·보관 조건 변경이면 PAS / II. **역가법 교체**: US PAS / EU Type II(B.II.d.2 생물). **EU CMA 동시 변경**: 규모 확대 **Type II(B.II.b.4)+Q5E**, PRAC 신호 후 RMP 갱신 **Type II(C.I.11)**+4.4/4.8, SO 기한 연장 **Type II(Annex II.E)** → 같은 MA라 **grouping 가능**(평가 1회·수수료 절감)이되 RMP가 긴급이면 **분리**(30일·USR). 변경마다 6개월 심사를 피하려면 **PACMP/comparability protocol 사전 합의**가 공급 전략이다.
