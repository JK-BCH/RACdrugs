## 1. 역가는 법이다
- **600.3(s)**: potency = 제품의 **"specific ability or capacity … to effect a given result"**, **적절한 실험실 시험** 또는 의도된 투여로 얻은 **통제된 임상 데이터**로 지시 → **임상 효과와 연결된 생물학적 능력**(함량·정체성 아님).
- **610.10**: 역가 시험은 **in vitro 또는 in vivo(또는 둘 다)** 로 **각 제품에 특별히 설계**되어 역가를 지시; **610.9** 동등 방법 대체(동등성 입증). 211.165(a) 출하 시험·211.160·211.194.
- **결과**: 역가 시험 없음·미검증·규격 미충족 출하 → **501(a)(2)(B) adulterated** → 483·WL·**BPDR**·리콜; 임상 단계에선 **312.42 hold** 사유(역가 측정 부재).
- **네 범주 구분(610)**: **identity 610.14**(라벨 그대로 — MSC는 ISCT 마커 CD73·CD90·CD105 ≥95%/음성 ≤2%, 형태·부착, chain of identity) · **purity 610.13**(생존율·잔류 배지·혈청·효소·비드·엔도톡신·세포 조성) · **potency 610.10**(**기능** — ISCT 2016 matrix) · **sterility 610.12**(+ 마이코플라즈마·외래성 바이러스). **ISCT 2006 기준(마커·부착·3계열 분화)은 정체성이지 역가가 아니다** — FDA/EMA는 "마커 통과 = 역가"를 인정하지 않는다. 규격표(3.2.P.5.1)는 네 범주와 특성화(release 아님)를 분리.

## 2. 2011 guidance (현행) — 어떤 시험이 610.10을 충족하나
| 항목 | 내용 |
|---|---|
| 역가 시험 유형 | **생물학적 시험**(in vivo 동물 / in vitro 세포 기반 — **MOA 반영**) 또는 **비생물학적 대리(surrogate) 분석**(표현형·유전자 발현·분비 단백·효소 활성 — **생물 활성과의 상관 입증 필수**) |
| **Matrix approach** | 단일 시험으로 부족(다중 MOA·복합 제품)하면 복수 보완 시험 조합 — 각 시험의 역할·합격 기준 명시 |
| 단계별 | **IND 초기부터 어떤 역가 측정**(정성·반정량 가능, 안전·용량 근거) → Phase 2 **정량** → **Phase 3 전** 적격·규격 → **BLA**: **검증된(Q2) 정량 시험 + 합격 기준 + 안정성 지시** |
| 기타 | 참조 물질·대조, 분석 변동 통계(USP <1032>–<1034>), 역가 = **comparability·안정성·공정 변경의 축** |

**왜 단일 생물 시험이 자주 실패하나**: 다중 MOA(면역조절 + 영양 인자 + 혈관신생) / 높은 변동(공배양 반응 세포 공여자, CV 20–30%) → 합격 기준·OOS 불안정 / 수일 소요 vs 짧은 유효기간 / 자가 배치별 출발 물질 / 동물 모델 윤리·재현성. **matrix + 대리지표가 수용되는 조건**: 각 시험이 특정 MOA·CQA에 매핑, 대리 분석은 생물 활성과의 상관이 **데이터로 입증**, 조합이 역가 변화를 **감지**(안정성·공정 변경에서 민감), 합격 기준은 임상 로트 경험. **깨지는 곳**: 상관이 좁은 범위에서만 성립, 대리지표가 열화 기전을 놓침(표현형 유지·기능 소실), 변경 후 상관 재검증 누락, 참조 물질 drift.

## 3. 2023-12 초안 — Potency Assurance Strategy
"**시험**에서 **보증 전략**으로": 출하 시험 하나로 역가를 보증할 수 없다 → **과학·위험 기반 수명주기 전략** — ① **QTPP** → ② **CQA**(역가 관련) → ③ **MOA 이해**(다중 가능) → ④ **통제 조합**: 제조 **공정 설계**(파라미터·QbD), **원료·시작 물질 통제**(공여자·세포 은행·벡터·배지), **공정 중 통제·시험**, **출하 역가 시험**(matrix 가능) → ⑤ **분석법 개발·검증**(Q14 ATP·Q2(R2)) → ⑥ 안정성·**변경 관리**(Q12·comparability), 단계별 성숙, BLA 3.2.P/3.2.S 통합.
**동인**: 짧은 유효기간·자가(결과 전 투여) / 다중 MOA·변동 / Q8–Q10 QbD(역가 = CQA, 통제 전략 언어) / Q14·Q2(R2) 분석 수명주기 / 2023–26 CBER 정책(FAQ·유연성·START)과 정합 — "시험 추가"가 아니라 "과학적 전략"으로 재정의, 초기 부담 완화·후기 엄격.
**기준일 답**: "2026-09-01 기준 **현행 최종 = 2011 Potency Tests**, **2023-12 초안**이 수명주기·위험 기반 접근 제시, **최종화(2026-11-02)는 기준일 이후**" — '현행 guidance'를 물으면 2011, 'FDA 방향·초안'을 물으면 2023. 불변: 610.10, MOA 연결, matrix/대리 상관, BLA 검증.

### 검증 설계(BLA 세포 기반 상대 역가)
**4PL 용량-반응**, 시험 vs **참조 물질** 동일 플레이트, **상대 역가(%)**, **평행성 검정**(<1034>). 파라미터(Q2(R2)/<1033>): 상대 정확도(50–150% 회수), 정밀도(분석자·일·세포 passage·시약 로트), 특이성(비활성·열변성 대조), 범위(합격 기준 포함), 희석 선형, robustness, **시스템 적합성**(참조 곡선 파라미터·대조). **참조 물질 2단계**: **1차**(임상 대표 로트, 광범위 특성화, −80/LN2, 소량) → **작업**(1차 대비 보정 assigned potency), **교체 프로토콜**(신·구 병행 n회, 역가 할당·불확도, **drift 추세**, 재적격 주기), 대량 분취·장기 안정성. 반응 세포: 은행·passage 상한·적격. **합격 기준**: 임상 로트 분포 + 공정 능력 + 안정성 변화(예: 참조의 60–140%), 통계 정당화, **상한**(과활성 안전). **안정성 지시**: 열화·동결해동·보관 중 손실을 감지해야 유효기간·해동 후 사용 시간 정당화 — 강제 분해로 입증; 안정성 프로토콜엔 matrix 전부가 아니라 **안정성 지시 요소**만 정당화해 선택.

## 5. EU — 가이드라인 + 약전 + QP
- **EMA 세포 기반 의약품 guideline(2008)**: 역가 = **의도된 MOA 관련 생물학적 활성의 정량**, 출하·안정성 규격, 대리 마커는 **기능과의 상관** 입증, 특성화 시 다중 기능. **GTMP guideline(2018)**: **벡터 역가**(물리 — 게놈 수 / 감염성), **전이유전자 발현·기능**, 변형 세포는 세포 역가 + 발현. **EMA/CAT/22473/2025**(2025-07-01): **단계 비례** — 초기 특성화·적격, **확증 시험 전 역가 시험 확립·규격 정당화**. **EMA comparability Q&A(2019-12)**: 변경 평가의 중심 = 역가.
- **집행**: 법 조문(610.10) 대신 **Dir 2001/83 Annex I + Ph. Eur.(구속) + EMA 가이드라인 + MA 규격**; **QP 인증**(Annex 16) 시 규격 충족 확인 → 미충족 배치 출하가 위반 축; Part IV(ATMP) 또는 Part I; 사찰(Art 111) critical → non-compliance; Art 117.
- **수렴 이유**: 양쪽이 **Q6B**(규격 구조)·**Q2(R2)**(평행성·상대 역가)·**Q14**(ATP·수명주기)를 공유 → 같은 검증 보고서·규격 정당화가 양쪽 Module 3에; USP ↔ Ph. Eur. 조화. **남는 차이**: 미국 610.2 lot release·CBER 제품 전문가 심사 vs EU QP 개인 책임·Part IV; 변경 카테고리(601.12 vs 1234/2008).

## 7. 역가가 약하면 전부 막힌다 — comparability의 축
Q5E: 변경 전후 "highly similar"를 **분석 비교**로 보이고 임상 관련 속성을 못 잡을 때만 bridging → 역가는 임상 효과와 가장 직접 연결된 CQA → **역가 동등 = 효능 동등 추정의 핵심**. 2023 초안·2026 성명 모두 "변경 수용 = 역가·CQA 비교성". 약한 역가의 결과: 감도 부족(변경을 못 봄 → 임상 bridging·거부) / 변동 큼(TOST 실패) / 대리 상관 미입증 / 안정성 비교 불가(유효기간 연장 막힘) / 사이트·규모·배지·자동화 전부 **보류**. 전략: Phase 1부터 역가 투자, 임상 로트 **참조 물질 은행**, 변동 감소(자동화·세포 은행), 역가-임상 상관(용량·반응), **comparability protocol(601.12(e))**.

## 8. 실무 상황
- **역가 OOS(정체성·생존율 통과)**: ① **Phase I 실험실 조사**(FDA OOS 2022: 반응 세포 passage·시약·플레이트·참조 곡선; 시스템 적합성 실패면 근거 문서로 무효화) ② **Phase II 전면 조사**(공정 기록·공여자·해동, 원료 변동, 다른 matrix 요소 일관성, **사전 정의 재시험 계획** — 합격 나올 때까지 금지, 재샘플링은 비대표성 입증 시만, 타 로트·안정성 추세) ③ 처분: 확정 OOS → 불합격(OOS 제품 투여 절차는 자가·대체 불가 경우에 한정, 동종은 해당 없음) ④ 보고: 미출하면 BPDR 아님, 유통·투여면 **BPDR 45일**(600.14), 리콜 평가(Class II) ⑤ CAPA: 시험 변동(참조 drift?) → 재검증, comparability·안정성 결론 재검토, 규격 재평가는 데이터 기반(완화는 PAS/Type II). EU: Ch.6 OOS·Annex 16 QP(미충족 → 인증 불가)·Art 117.
- **승인 2년 후 역가 범위가 불필요하게 좁음**: 근거 = **2026-01-11 성명**(상업 경험이 일관 품질을 보이면 합격 기준 재평가·개정 고려). 패키지: 상업 로트 분포·추세, 임상 결과·AE와 **비상관**(PV·레지스트리), 안정성 추세, 분석 변동 분해, Q6B 정당화, Q9(R1), 제안 범위·상한 유지. **미국 = PAS**(601.12(b) 규격 완화; 성명은 수용 가능성이지 카테고리 하향 아님; Type C/comparability protocol 사전 합의). **EU = Type II**(B.II.d.1.e — 승인 규격 범위 밖 변경), grouping, PRAC 영향 확인, QP·PQR. 핵심은 **임상 관련성 결여 증명**(잃은 로트 수가 아님), 상한·안전 지표 유지, 변경 후 모니터링.
- **pre-IND "정량 역가 없음 — Phase 1 역가 보증은?"**: 인정 — 2011은 IND 초기에도 **어떤 측정** 요구. 응답: ① MOA 가설·CQA ② Phase 1 역가 = **적격 반정량 기능 시험**(보고값/넓은 임시 기준) + 대리 분석 병행 ③ 공정 일관성 근거(2023 전략: 원료·세포 은행·파라미터·공정 중 시험의 재현성) ④ 개발 계획(Phase 1 로트 상관·변동 → Phase 2 정량 → Phase 3 전 검증, 참조 은행) ⑤ 임상 로트 보존 샘플 ⑥ FAQ 2026·유연성 성명(단계 비례). 피할 것: "정체성 마커로 역가 대체", "검증 완료 후 Phase 1". EU: 22473/2025 — 탐색은 적격, 확증 전 확립.

## 10. 흔한 혼동
1. **ISCT 마커 통과 = 역가?** 정체성. 역가는 기능.
2. **현행 guidance = 2026 최종?** 기준일 이후 — 2011 + 2023 초안.
3. **Phase 1엔 역가 불필요?** 어떤 측정은 필요(hold 사유).
4. **대리 분석만으로 역가?** 생물 활성 상관 입증 시만.
5. **3계열 분화능 = MSC 역가?** 특성화(MOA 아니면 역가 아님).
6. **역가 OOS면 재시험으로 합격?** 조사 먼저, 사전 정의 계획만.
7. **2026 성명으로 규격 완화가 CBE?** PAS(EU Type II).
8. **EU엔 610.10이 없으니 느슨?** Annex I·Ph. Eur.·QP로 집행.
9. **참조 물질은 하나?** 1차·작업 2단계 + 교체 프로토콜.
10. **안정성 프로토콜에 matrix 전부?** 안정성 지시 요소 선택.

## 11. 네 분야에 올려놓기
**MSC-EV(BPD) Potency Assurance Strategy(2023 구조)**: **QTPP** — 조산아 기관 내/정맥 EV, 항염·폐포 발달 지원·혈관 보호로 BPD 중증도 감소, 동결 보관·해동 후 X시간. **CQA** — 항염 활성(대식세포 TNF-α 억제 %), 내피 보호, 입자 수·단백/입자 비, 핵심 cargo(선정 miRNA·단백), 크기·마커(정체성). **MOA** — paracrine 면역조절·내피 신호(다중 → matrix). **통제 1 원료** — 공여자 적격(1271), **모세포 은행 역가 출하**(ISCT 2016 IDO/PGE2), 배지·보조 물질(5.2.12), passage 상한. **통제 2 공정 설계** — 배양(priming)·수확 시점·분리법(TFF/크로마토) 파라미터 ↔ EV 역가 상관, QbD 범위. **통제 3 공정 중** — 입자 수율·단백/입자, 오염 마커(albumin) 한도. **통제 4 출하 matrix** — 기능 시험 1–2개(정량 상대 역가) + 대리 cargo 정량(상관 입증 후), 정체성 마커, 순도, 무균·엔도톡신·마이코플라즈마. **분석 수명주기** — ATP(Q14) → 적격(Phase 1) → 검증(Q2(R2), BLA), 참조 2단계, 안정성 지시(Q1). **변경 관리** — Q5E·comparability protocol, 2026 성명으로 규격 재평가. **EU** — 생물의약품(ATMP면 Part IV·CAT), Ph. Eur. 2.7.29 비적용(세포 없음), Q6B 규격.
