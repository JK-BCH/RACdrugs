# Ch.27 — Dossier: 형식은 같고(CTD) 요구는 다르다(Module 1·지역 법) — 그리고 뭐가 빠지면 접수가 안 되나

> **덱:** Ch27_1(개념·구조) + Ch27_2(세부·상황형), 40장. 이틀 분량 한 장.
> **검증 메모(2026-11-22):** ICH **M4Q(R2)** Step 2 2025, Step 4 예정 **2027-06** → 기준일엔 **M4Q(R1)**; eCTD·Module 1(Ch25); Hatch-Waxman·PIP compliance·505(o)(4)·RMP·ERA·Part 54(타 장) — 두 덱 메모 기준. M4 5모듈, 314.50·601.2, Dir 2001/83 Annex I Part I–IV, NtA Vol 2B, GVP V RMP, 3.2.R, RTF 314.101(d), 74-day letter, GDUFA RTR, 314.50(f) CRF, Form 3674, 314.53, EU validation·GMP 증명·QP declaration·1.5.3·Day -14는 ○.

## 학습 목표
1. **CTD 5모듈**의 구조(2.x·3.2.S/P/A/R·4·5.3.x)와 **조화된 것/안 된 것**을 안다.
2. **Overview vs Summary**, **3.2.R 지역 문서**, Q3D·Q5E·안정성 데이터의 **위치**를 말한다.
3. 미국 **314.50·601.2**가 CTD 어디에 매핑되는지(356h·특허 314.53·재무·debarment·3674·ISS/ISE·CRF), **RTF(314.101(d))·74-day letter·RTR**을 안다.
4. EU **Annex I Part I–IV**, **NtA Vol 2B Module 1**, **validation 체크리스트**(RMP·PIP compliance·GMP/QP·ERA·전문가·1.5.3)를 쓴다.
5. 미국·EU dossier 철학 차이(원데이터 재분석 vs 평가보고서; 특허·독점 vs 데이터 보호)를 설명한다.

## 1. CTD — 한 번 쓰고 재사용
| 모듈 | 내용 | 조화 |
|---|---|---|
| **1** | 지역 행정·처방 정보 | **비조화**(당국별) |
| **2** | 요약: 2.1 TOC · 2.2 Introduction · **2.3 QOS** · **2.4 Nonclinical Overview** · **2.5 Clinical Overview** · **2.6** Nonclinical Written·Tabulated Summaries · **2.7** Clinical Summary | ICH |
| **3** | Quality: **3.2.S** 원료 · **3.2.P** 완제 · **3.2.A** 부록 · **3.2.R** 지역 · 3.3 문헌 | ICH |
| **4** | Nonclinical: 4.2.1 약리 · 4.2.2 PK · 4.2.3 독성 · 4.3 문헌 | ICH |
| **5** | Clinical: 5.2 표 · **5.3.1** BA/BE · 5.3.2 생체물질 PK · 5.3.3 PK · 5.3.4 PD · **5.3.5** 효능·안전성(.1 controlled, .2 uncontrolled, **.3 복수 시험 분석 = ISS/ISE**, .4 기타) · **5.3.6** 시판 후 · **5.3.7** CRF·환자 목록 · 5.4 문헌 | ICH |

왜 만들었나(M4, 2000): 지역마다 구조가 달라 같은 데이터를 **세 번 재편집** → 구조·순서·요약 형식 통일, eCTD(M8)의 기반. 조화하지 **않은** 것: **내용 요건**(어떤 시험이 필요한가 — 지역 법), **Module 1**, 절차·시계. **M2–M5는 공유, Module 1만 바꿔 끼운다.** 비ICH도 대부분 CTD(캐나다·스위스·호주·WHO PQ·한국·중국); **ASEAN은 ACTD**(Part I 행정·II 품질·III 비임상·IV 임상 — 구조 다르나 매핑 가능).

## 2. Module 2 — 심사자가 먼저 읽는 것
- **Overview(2.4·2.5)** = **해석·논증**(개발 전략, 결과의 의미, B/R, 한계 — 비판적 평가, 짧게, 저자 의견). **Summary(2.6·2.7)** = **사실 요약**(표·텍스트, 해석 최소, 보고서와 숫자 일치). 분리 이유: 심사자가 논거와 데이터를 구분해 읽고 요약은 보고서로 추적.
- **2.5.6 Benefits and Risks Conclusions**(M4E(R2), Ch.24). 2.5.1 개발 근거에 505(b)(2)/hybrid 의존 논리.
- Module 2 품질이 심사 질문 수를 결정한다.

## 3. Module 3 — 구조와 지역 문서
- **3.2.S**: S.1 일반 · S.2 제조(제조자·공정·원료 통제·중요 단계·**S.2.6 공정 개발**) · S.3 특성(구조·불순물) · S.4 규격·분석법·검증·배치 분석·정당화 · S.5 기준물질 · S.6 용기 · S.7 안정성.
- **3.2.P**: P.1 조성 · **P.2 약제학적 개발**(P.2.3 공정 개발) · P.3 제조 · P.4 부형제 · P.5 규격(**P.5.6 정당화**) · P.6 기준물질 · P.7 용기 · P.8 안정성.
- **3.2.A**: **A.1** Facilities and Equipment(생물의약품 시설·장비) · **A.2** Adventitious Agents(비바이러스 — TSE·마이코플라즈마·박테리아; 바이러스 — 세포주·공정 제거 검증) · **A.3** 신규 부형제.
- **3.2.R 지역**: **미국** — executed batch records(대표 배치), method validation package, comparability protocols, 샘플 정보. **EU** — process validation scheme, medical device(DDC) 정보·NB opinion, CEP·TSE 적합 증명, 용기 적합성.
- **위치 규칙**: Q3D 원소불순물 위험평가 → **3.2.P.5.6**(요약) + 상세 P.2/3.2.R; **Q5E comparability**(임상 공정 vs 상용 공정) → **3.2.S.2.6 / 3.2.P.2.3** + 2.3·2.5, 미국은 3.2.R comparability protocol; 안정성 → **3.2.P.8**: 등록 시 **1차 배치 3개, 장기 ≥12개월 + 가속 6개월**, 유효기간 외삽은 Q1E(장기 데이터의 **2배까지, 최대 +12개월**) — 6개월 데이터로 24개월 불가(ICH Q1 통합판 2026-06 Step 4도 같은 원칙).
- **M4Q(R2)**: Step 2 초안 2025, Step 4 예정 2027-06 → 기준일엔 **R1**. 목표: Module 3·2.3을 구조화 데이터 친화적으로(control strategy·Q12 ECs 반영, 중복 제거, 신규 모달리티).

## 4. Module 4·5 — 배치 예
executed batch records → 3.2.R(US) / ISS → **5.3.5.3** + 2.7.4 / 문헌 pivotal → **5.4**(+5.3.5.4, 2.5 논거) / 외래인자 → 3.2.A.2 / 환경 → 미국 **1.12.14**, EU **1.6**. 505(b)(2): 신청 유형·참조 제품 → 1.2, 특허 certification → 1.3.5, 의존 논거 → 2.5(2.5.1), 새 PK → 5.3.1/5.3.3 + 2.7.1/2.7.2, 비임상은 참조·문헌(4.3) + bridging.

## 5. 미국 — 314.50/601.2와 Module 1, 그리고 RTF
### 5.1 매핑
| 314.50 요건 | CTD |
|---|---|
| **Form 356h**, 3674 | 1.1 |
| debarment 진술(FD&C 306(k)) | 1.3.3 |
| 재무 공개 **3454/3455**(21 CFR 54) | 1.3.4 |
| 특허 정보·certification(314.53, 314.50(i)) | 1.3.5 |
| 소아 평가·deferral/waiver(505B) | 1.9 |
| 환경(Part 25) | 1.12.14 |
| 라벨(SPL) | 1.14 |
| **ISS**(314.50(d)(5)(vi)(a)) / **ISE**(314.50(d)(5)(v)) | 5.3.5.3 + 2.7 |
| CRF 표(f)(1) = datasets; **CRF 원본(f)(2) — 사망·AE 중단 피험자 필수** | 5.3.7 |

- **특허(314.53)**: 약물 **물질·제품·사용 방법** 특허(공정·포장·대사물 제외)를 **NDA 제출 시**(Form 3542a), 승인 후 **30일 내 Form 3542** → Orange Book; 승인 후 발행 특허는 **발행 30일 내**. 부적격 특허(기기 구성품·공정)를 올리면 PIV·30-month stay를 부당 유발 → **FTC 2023–24 수백 건 delisting 이의**, "약물 자체를 청구하는 특허"만 적격 재확인 → 내부 적격성 검토·자진 삭제.
- **Form 3674**: FDAAA 801(ClinicalTrials.gov 등록·결과 보고) 준수 인증 — 늦은 등록은 인증 내용에 영향, 허위 인증은 민사·형사.
- **왜 ISS/ISE·CRF인가**: 미국 심사는 **FDA가 원데이터를 직접 재분석**(datasets·SAS)하는 전통 → 통합 분석과 사망·중단 CRF로 자체 검증, CDISC 의무도 미국만. EU는 **rapporteur가 신청자의 요약·보고서를 평가**하고 필요 시 요청 → 2.7과 CSR 부록으로 충분.
- **미국엔 전문가 선언이 없다** — 356h는 행정 양식, 책임은 신청자 서명.

### 5.2 접수 문턱
| | 내용 |
|---|---|
| **RTF**(314.101(d)) | ① 불완전(필수 섹션·CRF·ISS/ISE·데이터 누락) ② 형식 불량(eCTD 미준수·조직 불량·영어 아님) ③ 명백히 승인 불가(법적 근거·데이터 전무, 505(b)(2) 참조 부적절) ④ 수수료 미납. **60일 filing review**에서 결정, RTF면 PDUFA 시계 미시작 |
| **74-day letter** | filed 상태에서 filing 쟁점 통지(예: ISE 누락, define.xml 누락) → 지정 기한 내 amendment; **major amendment**면 목표일 3개월 연장 가능 |
| **ANDA RTR**(GDUFA) | substantially complete 아니면 refuse-to-receive — **major deficiency ≥1**(BE 누락·라벨·DMF LOA) 또는 **minor ≥10**; minor ≤9는 7 calendar days 내 보완 기회; RTR이면 목표일 미시작·수수료 일부 소멸 |

같은 M2–M5로 EU는 validation 통과, 미국은 RTF가 나는 미국 고유 원인: ISS/ISE·datasets(define.xml) 누락 / 사망·중단 CRF 미제출 / 356h·3674·3454/3455·debarment·특허 누락 또는 eCTD high error.

### 6.3 Validation 체크리스트 (Day 1의 전제)
eAF 완결·**수수료** / **PI**(QRD v10.4, mock-ups, Braille, 가독성 검사) / **RMP** 1.8.2 + PSMF 요약 / **PIP compliance check**(1.10; Art 7 Reg 1901/2006 — 없으면 validation 불가, 제출 **최소 60일 전** 요청 권장) / **GMP 증명 + QP declaration**(완제 QP가 API 제조소 GMP를 감사 근거로 선언, Art 8(3)(ha); API 제조소 자체 GMP certificate는 원칙상 의무 아님; 완제 제조소는 EU 제조 허가 또는 제3국이면 EU 당국 사찰 증명(보통 3년 내) 또는 MRA — 4년 지난 사찰이면 사전 승인 사찰 요청; 수입 API는 **Art 46b** written confirmation) / **ERA** 1.6 / **전문가 선언** 1.4 / 법적 근거·데이터 보호 주장 1.5 / orphan 1.7 / Module 2–5 완결·eCTD 검증. **Day -14 관행**: CHMP 시작 약 2주 전 제출 → validation → Day 1; 미비면 보완 요청, 해결 전까지 Day 1 미시작(다음 달로 밀림).

### 6.4 독점 주장의 철학 차이
미국: 독점은 **법정 자동**(NCE 5·3년·orphan 7·pediatric 6개월)이지만 1.3.5에 요청·근거, Orange Book 코드 — 특허 연계와 결합된 **시장 진입 통제**. EU: **데이터 보호 8+2+1** 법정, 특허는 dossier 밖, +1년은 1.5.3에서 **임상적 이익 입증**으로 — 증거 기반 보상. 미국은 "특허·독점 전략", EU는 "데이터 보호 + 가격·급여"가 전쟁터.

## 8. 흔한 혼동
1. **CTD가 내용 요건도 조화?** 형식만. 내용·Module 1·절차는 지역.
2. **Overview = Summary?** 해석 vs 사실.
3. **6개월 안정성으로 24개월?** 불가(Q1E).
4. **EU도 ISS/ISE·CRF 필수?** 2.7로 충분, CRF는 요청 시.
5. **API 제조소 GMP certificate 필수?** QP declaration이 핵심(certificate는 원칙상 아님).
6. **PIP compliance 없이 제출?** validation 불가.
7. **미국에 전문가 선언?** 없다 — EU 1.4.
8. **특허는 EU dossier에?** 밖. 데이터 보호만.
9. **74-day letter = RTF?** 아니다 — filed 후 쟁점 통지.
10. **ACTD = CTD?** 구조 다름(Part I–IV), 매핑 가능.

## 9. 네 분야에 올려놓기
EU: ATMP면 **Annex I Part IV** 위험 기반 정당화 문서가 validation에서 요구(분류는 CAT 자문 먼저). 미국 CBER: 3.2.S/P/A에 **세포 은행·공여자 적격성**(1271 Subpart C), 공정 중 통제·수율, **potency 매트릭스**(610.10), 외래인자(3.2.A.2), comparability, 동결보존·운송 검증, 규격(세포 수/EV 단위·순도·정체); Module 5에 **장기 추적 계획**(LTFU 제품별 5–15년), REMS/등록부(1.16/1.9), IFU. **동시 제출 critical path**: Module 3 lock(공정·규격·안정성 cutoff) → 4·5 완결 → Module 2(2.5.6) → 지역 Module 1 병행(미국 356h·특허·재무·SPL / EU eAF·QRD·RMP·ERA·PIP compliance·전문가) → 3.2.R → eCTD 빌드·검증 → pre-NDA/pre-submission 구조 합의 → 제출. **EU 3개월 전 체크**: eligibility·rapporteur·제출일, PIP compliance, GMP·QP·46b, RMP·PSMF, PI(QRD v10.4·Braille·가독성), ERA, 전문가 CV, eAF·SPOR ID, 수수료·orphan 감면, eCTD 검증.
