> **덱:** Ch35_1(개념·구조) + Ch35_2(세부·상황형), 40장. 이틀 분량 한 장.

## 학습 목표
1. 미국 **labeling vs advertising**, **202.1**(fair balance·brief summary·major statement + adequate provision·CCN·reminder·help-seeking), **312.7**, **Form 2253**(AA 사전 30일)을 적용한다.
2. **Caronia/Amarin → SIUU 2025·CFL 2018·Payor 2018·unsolicited 2011**의 통로와 여전히 금지되는 것을 구분한다.
3. **AKS·FCA·Sunshine·PhRMA·PDMA**와 **2025–26 DTC 집행 환경**의 사실/예정을 가른다.
4. EU **Title VIII Arts 86–100**(87(1)/(2), 88, 89/90, 91/92, 94–96, 97), **Dir 2006/114**, **EFPIA·ABPI/PMCPA**를 쓴다.
5. 글로벌(WHO 1988·IFPMA·캐나다·일본·호주)과 **글로벌 claims matrix·디지털 구조**를 설계한다.

## 1. 네 축
**누가 보는가(HCP vs 공중) × 어디서(국가·매체) × 승인 상태 × 주장 근거**. EU는 **공중 = 처방약 금지(Art 88)**, HCP는 **SmPC 범위(87(2)·91)**; 미국은 공중 허용이되 **fair balance·major statement·CCN**, HCP는 **substantial evidence 또는 CFL/SIUU**. 돈이 오가는 접점은 **법(Art 94–96 / AKS·FCA·Sunshine) + 코드** 이중 규제 — 답은 늘 **FMV·서면 계약·정당한 필요·공개·오락 금지·배우자 금지**.

## 2. 미국 — 법 구조와 형식 규칙
- **201(m) labeling** = 제품에 부착·동반(accompanying)하는 모든 문서(브로슈어·웹·영업 자료 → promotional labeling, **201.100(d) full PI 동봉**); **광고** = 그 외 매체. 둘 다 **502(a)**(허위·오도 = misbranded) + **201(n)**(중요 사실 누락 = misleading). **502(n)**: 처방약 광고에 확립명·정량 조성·**brief summary** + FDA 규정. OTC 광고는 **FTC**(1971 MOU). **Lanham Act §43(a)** 경쟁사 소송(POM 2014).

| 202.1 규칙 | 내용 |
|---|---|
| **Fair balance** | 효능 vs 위험 정보의 **비중·현저성** 균형 |
| **인쇄** | **brief summary**(부작용·금기·효과) |
| **방송**(202.1(e)(1)) | **major statement**(주요 위험 구두) + **adequate provision**(brief summary 대신 PI 접근: 수신자 부담 전화·웹·동시 인쇄 광고·HCP 상담 — **4요소**, 기준일 유효) |
| **CCN**(2024-11-20 준수) | ① 소비자 친화 언어 ② 이해 가능 음성(음량·발음·속도) ③ TV **dual modality**(동시 자막) ④ 텍스트 가독(크기·대비·지속) ⑤ major statement 중 **방해 요소 금지**; TV·라디오 형식(인터넷 영상 포함, 인쇄·배너 제외); 위반 502(n) |
| **Reminder**(202.1(e)(2)(i)) | **이름(필요시 가격·제형)만**, 적응증·효능·용량 없음 → brief summary 면제; **boxed warning 제품 불가** |
| **Help-seeking** | 질병 인식, 제품명 없음 → 광고 규정 밖(제품 광고와 **인접 배치 시 하나로** 봄) |
| (e)(6) | 허위·오도 예시 — 근거 없는 비교 우위, 선별 인용 |

- **312.7**: 승인 전 판촉 금지(임상 안전·효능 대표 진술 금지). 관행 예외 — **institutional / coming soon**(제품명·회사명·승인 임박만, 적응증·효능 주장 없음, 질병 인식 광고와 묶지 않기).
- **Form 2253**(314.81(b)(3)(i), 601.12(f)(4), ANDA 314.98): 모든 판촉 labeling·광고를 **최초 배포 시**(동시) 제출 — 사전 승인 아님(사후 감시), eCTD **1.15**(의무 연도 확인). **예외 사전 제출**: **AA 제품**(314.550/601.45) — 승인 전엔 승인 후 120일 내 사용 자료를 **승인 ≥30일 전**, 승인 후도 **배포 ≥30일 전**(FDA 해제까지); REMS·WL 후 요구 시. 검토 **OPDP**(CDER)·**APLB**(CBER — 생물·세포유전자). 자발 **advisory comments**(출시 자료·TV 권장).
- **집행**: **Untitled letter**(경미·초범 — 중단, **15 working days** 응답: 동의·중단일·유사 자료 목록) vs **Warning Letter**(중대·반복·BW 누락·대규모 DTC — 중단 + **corrective advertising·교정 Dear HCP**(같은 매체·대상), 15 wd, 공개, 미이행 시 압류·금지명령·DOJ/FCA, 신청 심사 영향). **Bad Ad Program**(2010). 응답 후 MLR 재점검·2253 이력·유사 자료 전수 회수.
- **60초 TV 광고 설계**: 라벨 적응증·substantial evidence·대표성 → **major statement(CCN 5)** → **adequate provision 4요소** → fair balance(시간·현저성) → 체험담·배우 의사 표기, 근거 없는 가격·비교 금지 → MLR → OPDP advisory → **2253 최초 방영 시**(AA 30일 전) → 기록.

## 3. 미국 — 표현의 자유와 허가 외 정보의 통로
- **판례**: **Sorrell**(2011) 상업적 발언 보호; **Caronia**(2d Cir 2012) — 영업사원의 **진실·비오도 허가 외 발언 자체** 처벌은 1조 위반, 발언은 **intended use 증거**로만; **Amarin**(SDNY 2015) 선언적 구제 → FDA 합의. FDA 대응 = 처벌 대신 **안전 항구 guidance**.

| 통로 | 조건 |
|---|---|
| **SIUU**(2025-01-07 최종; 2023-10·2014 reprints 초안 대체) | 회사가 **먼저** HCP에 보내는 **승인 제품 허가 외 사용 과학 정보**. 기준 **scientifically sound**(설계·수행·분석·통계) + **clinically relevant**(진료 결정 유의미) — 단일 사례·초기 탐색·동물만 불가. **공개 문구**: FDA 미승인·안전성/효능 미확립, 승인 적응증·BW·주요 위험, 한계·상반 증거, 자금·이해관계, **라벨 사본**. 형식: peer-reviewed 재인쇄·독립 진료지침·참고서·**회사 생성 발표 자료**(원 출처 충실); **판촉과 분리**(별 웹페이지·직접 링크 자제), 글자 제한 플랫폼 미사용 |
| **CFL**(2018-06) | 라벨에 **문자 그대로 없는 정보**도 ① 같은 적응증·인구·용법·용량(새 intended use 아님) ② 위해 가능성 ↑ 없음 ③ 라벨대로 안전·효과적 사용 가능 → 판촉 가능(추가 endpoint·장기·발현 시간·PRO·편의성·기전); 증거는 "과학적으로 적절·통계적으로 건전" + 공개 |
| **Payor**(2018-06, FDAMA 114 → 502(a)) | **HCEI**(승인 적응증 **관련** 경제 분석) → **competent and reliable scientific evidence**, 가정·모델·한계·자금 공개, 대상 payor·제제위원회(HCP·소비자 아님); **미승인 사용·미승인 제품**(심사 중)도 payor에 **사실적·비오도 + 미승인 공개**(PIE) 가능; RWE 지속률은 HCEI/CFL 범위 |
| **Unsolicited requests**(2011-12 초안) | HCP **자발 질문** → **의학부 1:1·비판촉·균형·기록**; 영업이 유도·전달하면 판촉 |
| **Social media**(2014 초안 2건) | 글자 제한 플랫폼에 효능 + 최소 위험(BW) + PI 직접 링크를 **같은 포스트**에 못 담으면 효능 주장 금지(reminder 수준); 회사 의뢰·보수·통제 influencer = 회사 광고(링크 참조는 fair balance 불충분, FTC 관계 공개); 환자 체험담 = labeling(대표성·위험 정보·2253) |

- **MSL 경계**: 의학부 소속·비영업 평가(처방 KPI 금지), 과학 교류, unsolicited 1:1, **학회 부스**는 과학 부스("investigational"·"not approved", 포스터·초록) vs 판촉 부스(승인 적응증·국가 라벨) — EFPIA 국제 행사는 개최국 코드 + 승인 상태 표기, OPDP는 부스 자료도 labeling; IIS 지원은 의학부·FMV·판촉 무관. 금지선: 준비된 허가 외 발표를 "요청받았다"고 포장, 영업 동행 허가 외 대화.
- **여전히 금지**: 허가 외 **판촉**(주장·요약·암시로 새 intended use → 201.128/801.4), **오도·불균형**, 허가 외 유도 **경제적 인센티브**(AKS·FCA), 승인 전 효능 주장(312.7). 보호되는 건 **정보**, 처벌되는 건 **의도된 사용의 조작**.

## 4. 미국 — 돈의 흐름, 집행, 2025–26 환경
- **AKS**(42 USC 1320a-7b(b)): 연방 프로그램 처방·구매 유도 **보수**(현금·식사·연사비·과다 컨설팅·무료 서비스) 금지 → 형사·민사·배제; **안전 항구**(FMV 서면 계약·개인 서비스·할인); PhRMA Code 준수가 OIG 평가 요소. **FCA**: 허가 외 판촉·리베이트로 유발된 Medicare/Medicaid 청구 = 허위 청구, **qui tam**(15–30%), **3배 + 건당 벌금**, DOJ 합의 + **CIA**(보통 5년). **Sunshine/Open Payments**(ACA, 2013~; 2022부터 PA·NP 등 추가). **PhRMA Code 2022-01-01**: 오락·레저 금지, 적정 식사(사무실 내), 연사 프로그램 제한, 컨설팅 FMV, 선물 금지. **OIG CPG**(2003 제약 + General 2023 **7요소**: 정책·절차 / 책임자·위원회 / 교육 / 소통 채널(핫라인) / 모니터링·감사 / 징계 / 시정·조사 대응).
- **내부고발(소아 허가 외 + 연사비)** 노출: FDA misbranding(502(a)/(f), 201.128) → WL·압류·303(Park) / DOJ FCA qui tam·형사 / AKS 배제 / OIG CIA / 주 검찰·타국 조사. Caronia는 진실·비오도 발언만 보호 — 보수 연계·오도·안전성 미확립 주장은 밖. 완화 = CPG 7요소 + 연사 프로그램 통제(FMV·참석 필요성·반복 금지·식사 한도)·MSL/영업 분리·자발 공개.
- **PSP·copay·환자단체**: PSP는 AKS(제품 사용에 부수·의학적 필요·보험 무관, HCP 혜택 금지, HIPAA, 판촉 분리·2253); **copay card는 상업 보험자만 — Medicare Part D·Medicaid 대상은 AKS 위반**(OIG 2014 SFA), 자격 확인·"not valid for government beneficiaries"; EU 환자단체 후원은 EFPIA PO Code(서면 계약·독립성·처방약 판촉 금지·ToV 공개).
- **PDMA 1987 / 21 CFR 203**: 샘플은 **면허 의료인 서면 요청**(203.30), **수령 확인 서명**, 제조자 **기록·재고·분실 보고**, **판매·거래 금지**(연방 범죄), 대리 요청 불가.
- **2025–26 DTC**: 메모(2025-09-09)는 **집행 지시·규칙 검토** — 법(502(n))을 바꾸지 못하고 **전면 금지는 1조 장벽**. FDA가 기준일 전 실제로 한 것: 기존 202.1 위반 **집행 급증**(약 100 cease-and-desist + 2025-09-16 60+ WL, 소셜·influencer·텔레헬스), **adequate provision 폐지 의향**(NPRM 2026-12 예정 — **미공표**), 위험 정보 분량·제시 지적 강화. **현행법**: DTC **합법**, 방송 major statement(CCN) + adequate provision, 인쇄 brief summary, 2253 사후. 왜 미국·뉴질랜드만 DTC? 미국 법은 금지한 적 없음 + 1조(Virginia Pharmacy 1976·Sorrell) + 1997 방송 guidance의 adequate provision 해석 + 환자 자율·민간 보험; EU Art 88은 처방 = 전문 판단·공적 지출 보호.

- **Dir 2006/114 비교 광고**: 비오도·같은 필요 제품·**중요·관련·검증 가능·대표적 특성 객관 비교**·비하 금지·혼동 금지. 간접 비교(네트워크 메타분석) 우위 주장은 **불가**(광고), 과학 정보로만; 미국도 202.1(e)(6)(ii) 비교 우위엔 **head-to-head substantial evidence**(교차 시험 비교 불가), Lanham 위험. 대안: SmPC 효능 데이터·"직접 비교 없음"·기전·투여 경로 차이(사실).

### 5.1 EU 상황 예
- **독일 신제품**: 질병 인식 TV 스팟 — Art 86(2) 제외(제품 직접·간접 언급 없을 때), 단일 치료 옵션·브랜드 색·동시 캠페인으로 특정되면 **Art 88 위반**(HWG 엄격); EC 결정 보도자료 — 기업·재무 사실 전달은 관행 허용, 환자 행동 권유·과장·공중 배포면 광고(PMCPA는 보도자료도 코드 적용); 브랜드 환자 웹 — **DTC 금지** → PL·SmPC·승인 RMP 자료만, HCP 섹션 접근 통제.
- **CHMP 긍정 의견 단계**: Art 87(1) MA(EC 결정) 전 광고 금지 → 보도자료 절제, 환자단체 "의사에게 문의" 삭제(87(1)+88 이중 위반, 회사 제공·후원이면 회사 책임), 미국 coming soon은 제품명·회사명만.
- **학회 출장**: 비즈니스 클래스·배우자·리조트·갈라 → Art 94(2)/95 + EFPIA: 등록·합리적 여행·숙박·식사만, **오락·레저·리조트 금지**, **배우자 불가**, **소속국 + 개최국 코드** 모두, ToV 공개; 가능한 안 = 이코노미·회의장 호텔·공식 만찬·배우자 제외.
- **HCO 자문회의(독일)**: 정당한 필요 문서화 → 서면 계약·FMV → 병원 사전 승인(StGB §299a/b) → 적정 접대 → **ToV 공개**(개인별 동의 또는 합산, **다음 해 6/30**, 3년) → 기록. 미국 대응 AKS 안전 항구·Sunshine·PhRMA.
- **프랑스·독일 샘플 프로그램**: Art 96 조건 전부 + 요청서 양식·CRM 수량 카운터(국가 한도 하드 스톱)·배치 추적·레프 교육·감사; 수치는 국가 규칙 확인.

## 7. 글로벌
**WHO Ethical Criteria 1988**: 국가 보건 정책 일치, 정보 신뢰·정확·균형·최신·검증 가능, 영업사원·샘플(소량·요청)·학술 후원(부수적)·시판 후 연구(판촉 위장 금지)·수출 제품 동일 기준 — IFPMA·국가법의 준거. **DTC 지도**: 처방약 DTC 허용 **미국·뉴질랜드**만; **캐나다** C.01.044(명칭·가격·수량만), HCP 광고 **PAAB** 사전 심의; **호주** 금지, Medicines Australia Code; **일본** PMD Act(허위·과대·미승인 금지) + DTC 금지 + MHLW 2019 + JPMA; 한국·중국·브라질 금지. **일본에서 미국 detail aid 번역 사용**: 添付文書 범위로 주장 축소(CFL 추가 삭제), MHLW 사내 심사·미승인 정보 금지·모니터링, PMD Act 66–68, JPMA 투명성; 런치 세미나는 公正競争規約(정보 제공에 부수·상한)·오락·선물 금지·강연료 FMV·공개.

## 8. 비교와 설계
- **EU가 더 엄격**: DTC 전면 금지 / **87(2) SmPC 일치**(CFL·SIUU 같은 공식 통로 없음) / 코드 사전 심의 문화 + 공개 판정 / 접대·선물·ToV 세부. **미국이 더 엄격**: fair balance·brief summary·major statement·**CCN 같은 정량적 형식 규정** / 2253 전수 사후 감시 + 공개 서신 / **형사·FCA·AKS 금전 제재 규모** / 312.7 적용 폭. → 글로벌 자료는 **EU 기준으로 내용 범위**, **미국 기준으로 형식·균형**, 금전 접점은 미국 법 수준.

## 11. 흔한 혼동
1. **2253 = 사전 승인?** 사후 제출(AA만 30일 전).
2. **Reminder ad는 어디나?** BW 제품 불가.
3. **adequate provision 폐지됐다?** 미공표 — 유효.
4. **Caronia로 허가 외 판촉 자유?** 정보만 보호, intended use 조작은 처벌.
5. **SIUU = unsolicited requests?** SIUU는 회사 **발신**, unsolicited는 HCP **요청**.
6. **EU 질병 인식 = 광고?** 제품 언급 없으면 Art 86(2) 제외.
7. **EU에 CFL 같은 통로?** 없음 — 87(2).
8. **EFPIA 공개 기한?** 다음 해 6/30.
9. **copay card는 모두 OK?** Part D·Medicaid는 AKS.
10. **DTC 허용국?** 미국·뉴질랜드만.
11. **교차 시험 비교 우위?** 양쪽 불가.

## 12. 네 분야에 올려놓기
**승인 전 EV 회사**: 웹 "폐 조직을 재생한다" = **312.7 + Art 87(1)** → 삭제, 허용은 "investigational, not approved" 파이프라인·기전·시험 등록; 투자자 자료는 공시 채널·면책·한계; 학회는 과학 포스터만(브로슈어 불가, 의학부 운영). **승인 후 론칭 매트릭스**: **미국** — HCP 라벨 적응증·substantial evidence, 라벨 밖 CFL/SIUU, full PI(201.100(d)); 공중 DTC 허용(fair balance·major statement·CCN·소셜 2014·2025 환경); 돈 AKS·Sunshine·PhRMA, copay Part D 제외; **2253 최초 배포**(AA 30일 전), BLA라 **APLB**. **EU** — Art 91/92 + 87(2), 역삼각 **5년** 표시·홍보 금지, 국가 abbreviated PI; **Art 88 금지**, 질병 인식(86(2))·승인 환자 자료; Art 94–96 + EFPIA ToV 6/30·PO Code; 국가 사전 심의·코드 서명. **일본** — 添付文書 범위, MHLW 2019 사내 심사, JPMA 2025, DTC 금지, 公正競争規約. **공통 축** — 라벨 문구 차이 → 주장별 증거·공개 문구·지역 승인 열, 단일 MLR, 라벨 갱신·신호 시 자료 회수·재승인, PV 연동(소셜 screening). "재생"이 라벨에 없으면 CFL 3요인 검토 후에도 불가.
