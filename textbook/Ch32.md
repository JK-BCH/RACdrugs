# Ch.32 — GMP와 사찰: 결함이 아니라 "방법·시스템"을 심판한다

> **덱:** Ch32_1(개념·구조) + Ch32_2(세부·상황형), 40장. 이틀 분량 한 장.
> **검증 메모(2026-11-22):** FDA **RRA** Q&A 최종 **2025-06-26**; 해외 제조소 **불시 사찰 확대 2025-05**; EU **Ch.4·Annex 11 개정 + Annex 22(AI)** 초안 2025-07-07, 의견수렴 2025-10-07 종료, **최종 미공표** → 시험은 **2011년 판**; **EU-US MRA** 인체용 **2019-07-11** 전 회원국 인정(Ch.2 덱은 07-12로 표기 — 날짜 확인 필요), 동물용 **2023-05-31**(Decision 2536/2023); FDA **QMM** 자발 프로토타입 3년차(FR 2026-02-11) — 두 덱 메모 기준. 501(a)(2)(B)·704·501(j)·FDASIA 705, 210/211·600–680·1271 Subpart D·210.2(c), 483 15 business days(2009 FR)·NAI/VAI/OAI·WL 15 working days·Import Alert 66-40·CPGM 7356.002/7346.832·Park doctrine, Dir 2001/83 Arts 40/46/46b/47/48–52/111/116–118, Dir 2017/1572(2022-01-31)·2017/1569, Vol 4 Part I–IV(Part IV 2018-05-22)·Annex 1(2023-08-25)·15·16·21, Q7/Q9(R1)/Q10, PIC/S(FDA 2011-01-01)·PI 041-1(2021-07-01), WHO TRS 986/1033, FDA DI 2018-12·MHRA 2018-03, OOS 2006/Rev 1 2022-05, PV 2011, 200.10(b)·Ch.7/8/9·CPG 130.300·Annex 16 §3·AIP 1991·306 debarment·1271 Subpart F·재제출 Class 1/2·CoCP 등급·GMP 인증서 3년은 ○.

## 학습 목표
1. 미국 **501(a)(2)(B)·704·501(j)** 와 EU **Art 40 → 46/47 → Vol 4 → QP·Art 111** 계층을 쓰고, 규격 합격 배치도 adulterated가 되는 이유를 설명한다.
2. 미국 **사찰 유형·결과 사다리**(483 → 분류 → WL → Import Alert → consent decree → 303)와 EU **인증서/non-compliance → Art 116–118**을 적용한다.
3. **RRA·불시 사찰·MRA·QMM**의 2026 상태를 안다.
4. 사찰관이 보는 네 기록(**OOS·공정 검증·불만/결함·연간 검토**)과 **Annex 16 §3**, **CPG 130.300 vs Ch.9**를 구분한다.
5. **외주 책임**(200.10(b)·Ch.7·quality agreement), **PIC/S·data integrity·WHO**를 쓴다.

## 1. GMP는 법적 결과가 걸린 품질 규범
- **FD&C 501(a)(2)(B)**: 제조·가공·포장·보관의 **방법·시설·관리가 CGMP에 부합하지 않으면 adulterated** — 실제 결함 증명 불필요(1962 Kefauver-Harris의 **예방 기준**; 시험은 샘플링이라 결함을 다 못 잡음). **704** 사찰 권한(Form 482), **704(a)(4)** 사찰 전·대신 기록 요구(FDASIA §706). **501(j)** 사찰 **거부·지연·제한·방해 = adulterated**(FDASIA §707). **FDASIA §705** 위험 기반 사찰 주기(2년 주기 폐지). EU **Art 116**도 "제조가 MA 기재·GMP와 다르게"를 독립 사유로 둔다 → 규격 합격 배치도 압류·회수 대상, **Park doctrine**(US v. Park 1975, 303(a): 책임 있는 임원은 고의 없어도 개인 책임). 전략 함의: **배치가 아니라 시스템을 고친다**(Q10 PQS·CAPA 효과성), 응답은 "제품은 괜찮았다"가 아니라 "통제가 왜 실패했고 어떻게 바꿨나".

| 제품 | 미국 CGMP |
|---|---|
| 완제 | **21 CFR 210/211**(211.22 quality unit, 211.84, 211.100/113, 211.160–167, 211.180–198) |
| API | 211 직접 적용 아님 → **ICH Q7** guidance |
| 생물의약품 | **600–680** + 211 |
| HCT/P | **1271 Subpart D cGTP**(351 제품은 211 + cGTP) |
| Phase 1 IMP | **210.2(c)** 211 면제, 2008 Phase 1 guidance(cGTP는 면제 안 됨) |

## 2. EU — 법 계층, QP, Art 111
**Dir 2001/83 Art 40** 제조·수입 허가(**MIA**) → **Art 46** 제조자 의무(GMP, API GMP 확인(46(f)), 부형제 위험평가) · **46b** 제3국 API **written confirmation**(제조소별; **Art 111b 동등성 목록**(미국·일본·스위스·호주·브라질·이스라엘·한국) 면제, 또는 EU NCA 사찰 GMP 인증서) · **Art 47** → **Dir (EU) 2017/1572**(인체용, 2022-01-31, Dir 2003/94 대체), IMP는 **Delegated Reg 2017/1569** → **EudraLex Vol 4**: **Part I**(Ch 1–9) / **Part II**(API = Q7) / **Part III**(SMF·Q9·Q10) / **Part IV ATMP**(2018-05-22) / **Annex 1–21** — Annex 1 무균(2022-08-25 공표 → **2023-08-25** 시행, 8.123 동결건조기 2024-08-25, **CCS**), Annex 15(2015-10-01), **Annex 16 QP 인증**(2016-04-15), Annex 21 수입(2022-08-21). 배치 출하는 **Art 48–52 QP**.

- **Art 111**: NCA가 위험 기반으로 제조자·수입자·도매·API·부형제·제3국·PV 사찰(EMA는 CAP 사찰 조정) → **90일 내 GMP 인증서**(111(5), 통상 **3년** 표기) 또는 **non-compliance statement**(111(7)) → **EudraGMDP** 공개 → **Art 116**(MA 정지·철회·변경)·**117**(공급 금지·회수)·**118**(MIA 정지), CAP은 **Reg 726/2004 Art 20**. 스위스 → 인도 API 전환: 인도는 목록 밖 → **CDSCO written confirmation** + 46(f) 감사 + 52a 수입자 등록 + variation(B.I.a.1)·ASMF/CEP.
- **왜 EU는 인증서·QP, 미국은 둘 다 없나**: EU = **제품 출하 중심**(국가가 MIA로 제조소 허가, **QP 개인**이 배치마다 법적 책임·서명·위반 시 개인 징계·형사, 사찰 결과를 **인증서 문서**로 27개국이 공유). 미국 = **단일 당국·사찰 중심**(등록 510, 사찰 분류 NAI/VAI/OAI, BLA는 시설이 license에 포함, 책임은 **211.22 quality unit 조직**). 함의: EU 출하는 QP가 **독립적으로 거부**할 수 있는 보고선, 외부 사이트는 **감사·quality agreement**로 QP의 신뢰 근거(Annex 16 §1.7), 글로벌 QMS는 미국식 배치 기록 검토 + EU식 QP 인증 두 단계; MRA 국가 제조품은 재시험 면제여도 **QP 인증은 생략 불가**.
- **인증서 만료 임박·재사찰 미정**: 만료 = 비준수 선언은 아니지만 QP는 Annex 16 §1.7 근거 필요 → 사찰국에 재사찰·desk-based 평가 요청(코로나 시기 일괄 연장 선례), MAH/QP 자체 감사로 보강, Art 51 수입 시험, 46b 유효성, 대체 공급자 variation 검토.

## 3. 사찰 유형과 결과 사다리
### 3.1 미국 사찰 유형
| 유형 | 프로그램 | 내용 |
|---|---|---|
| **Surveillance(routine)** | CPGM **7356.002** | **6-system**(Quality 필수 + 1개 이상: Facilities & Equipment, Materials, Production, Packaging & Labeling, Laboratory Control); 주기 FDASIA 705 위험 기반 |
| **Pre-approval(PAI)** | CPGM **7346.832**(2022) | 3 objectives: **상업 생산 준비도 · 신청서 일치 · data integrity 감사**; 실패 → **CR**(시설 미적합) |
| **For-cause** | — | 리콜·FAR·불만 신호 |
| Follow-up/compliance | — | WL 후 CAPA 확인 |

### 3.2 결과 사다리
**Form 483**(관찰사항, 최종 결정 아님) → 응답 **15 business days**(2009 FR: 기한 내 응답은 WL 결정 전 검토) → EIR·**NAI/VAI/OAI**(사이트 전체 분류; 개별 483 항목엔 공식 등급 없음) → Untitled Letter / **Warning Letter**(**15 working days**, 공개, pending 신청 **승인 보류**) → **Import Alert 66-40**(DWPE: 입항 시 자동 억류, 반증 기회, refusal 801(a)) → **seizure(304)·injunction(302)·consent decree** → **303** 형사(Park). **AIP**(1991, 데이터 신뢰성 의심 시 심사 보류), **debarment**(306, GDEA 1992). **미국에 없는 것**: 의약품 CGMP **civil money penalty**(기기 303(f)(1)에만), **mandatory recall**(생물 351(d)·기기 518(e)·569D는 있음) → 리콜은 '자발', 압력은 압류·금지명령·공개.
- **483 응답 15일 계획**: 마감 전 제출(늦으면 WL 판단에 반영 안 됨) · 항목별 **근본 원인 → CAPA → 일정 → 효과성**, 개별 사례를 **시스템 전체로 확장** · DI 항목은 2018 Q&A 기대(범위·영향 조사·위험 평가·관리 전략, 제3자 감사) · 출하 배치 **제품 영향 평가**(FAR 3 working days) · 지킬 수 있는 날짜만, 업데이트 응답 · 사실 오류는 근거로 반박.
- **WL + pending ANDA**: 사이트 OAI → 승인 보류 → 서면 응답·정기 업데이트 → **follow-up 사찰**에서 VAI/NAI 재분류 → **close-out letter**(2009) → 승인 재개. **Import Alert 제거**: petition(CAPA 완료 증거·제3자 감사·영향 배치 조사) + **재사찰**(보통 필수), 특정 제품 exclusion 가능, 수개월~수년.
- **Consent decree**: 302 금지명령 소송 합의 → 법원 명령 — 시설 생산·유통 중단(의학적 필수 제품 조건부 예외), **독립 전문가** 인증 후 FDA 승인 재가동, 수년 감사·보고, **일당·배치당 liquidated damages**, FDA 비용 상환, 임원 개인 명시; 5년+ 흔함.
- **CR(시설 OAI) — CMO 교정 vs 교체**: 교정 = CMO CAPA → 재사찰 → 재제출(재사찰 필요 시 **Class 2, 6개월**; Class 1은 2개월), comparability 불필요·일정 통제 불가. 교체 = 새 제조소 데이터(검증·**Q5E**·안정성) → **major amendment(+3개월)** 또는 Class 2 + 새 PAI. 양쪽 200.10(b) 책임·quality agreement.

### 3.3 EU — 등급과 non-compliance 흐름
EU는 **결함별 등급**(CoCP: **critical / major / other**, 다수 major → critical 상승; DI 위조는 critical = 미국 OAI) + 결론 "준수/비준수". CAP 제조소에 critical → **EudraGMDP non-compliance**(111(7)), MIA 조치 사찰국(118) → CoCP 위험 평가, MAH·QP 영향 배치 회수/출하 중단 → **EMA·CHMP** B/R·공급 필수성 → **Reg 726/2004 Art 20**(MA 정지·제조소 삭제·회수; 20(4) 긴급 회원국 사용 정지) → 공급 필수 제품은 **supply-critical** 경로(추가 시험·QP 강화 조건부 제한 공급, MSSG) → 재사찰·CAPA 후 statement 철회·인증서 재발급.

## 4. 사찰 방식의 변화 (2024–26)
- **RRA**(최종 guidance **2025-06-26**): **Mandatory RRA** = 704(a)(4) 법정 기록 요구("사찰 전·대신") — 211 기록을 합리적 기한 내 제출, 거부·지연은 **501(j)**; **Voluntary RRA** = 동의 기반 원격 평가·livestream·인터뷰(거부 자체 제재 없음, 사찰 전환 가능). 결과는 사찰 분류·관찰 서면에 사용 가능, 해외 사이트도 대상. 준비: 기록 인벤토리·요청 로그·법무 검토·번역.
- **해외 불시 사찰 확대**(2025-05 발표, 인도·중국 pilot 후): 704은 원래 사전 통지 의무 없음(국내는 늘 불시) → 해외도 **상시 준비 상태**(즉시 열람·영어 SOP 요약·통역), 입장 절차(501(j)), RRA와 결합, 사찰 전 기록 '정리' 관행은 DI 위험.
- **EU-US MRA**(GMP Annex 2017 개정): 인체용 **2019-07-11** 전 회원국 인정 — EU NCA가 FDA 사찰 결과를 자체 사찰 대신 인정, **Art 51(1)(b) 배치 재시험 면제**; 여전히 EU 수입자 **MIA + QP 인증**(Annex 16) 필요; 백신·혈장 유래는 초기 범위 제외; 동물용 **2023-05-31**.
- **QMM**: 자발 프로토타입(3년차 모집 FR 2026-02-11) — 규정 아님.

- **Annex 16 §3**: **예상치 못한 편차**에 한해 QP 인증 고려 가능 — 모든 등록 규격 충족 + QRM 영향 평가(없음 결론) + 등록·조사·기록 + 필요시 추가 시험. **계획된 편차는 불가** → 변경 관리·variation. 미국 대응 211.192·211.100(b)(QP 조항 없음).
- **자체 감사**: 미국 211에 명문 요건 없음, **CPG 130.300**(1996) — FDA는 **내부 감사 보고서를 일상적으로 요구하지 않음**(수행 증거·일정·CAPA 종결은 요구 가능; 법원 명령·형사·동의 명령 예외). EU **Ch.9 Self Inspection** 명시 — 독립·정기·계획, 기록·CAPA·추적을 사찰관이 봄. Q10 CAPA·경영 검토에 넣어 양쪽 충족.

## 6. 외주해도 책임은 안 넘어간다
- **200.10(b)**: CMO에서의 CGMP 위반 책임은 **owner와 CMO 모두**("extension of the manufacturer's own facility"). **EU Ch.7**(2013): contract giver가 acceptor 적격성·GMP를 평가·보증, QP는 Annex 16 §1.7 공급망 신뢰 근거, MAH는 Art 46/Annex II.A. 집행: CMO WL이 **owner 제품명**과 공개, owner 신청 CR·Import Alert, 감사 기록 부재 = owner 결함.
- **Quality agreement**(FDA 2016-11 guidance + Ch.7): 역할·책임 분담표(211 Subpart별/contract giver·acceptor) · **변경 통지**(사전 승인 변경·규제 분류 연동) · 편차·OOS·불만·리콜 통보 시한 · **감사·사찰 접근권**, 당국 결과(483·WL·non-compliance) 통지 · 하도급 금지/승인 · 기록 보존·DI · 배치 기록·CoA, **QP 인증 근거** · 분쟁·종료·기술이전. 사업 계약과 분리, owner 최종 책임.

## 7. 글로벌 공통어

## 10. 흔한 혼동
1. **501(a)(2)(B) vs 501(j)** — 방법 미준수 vs 사찰 거부.
2. **483 = 위반 결정?** 관찰사항. 등급은 사이트 분류(OAI).
3. **EU에 OAI?** 결함별 critical/major/other.
4. **MRA면 QP 인증 생략?** 재시험 면제만.
5. **API 제조소도 GMP certificate 필수?** QP declaration 중심, 46b 확인서.
6. **Annex 11 최신판 적용?** 2011판.
7. **내부 감사 보고서를 FDA가 요구?** CPG 130.300 — 일상적으론 안 함.
8. **계획된 편차도 Annex 16 §3?** 예상치 못한 편차만.
9. **OOS 평균으로 합격?** 금지.
10. **CMO 위반은 CMO 책임?** owner 공동(200.10(b)).
11. **의약품 CGMP civil money penalty·mandatory recall?** 없음.
