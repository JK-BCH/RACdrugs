# Ch.26 — 신속 경로: 지정·승인 방식·심사 속도는 서로 독립이라 겹친다

> **덱:** Ch26_1(개념·구조) + Ch26_2(세부·상황형), 40장. 이틀 분량 한 장.
> **검증 메모(2026-11-22):** Fast Track·BTD·RMAT 요청 → **60 calendar days**; Fast Track은 pre-NDA 전, BTD는 **EOP2 전**; priority review NME filing+6개월 / non-NME receipt+6개월; **RPD PRV 2026-02-03 재승인 → 2029-09-30**(기준일 유효); EMA accelerated assessment Art 14(9) **150일(90+30+30, ATMP 120+30)**, 제출 2~3개월 전 요청, major public health interest + therapeutic innovation; conditional MA 1년 갱신; FDORA AA 개정; AA draft 2024-12·*Expedited Programs for RMT* draft 2025-09 — 둘 다 2026-09-01 기준 draft (2026-11-28 원문 확인) — 두 덱 메모 기준. 506(a)/(b)/(c)/(g)/(h), PRV 3종·90일 통지, 314.550/601.45, Animal Rule, Art 14(8)·83, BTD rescission은 ○.

## 학습 목표
1. 미국 **Fast Track / BTD / RMAT**(지정), **AA**(승인 방식), **priority review**(심사 속도)의 요건·혜택·**요청 시점**을 구분한다.
2. **AA의 사후 의무**(FDORA·판촉 사전 제출·506(c)(3))와 **RMAT 506(g)(7)** 확증 유연성을 안다.
3. **PRV 3종**과 RPD PRV의 2026 상태, **LPAD·Animal Rule**을 안다.
4. EU **accelerated assessment·conditional MA·exceptional circumstances·PRIME·Art 83**의 규칙을 쓰고 미국과 **짝지을 때의 불일치**를 말한다.
5. 기준일 기준 **무엇이 draft인지** 가른다.

## 1. 왜 세 결정이 따로인가
지정은 "개발 중 FDA 관여 수준", AA는 "어떤 종점으로 승인하나", priority는 "심사에 몇 달 쓰나" — **질문이 달라** 독립적으로 획득·누적된다(BTD 없이 AA 가능, AA 없이 priority 가능). 한 지정 상실이 다른 혜택을 자동으로 없애지 않고, 스폰서는 거절 위험을 분산한다. 전형적 조합: **BTD/RMAT + AA + priority**. 지정이 승인을 보장하지 않고 **505(d) 표준 증거 기준은 그대로**다.

## 2. 지정 — Fast Track, Breakthrough, RMAT
| | **Fast Track** 506(b) | **Breakthrough** 506(a) | **RMAT** 506(g) |
|---|---|---|---|
| 요건 | serious + **unmet need 대응 잠재력**(비임상·임상 데이터), 또는 QIDP | serious + **preliminary clinical evidence**가 기존 치료 대비 **substantial improvement**(임상적으로 중요한 종점) | regenerative medicine therapy(세포·조직공학·HCT/P·복합) + serious + **preliminary clinical evidence가 unmet need 대응 잠재력** |
| 혜택 | 잦은 소통, **rolling review**, priority 적격 검토 | Fast Track 전부 + **집중 가이던스**(Phase 1부터) + 조직적 commitment(senior 관여) | BTD 수준 + **AA 확증을 RWE·등록부·추가 임상으로**(506(g)(7)) |
| 응답 | 60일 | 60일 | 60일 |
| 시점 | **pre-NDA/BLA 전**(그 뒤엔 혜택 의미 없어 거절 가능) | **EOP2 전** | 보통 IND 단계 |

- **문턱 차이**: Fast Track은 "잠재력"(비임상만으로 가능), BTD는 "예비 임상 증거로 상당한 개선". **RMAT vs BTD**: RMAT는 기존 치료 대비 비교가 필요 없고 unmet need 잠재력만 — 문턱이 낮다. 재생의학 제품은 RMAT가 기본.
- **철회(rescission)**: BTD는 후속 데이터가 개선을 지지하지 않으면 FDA가 철회 — 지정이 "현 시점 증거 기반 잠정 판단"이라서. Fast Track도 요건 상실 시 철회 가능(드묾). 철회돼도 NDA는 505(d)로 평가되므로 승인 거절을 뜻하진 않는다.
- **Fast Track 요청 내용**: serious 근거, unmet need 분석, 잠재력 근거(데이터·기전), 적응증·개발 계획. IND에 제출.
- **Rolling review**: 완성 섹션(CMC·비임상)을 먼저 제출해 심사 시작. 한계 — **PDUFA 시계는 완전한 신청(마지막 섹션) 제출 때 시작**, FDA 사전 동의 필요, PDUFA 신청 수수료 **전액은 첫 부분 제출 때** 납부 (2026-11-28 검증).
- **"Fast Track이니 6개월 심사"는 틀리다** — 심사 기간은 **priority review**(filing 시 별도 판단) 문제.

Phase 2에서 validated 임상 종점 40% 개선(치명 질환): 즉시 **BTD**(EOP2 전), Phase 3에서 priority 적격 논의, 대리 종점이면 AA 합의, 재생의학이면 RMAT.

## 3. Accelerated Approval — 의무가 붙는 승인
- **506(c)**: 중증 질환 약을 **임상 이익을 reasonably likely to predict하는 surrogate endpoint** 또는 **intermediate clinical endpoint**(비가역 사망·이환보다 앞서 측정되는 임상 이익) 효과로 승인하되 **확증시험으로 임상 이익 검증**을 조건으로. **지정이 아니라 승인 방식** — EOP2에서 합의.
- **FDORA 2022 이후 의무**: ① 확증시험(506(c)(2)(A), PMR) — FDA는 **승인 전 또는 승인 시 진행 중(underway)** 요구·설계·기한 조건 명시 가능 ② **6개월마다 진행 보고** ③ 라벨에 AA 표기·확증 요건 ④ **판촉자료 사전 제출**(314.550/601.45: 승인 전 심사 기간엔 **전부**, 승인 후엔 배포 **30일 전** — 일반 2253 "배포 시"와 다름) ⑤ 확증 실패·불이행·새 안전성 → **506(c)(3) 신속 철회**(통지 → 회의 → 서면 소명 → 자문위 가능 → 결정, **청문 없이**). 2024-12 AA draft guidance는 기준일 draft다.
- 왜 사후 의무가 무거운가: 조기 승인은 **불확실성을 환자 접근과 교환**하는 것이라 확증 의무·보고·철회 권한으로 사후에 해소해야 B/R 논리가 닫힌다. 확증이 수년 지연되며 "임시"가 "영구"가 되는 비판(dangling AA) → FDORA.
- **확증 실패 + 하위군 추세**: 신속 철회 절차 시작 가능. 스폰서 논거는 **사전 정의된** 하위군·다른 확증 증거여야 하고 사후 추세는 약함 → 적응증 축소, 추가 확증시험, 자발 철수.
- **RMAT 506(g)(7)**: 확증을 **임상 증거·임상 연구·환자 등록부·RWE**(EHR 등)로, 치료받은 전체 환자 데이터(승인 전·후) 활용 가능. 설계는 사전 합의 — 전향적 등록부(사전 정의 종점·추적) + 임상시험 환자 장기 추적 + 외부 대조. 위험: 등록부의 결측·비교군 부재로 확증 실패 시 철회 노출 → 종점·성공 기준 사전 문서화.

## 4. Priority review와 PRV
- **Priority review**: 승인 시 중증 질환의 **안전성 또는 효과에 significant improvement**(또는 PRV·QIDP·특정 소아 보충). NME NDA·original BLA **filing + 6개월**(standard 10), non-NME **receipt + 6개월**. 지정 통지는 filing(Day 60).
- **PRV 3종**: **tropical disease**(524) · **rare pediatric disease**(529) · **material threat MCM**(565A). **양도 가능**(판매), 다른 제품 신청에 사용(**적응증 무관**), 사용 **90일 전 통지** + 수수료. **RPD PRV**: 2024-12-20 이후 sunset 중 → **2026-02-03 Consolidated Appropriations Act 2026으로 2029-09-30까지 재승인** → 2027-03 승인 제품도 RPD 요건(소아 희귀질환, 신청 전 지정)이면 수여.

## 5. LPAD, Animal Rule
- **LPAD**(506(h), 21st Century Cures): 제한된 환자 집단(심각 감염·대안 부족)용 **항균·항진균제**를 **작은 데이터셋**으로 승인; 라벨 Highlights·적응증에 **"Limited Population"**, 데이터 제한 명시, **판촉 사전 제출**. QIDP면 Fast Track 자동 적격·+5년.
- **Animal Rule**(21 CFR 314.600/601.90): 사람 효능 시험이 **윤리적·현실적으로 불가능**한 CBRN 대응 제품을 **잘 특성화된 동물 모델 효능**으로 승인, PMR로 현장 연구.

## 6. EU — accelerated assessment, conditional MA, exceptional, PRIME, Art 83
| 도구 | 규칙 |
|---|---|
| **Accelerated assessment**(Reg 726/2004 Art 14(9)) | 기준 **major public health interest**, 특히 **therapeutic innovation**. **150일**(210 대신) = **90+30+30**; **ATMP 120+30**(CAT 단계 추가). 요청은 MAA 제출 **2~3개월 전**(CHMP 사전 판단). **major objection이 나오면 standard 210일로 전환**(Day 120 LoQ 체계) → 질문 없이 끝날 dossier에만 유리 |
| **Conditional MA**(Reg 507/2006) | 4조건(Ch.17); **1년 유효**, 갱신 신청 **만료 6개월 전**, 갱신 시 SO 진척·B/R 재평가; SO 완료 → **표준 MA 전환**(5년 체계); 미이행 → 갱신 거부·조건 변경. SO 지연(CSR 2027-12 → 2028 중반)이면 갱신 신청에서 사유·새 일정 정당화 + **SO 기한 변경 variation** + 연 1회 진척 보고 |
| **Exceptional circumstances**(Art 14(8)) | 포괄 데이터를 **객관적으로 영원히 못 얻을 때**, 특정 의무(등록부·안전성 보고), **연 1회 재평가**, 전환 목표 없음. 미국 대응물 없음 — 505(d) + 외부 대조/FDAMA 115 정규 승인 또는 AA |
| **PRIME**(2016) | unmet need + major therapeutic advantage; proof of concept(SME·학계는 proof of principle). 거부돼도 새 데이터로 **재신청 가능**, accelerated assessment는 **별도 요청**이라 PRIME 거부가 AA를 막지 않음(PRIME 제품은 AA 적격 "가정") |
| **Compassionate use**(Art 83) | **회원국 국가 프로그램**, CHMP는 요청 시 조건·대상 **의견**(비구속). 결정은 회원국(미국 expanded access와 달리 중앙 승인 아님); 명명환자 공급은 Dir 2001/83 Art 5(1) |

## 7. 미국 ↔ EU 짝짓기와 불일치
| 미국 | EU | 불일치 |
|---|---|---|
| Fast Track / BTD | **PRIME** | PRIME 기준은 BTD의 "substantial improvement"에 가깝고, **Fast Track의 비임상만으로 가능한 문턱은 없음** |
| AA 506(c) | **Conditional MA** | AA = **대리 종점**이 핵심; CMA = **포괄 데이터 미완성**(대리 종점이 아니어도 가능) |
| Priority review | **Accelerated assessment** | 기준(significant improvement vs major public health interest)·일수(6개월 vs 150일) 다름 |
| RMAT | (없음) | EU는 ATMP 분류 + PRIME으로 대응 |

**법적 효력**: AA·CMA 둘 다 **완전한 법적 승인**(시판·급여 신청 가능). AA는 라벨 AA 표기·확증 문구·판촉 사전 제출·신속 철회 노출; CMA는 SmPC·EPAR에 conditional 표기, **Annex II.E에 SO**, 1년 갱신, 전환 시 표기 삭제.

## 8. 2026-09-01 기준 상태
- **유효**: Expedited Programs guidance(2014 final), RMAT guidance(2019 final), FDORA 506(c) 개정, **RPD PRV**(2026-02-03 재승인).
- **draft(2026-09-01 기준) (2026-11-28 원문 확인)**: AA guidance 2024-12, *Expedited Programs for Regenerative Medicine Therapies* 2025-09. "RPD PRV expired / AA guidance final / RMT guidance final"은 셋 다 틀리다.

## 10. 흔한 혼동
1. **Fast Track = 6개월 심사?** 아니다 — priority review가 별도.
2. **BTD를 EOP2 후에?** 늦다. Fast Track도 pre-NDA 후면 거절 가능.
3. **AA는 지정?** 승인 방식.
4. **RMAT = BTD?** RMAT는 "substantial improvement" 불요.
5. **AA 판촉은 2253으로 배포 시?** 사전 제출(30일 전).
6. **PRV는 같은 적응증에만?** 적응증 무관, 양도 가능.
7. **RPD PRV 만료?** 2026-02-03 재승인.
8. **AA(506(c)) = CMA?** 겹치지만 다름(대리 종점 vs 데이터 미완성).
9. **EMA AA 요청은 제출 때?** 2~3개월 전.
10. **CMA는 임시 승인?** 정규 MA와 같은 법적 효력.
11. **Art 83은 EU 중앙 승인?** 국가 프로그램, CHMP 의견만.

## 11. 네 분야에 올려놓기
**미국**: ① RMAT(IND 단계; EV가 regenerative medicine therapy 정의에 드는지 OTP와 사전 논의) ② orphan designation ③ AA + 확증 **등록부/RWE** 합의(506(g)(7)) ④ priority ⑤ 소아면 RPD PRV. **EU**: ① CAT 분류 ② PRIME(proof of concept; 학계/SME는 proof of principle) ③ SA/protocol assistance ④ MAA 2~3개월 전 accelerated assessment ⑤ 데이터 미완성이면 CMA + SO(장기추적 PASS) ⑥ Art 83. **합동 일정**(Phase 2 완료 2027 Q2, 제출 2028): 2027 Q2–Q3 BTD/RMAT + EOP2(AA 종점·확증 설계) + PRIME·SA → 2027 Q4 pre-BLA·rolling 합의 + EMA eligibility·rapporteur → 2028 Q1 EMA AA 요청 → 2028 Q2 BLA(priority) / MAA(150일, 필요시 CMA) → 승인 후 AA 6개월 보고·판촉 사전 제출 / CMA 연 갱신·SO.
