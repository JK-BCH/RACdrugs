# Ch.36 — 시장 접근(급여·가격): 세 번째 관문, 그리고 규제 결정이 접근 변수가 되는 지점

> **덱:** Ch36_1(개념·구조) + Ch36_2(세부·상황형), 40장. 이틀 분량 한 장(Phase 1 마지막).
> **검증 메모(2026-11-22):** EU **HTA Reg 2021/2282** 적용 **2025-01-12**(항암·ATMP JCA) → **2028-01** 희귀 → **2030-01** 전 CAP; 미국 **IRA 협상** 1차 10개 → **2026-01-01** 적용, 2차 15개 → **2027**, 3차 15개(**2026-01-27 선정, Part B 최초 포함**) → **2028-01-01**; **OBBBA 2025-07-04** orphan 제외 확대(복수 희귀 지정, 시계는 첫 비희귀 승인부터); **MFN EO 2025-05-12**(이후 개별 합의는 기준일 이후); **CMS CGT Access Model 2025-01**(겸상적혈구, 33개 주+DC+PR); 독일 **MFG 2024-07-04** → **비공개 급여가 2025-01-01**(+9% 할인) — 두 덱 메모 기준. Part A/B/D·MDRP 23.1%·340B·IRA 재설계·9/13년·75/65/40%, TFEU 168(7)·Dir 89/105 90/180·JCA −45/+30·AMNOG 6개월/7개월째/€30M·HAS SMR/ASMR·accès précoce 2021·NICE £20–30k·1.2/1.7·AIFA MEA, 일본 60–90일·1.25/0.75·2019 CEA, CDA-AMC 2024·pCPA·PMPRB·PBAC, WHO EML·MPP·TRIPS, Reg 141/2000 10년은 ○. EU pharma package 2026-09-28 채택 → **시험 비적용**. "?": HTA Reg 2028/2030 적용 **일자**, 2차 MFP 공표일.

## 학습 목표
1. **승인 → 급여 → 가격** 세 관문과 미국·EU·일본 결정자를 구분한다.
2. 미국 **Part A/B/D·MDRP·340B·IRA**(협상 자격·일정·상한·재설계·인플레이션 리베이트)와 **CGT Access Model·MFN**을 쓴다.
3. EU **168(7)·Transparency Dir·HTA Reg(JCA·JSC)·AMNOG·HAS/CEPS·NICE·AIFA**와 비공개 가격·ERP를 설명한다.
4. **일본·캐나다·호주·WHO 도구**와 공통 어휘(QALY·ICER·MEA·gross-to-net)를 쓴다.
5. **규제 결정(비교약·종점·orphan·ATMP 분류·확증 연구)이 접근 변수**가 되는 지점과 승인 전 payer 통신의 경계를 안다.

### 2.3 가격 거버넌스 체크리스트
WAC 자유 + **주 투명성법**(출시가·인상 신고) · gross-to-net(PBM·340B·Medicaid·VA/FSS)이 **best price**에 미치는 영향, 성과 계약은 VBP 복수 best price · 인상은 **CPI-U 이내** · 9/13년 협상 시계·orphan 전략 · 340B 비중 · Part D catastrophic **20%** 할인 · MFN 압력 · ASP/AMP 보고 정확성(허위 FCA) · copay(AKS, Part D 제외) · 가격위원회 기록·법무 서명(III-6).

### 2.4 승인 전 payer 통신과 CGT 지불
- **2018 Payor Communications guidance**: **PIE** — 미승인 제품 정보를 **payor·제제위원회**에 **사실적·비오도 + "FDA 미승인" 공개**(설계·결과·예상 시점·가격·BIM), HCP·환자 대상 아님, 판촉 어조 금지 → 312.7 위반 아님. **HCEI**(FDAMA 114)는 승인 후 승인 적응증 관련 경제 정보("competent and reliable scientific evidence"). AMNOG 결과 보도자료는 기업·투자자 정보로 가능하되 Art 88·87(2)·FSA 준수.
- **CMS CGT Access Model**(2025-01): CMS가 **주 Medicaid 대신** 제조사와 **outcomes-based agreement** 협상(겸상적혈구 유전자치료 Casgevy·Lyfgenia, **33개 주+DC+PR**) → 1회 치료제 OBA 전례. 민간은 outcomes guarantee·분할·재보험·구독형, portable 계약; MDRP는 VBP 복수 best price.

## 3. EU — 가격·급여는 회원국, 임상 평가만 공동
### 3.1 법 틀
- **TFEU Art 168(7)**: 보건 서비스·자원 배분은 회원국 권한 → EU는 가격·급여를 **조화하지 않음**.
- **Transparency Directive 89/105/EEC**: 가격 결정 **90일**(예외 **+60**), 급여 등재 **90일**, 통합 **180일**; 객관적·검증 가능 기준·**사유 명시**·사법 구제; 정보 부족 시 시계 정지; 기한 경과 시 신청 가격 판매 가능(국가 이행 상이). 250일 무응답 → 위반: 서면 요구·국가 법원(직접 효력)·EC 민원; 단 Directive는 **절차**만, 가격 수준·급여 범위는 회원국.
- **HTA Regulation 2021/2282**(발효 2022-01-11, 적용 **2025-01-12**): **JCA = 상대적 임상 효과·안전성(PICO별)만**, 비용 효과·가격·급여는 국가; 회원국 **"due consideration"**(비구속, 같은 임상 증거 **국가 재평가 금지**); **JSC**(EMA 병행); **HTACG** 조정; 범위 항암·ATMP(2025) → 희귀(**2028-01**) → 전 CAP(**2030-01**) + 고위험 기기. EUnetHTA 21 2023-09 종료.

### 3.2 JCA 절차와 마찰
Scoping(회원국 PICO 수요 → 소그룹 통합) → **dossier: CHMP 의견 예정일 ~45일 전**(EMA 자료 + PICO별 분석·간접 비교) → assessor·co-assessor, HTD 사실 확인 → **보고서 채택: EC 결정 후 30일 내**, 공개 → 국가 단계(독일은 여전히 **국가 dossier**·zVT·6개월·협상 — JCA PICO ≠ zVT면 둘 다). 왜 가격은 아닌가: 168(7). 마찰: **PICO 폭발**(간접 비교 다수), 중복(AMNOG·HAS 국가 dossier), **MAA 일정 결합**(−45/+30), 비구속의 양면(무시 가능 / 부정 JCA 전 유럽 공개), 방법론 수용성 차이 → 완화는 **JSC**, EMA-HTA 병행 자문, 모듈형 dossier, G-BA §8.

### 3.3 독일 AMNOG (§35a SGB V, 2011)
출시 시 **자유 가격**(즉시 급여) + G-BA dossier → **IQWiG 3개월** → **G-BA 6개월** 추가 편익 등급(major / considerable / minor / non-quantifiable / none / less, vs **zVT**) → **GKV-SV 협상 6개월**(결렬 → 중재 3개월), 편익 없음이면 **zVT 연간 비용 이하**. **GKV-FinStG 2022**: 협상가 **7개월째부터**(기존 13), orphan 특례 매출 한도 **€30M**(기존 €50M; 추가 편익 자동 인정, 등급만 평가). **AbD**(GSAV 2019, 사용 동반 데이터 수집). **MFG 2024**(✔): **비공개 급여가** 2025-01-01~(독일 R&D 요건, **+9%** 할인, 2028-06-30까지 협상) → ERP 차단. **§8 AM-NutzenV 사전 상담**(Phase 3 전 zVT·종점·인구, 서면). **"추가 편익 미입증"**(비교약 ≠ zVT): 가격 zVT 이하·ERP 파급 → 구제 = 협상 하위집단 논증, **재평가**(새 증거·1년 후), 중재, 적응증 분할; 예방 = §8·JSC·라벨↔zVT 정렬·직접 비교/수용 가능 간접 비교·QoL·orphan 특례.

### 3.5 비공개 가격, ERP, 출시 순서
많은 국가가 **외국 가격 바스켓(ERP)** 참조 → **공식 가격 높게·실질은 비공개 할인**(PAS·리베이트·**MFG**). 효과: ERP 정보 가치 하락·저소득국 노출, 투명성 논쟁(WHA 2019), **MFN은 비공개 할인을 못 봄** → 효과 제한·공개 요구 압력; 비공개가 없으면 저가국 출시 지연. **출시 순서 예**: 미국(WAC) → 독일(기준점; 2025부터 비공개가 옵션) → 영국·북유럽(PAS) → 프랑스(ASMR I–III 정합) → 이탈리아·스페인(MEA) → 동유럽(지연·named-patient); 일본은 1.25/0.75 조정이라 주요국 확정 후. Transparency Dir 시계는 **신청 후**라 신청 시점 조절. **EU pharma package**(2026-09-28 채택)는 기준일 이후.

## 4. 일본·캐나다·호주·글로벌
- **일본 NHI**: 승인 후 **60~90일** 수재(연 4회, 中医協). 방식 **유사약 효능 비교**(I 신규성 → 비교약 1일 약가 + 가산 / II → 최저가) 또는 **원가 계산**(유사약 없음; 개시도 낮으면 가산 축소). **가산**: 획기성(70–120%)·유용성(5–60%)·시장성·소아·**선구(sakigake)**. **외국 평균 조정 1.25배 초과 인하 / 0.75배 미만 인상**. **비용 효과 평가(2019-04)**: H1–H3 지정 → 수재 **후** ICER → **가격 조정**(거부 아님). 개정 매년(2021~ 중간년), **시장 확대 재산정**, 효능 추가 재산정, 신약창출 가산. 재심사 8년(Ch.34).
- **캐나다**: Health Canada **NOC**(표준 300일·우선 180일, **pre-NOC CDA-AMC 제출** 허용) → **CDA-AMC**(2024, 구 CADTH; 퀘벡 **INESSS**) 급여 권고 → **pCPA** 공동 협상(LOI, 비공개) → 주 등재; **PMPRB** 특허약 상한(2022 가이드라인, 국제 참조·환수). **호주**: TGA ARTG → **PBAC**(연 3회, ~17주, 비용 효과) → PBS + 가격 협상·deed, **TGA-PBAC 병행**, LSDP(고가 희귀).
- **글로벌**: **WHO EML**(1977~, **2년 주기**) 국가 정책·조달 준거; Fair Pricing Forum(2017); 공동 조달 **Gavi·Global Fund·PAHO Revolving Fund·UNICEF**(WHO **PQ** 전제); tiered pricing(역수입·참조 차단 필요); **MPP** 자발 라이선스(2010); **TRIPS** 강제 실시(Doha 2001·31bis)·병행 수입·Bolar. "저자원 접근 = PQ + 조달 + 가격 도구".

## 5. 공통 도구와 철학
- **어휘**: **QALY**(생존 × 효용) · **ICER**(Δ비용/ΔQALY) · 임계값 · **budget impact** · list(WAC) vs **net** · **gross-to-net** · **ERP/IRP** · **AMCP Format** · global value dossier · CEA/CUA·BIM · HCEI · evLYG(ICER).
- **MEA 분류**: **재정 기반**(할인·리베이트, 가격-물량·지출 상한·payback, 무료 초기 용량·dose cap, 포트폴리오) / **성과 기반**(payment by result — AIFA 레지스트리 환급, outcomes guarantee — 미국 민간·CGT Access Model, 연금형·분할, **CED/managed access** — CDF·IMF·CMS CED·독일 AbD·네덜란드 조건부) / 혼합. 설계: 측정 가능 결과·시점, 데이터 원천, 지불 트리거, portability, 분쟁, **best price 영향**, 행정 비용; PASS/PMR과 **단일 프로토콜**.
- **왜 영국은 QALY, 독일은 등급, 미국 공공은 QALY 없음**: 영국 단일 세금 재원 NHS → 기회비용 명시(£20–30k·modifier, 평등주의, 거부가 명시적). 독일 2011 AMNOG는 QALY 거부(IQWiG 효율성 경계 논쟁) → 환자 관련 종점 **추가 편익 등급**으로 협상 근거, 사회보험 전통. 미국 다원 보험·선택 가치·차별 논란 → ACA PCORI QALY 금지, **IRA 협상 QALY 차별 금지**, CMS 다요소; QALY는 ICER(비정부)·민간 참고 → 같은 데이터로 영국 ICER·독일 종점 통계·미국 협상 서사/HCEI, PRO/QoL은 셋 다.
- **1회 치료제의 압력**: 가치 수십 년·비용 일시 → 예산 충격, 환자 이동, 내구성 불확실, 형평, best price·ERP·재산정 규칙 부적합. 도구: 미국 CGT Access Model·VBP 복수 best price·outcomes guarantee·분할·NTAP; 독일 AbD·성과 환급·연금형·€30M·MFG·NUB; 일본 CEA 조정·원가 계산·재산정·고액요양비; 영국 IMF·연금형. 공통 = **레지스트리 결과 측정 = PASS/PMR/CED**, portable 계약.

## 6. 규제-접근 접점
- **Phase 3 설계에서 잠글 것**: ① **payer 비교약**(독일 zVT·JCA PICO·NICE 표준치료) — **JSC + EMA 병행 자문**·FDA 회의 ② **종점**: 규제 1차 + **환자 관련 종점(사망·이환·EQ-5D·PRO)**, 대리면 장기 확증(PMR·PASS·CED) ③ 인구·하위집단 사전 계층화 ④ 장기 추적·레지스트리 전환 ⑤ 경제 입력(자원 사용·입원·투여 시간), 간접 비교 네트워크 ⑥ RWE 다중 활용(PASS/PMR/HTA/AbD/CDF) ⑦ 미국 HCEI·CED ⑧ 일본인 데이터·가산 근거 → **글로벌 가치 dossier**.
- **"규제 성공, 접근 실패"**: 원인 = 증거 기준 불일치(위약·대리·단일군 승인 vs 활성 비교·환자 관련·장기), 비교약 ≠ zVT/PICO/표준치료, 인구 불일치(광범위 라벨 vs 급여 하위집단), 가격-가치 격차·ERP, 타이밍. 선제 = JSC·EMA 병행·G-BA §8·NICE 자문으로 **승인·접근 동일 증거**, PRO·자원 사용, 대리 종점이면 **확증 설계를 PMR/PASS/CED/AbD에 동시 등록**, 적응증 문구 정합, 가속 승인은 **managed access(CDF·AbD·OBA)** 사전 설계, 승인 전 PIE.
- **가속 승인 항암제(단일군·반응률) 보장**: 반대 = 대리·비교 없음 → AMNOG 미입증(orphan이면 특례·non-quantifiable), NICE 불확실성, CMS CED(Aduhelm 2022). 계획 = **확증 시험 = 공용 자산**(506(c) PMR, FDORA 승인 전 착수·마일스톤 + CMA SO 통일, payer 비교약·OS·PRO) · 독일 §8 zVT·간접 비교(IPD·MAIC) 합의·AbD·€30M · 영국 CDF + PAS·modifier · 미국 CED/LCD·레지스트리·HCEI(외삽 한계)·PIE · 조건부·성과 연동 가격, 506(c)(3) 철회 위험 계약 반영.
- **Orphan 조합**(유병 2/10,000): Reg 141/2000 **시장 독점 10년**(소아 PIP +2; 5년 후 수익성 재검토 → 6년 단축 가능), 수수료 감면, protocol assistance · 독일 €30M 특례·비공개가 · 프랑스 ASMR I–III 가능성·accès précoce · 이탈리아 혁신성 지정 · HTA Reg 희귀 JCA **2028-01**(항암·ATMP 겸하면 2025) · 영국 HST/modifier · 미국 ODA 7년·IRA 제외(OBBBA, 비희귀 승인 피하기) → 적응증 문구 희귀 범위 유지, 매출 €30M 예측, 레지스트리.
- **승인 전 payer 통신 경계**: PIE(payor만, 사실적·비오도·미승인 공개·BIM 가능)는 312.7 밖; HCEI는 승인 후; AMNOG 결과 보도자료는 Art 88·87(2)·FSA 준수(G-BA 문구 정확 인용, 비교약 비하 금지); 가격·HTA 자료도 labeling 판단 가능 → 법무·규제 공동 승인(III-6), Reg FD·MAR 정합.
