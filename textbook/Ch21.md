# Ch.21 — 소아: 미국은 채찍(PREA)과 당근(BPCA)이 따로, EU는 한 법(1901/2006)에

> **덱:** Ch21 (20장).
> **검증 메모(2026-11-22):** PREA iPSP = EOP2 후 60일 내, NDA/BLA 전 합의; BPCA Written Request → 6개월 pediatric exclusivity; EU Reg 1901/2006 Art 16(성인 human PK 완료 시점까지 PIP/waiver), Art 36(SPC +6개월), Art 37(orphan 10→12년), Art 30(PUMA, 10년 보호); ICH E11A Step 4 2024-08-21, E11(R1) 2017 — Ch21 덱 메모 기준. PREA 트리거 5종, orphan 면제 + RACE Act 2020-08-18, deferral/waiver, 90/90/30 틀, 505B(a)(4) 연 1회 보고, 21 CFR 50 Subpart D, PDCO·compliance check·Art 7/8·Art 36(4), EMA 소아 제형 2013, S11 2020, pharma package(기준일 이후)는 ○.

## 학습 목표
1. **PREA** 트리거·면제·**RACE Act**·iPSP 시점·deferral/waiver를 적용한다.
2. **BPCA** Written Request → 6개월 독점의 구조와, 한 연구로 **PREA+BPCA**를 동시에 충족하는 논리를 안다.
3. EU **PIP** 시점(성인 PK 완료)·compliance check·보상(Art 36/37/30)과 **Art 36(4)** 배타를 안다.
4. **E11(R1)·E11A·S11**·소아 제형·**21 CFR 50 Subpart D**를 쓴다.
5. 글로벌 소아 일정이 **EU 시점에 지배**되는 이유를 말한다.

## 1. 미국 — PREA(505B): 의무
| 항목 | 내용 |
|---|---|
| 트리거 | NDA/BLA(또는 보충)에 **새 활성성분·적응증·제형·용법·투여 경로** |
| 면제 | **Orphan 지정 적응증** — 단 **RACE Act**(FDARA 2017 §504, **2020-08-18** 발효) 이후 **분자 표적이 소아 암과 관련된 항암제**는 orphan이라도 적용(FDA "relevant molecular targets" 목록) |
| iPSP | **EOP2 meeting 후 60일 내**(또는 합의한 시점) → FDA 응답 **90일** → sponsor **90일** → 합의 **30일** → **agreed iPSP**; **NDA/BLA 제출 전 합의 필수**(미합의 제출은 filing 쟁점) |
| **Deferral** | 소아 연구를 **나중에**(성인 승인 후) — 성인 데이터 먼저 준비, 소아 연구 시간 더 필요; 승인 시 PREA PMR 기한, **연 1회 상태 보고**(505B(a)(4)), 미이행 시 non-compliance 공개·misbranded 가능 |
| **Waiver**(전체·부분) | 소아 수가 적어 비현실적, 소아에 **무효·안전하지 않을 가능성**, 제형 개발 불가(부분), 성인 대비 의미 있는 이익 없음 |
| 제형 | **연령 적합 제형** 개발 요구(505B(a)(5)); 불가능하면 부분 waiver 근거 |

EOP2가 3월 1일이면 iPSP는 **4월 30일경**. 성인 orphan 암 kinase inhibitor인데 표적이 소아 육종과 관련되면 **PREA 적용** — iPSP에 소아 암 연구 계획(또는 waiver/deferral 근거)을 넣는다.

## 2. 미국 — BPCA(505A): 자발과 보상
FDA가 **Written Request**(연구 설계·기한 명시) 발행 → 스폰서가 **"fairly responds"** 하는 연구를 기한 내 제출(만료 9개월 전 권고) → FDA 수용 시 **6개월 pediatric exclusivity**를 그 활성 moiety의 **모든 기존 독점·특허에 추가**. **결과가 음성이어도** 부여. 자발적이지만 FDA가 요청 가능.

**한 연구로 둘 다**: PREA 의무 연구는 보상이 없지만, FDA가 같은(보통 더 넓은 — 추가 연령·적응증) 범위에 **WR을 발행**하면 PREA 의무를 이행하면서 **BPCA 6개월 독점**도 받는다. 스폰서는 PSP 협의 때 WR 발행을 요청해 의무를 보상으로 바꾼다.

## 3. 윤리 — 21 CFR 50 Subpart D
| 조항 | 범주 |
|---|---|
| **50.51** | 최소 위험 |
| **50.52** | 최소 위험 초과 + **직접 이익** 전망 |
| **50.53** | 최소 위험 **약간 초과**, 직접 이익 없음, 경험이 실제 의료 상황과 유사, **질환에 대한 일반화 가능한 지식** 산출 |
| **50.54** | 그 외 — FDA·전문가 패널 검토 |

임상 필요를 넘는 채혈이 있는 소아 PK 시험(직접 이익 없음) → **50.53**.

## 4. EU — Reg 1901/2006: 의무와 보상을 한 틀에
| 조항 | 내용 |
|---|---|
| **Art 7 / 8** | 신규 MAA(7) 및 특허 보호 제품의 변경 — 새 적응증·제형·경로(8)는 (a) 합의 PIP 결과 (b) 제품별 waiver (c) class waiver (d) 합의 PIP + deferral 중 하나 없이는 **신청 무효** |
| **Art 16** | PIP/waiver 신청은 정당한 예외 외 **성인 human PK 시험 완료 시점까지** → **PDCO** 의견 → EMA 결정 |
| **Art 23** | **Compliance check**(PIP 준수·완료 확인) — MAA **validation 전** |
| **Art 20** | Deferral(연 1회 PDCO 보고; 보상은 전체 완료 후) |
| **Art 36** | 합의 PIP 전 결과 포함(음성이어도, SmPC 반영) → **SPC 6개월 연장** |
| **Art 37** | orphan 제품은 대신 **시장독점 10→12년** |
| **Art 36(4)** | orphan이 Art 37을 받으면 **SPC 연장 불가**(택일; orphan 지위 포기 시 SPC 연장 선택 가능 — 특허 잔여 기간·독점 가치로 계산) |
| **Art 30 PUMA** | 특허·SPC 만료 제품의 **소아 전용 MA** → **8+2(=10)년** 데이터·시장 보호 |

**Pharma package**는 2025-12 정치 합의, **2026-09-28 Council 채택**으로 1901/2006을 대체할 예정이지만 **기준일(2026-09-01) 이후** → 시험은 **현행 Paediatric Regulation**(PIP·PDCO·Art 36/37) 기준. "PIP가 폐지됐다"는 말은 틀리다.

## 5. 세 제도 비교와 글로벌 일정
| | **PREA** | **BPCA** | **EU 1901/2006** |
|---|---|---|---|
| 성격 | 의무 | 자발(WR) | 의무 **+ 보상** |
| 보상 | 없음 | 6개월 독점 | SPC +6개월 / orphan 12년 / PUMA |
| 시점 | iPSP = **EOP2 후 60일** | WR 기한 | PIP = **성인 PK 완료 시** — 가장 이름 |

EU PIP는 **Phase 1 끝**에, 미국 iPSP는 **EOP2 후**라 **EU가 먼저**다 → 글로벌 소아 계획은 **PIP 일정에 맞춰** 세우고 미국은 그 내용을 iPSP로 재구성한다. EMA·FDA **Pediatric Cluster**가 불일치를 줄인다.

예: 성인 Phase 1 종료 2027 Q1, EOP2 2028 Q4 → **2027 Q1–Q2** PIP/waiver 신청(PDCO 60+60일 + clock-stop → 2027 하반기 결정) → **2028 Q4 EOP2 → 60일 내 iPSP**(PIP와 정합) → 2029 상반기 agreed iPSP → **MAA 전** compliance check, **NDA 전** agreed iPSP. deferral이면 양쪽 연 1회 보고.

## 6. 과학 — E11(R1), E11A, S11, 제형
- **E11(R1)**(2017) 연령 구분: **조산아 / 만삭 신생아 0–27일 / 영아·유아 28일–23개월 / 소아 2–11세 / 청소년 12–16/18세**(지역별). 발달 기준 참고이고 질환·약물에 따라 조정.
- **E11A**(Step 4 **2024-08-21**) extrapolation: **질환 유사성·약리 유사성·노출-반응 유사성** 근거로 **extrapolation concept → plan**. 청소년은 **PK 매칭 + 안전성**으로 성인 효능 외삽(독립 효능 시험 생략), 어린 연령은 불확실성에 따라 PK/PD 또는 축소 효능 시험. 모델링(popPK, 노출-반응) 중심, iPSP/PIP에 명시. 한계: 유사성 입증 필요(신생아·영아는 보통 불가), **안전성은 외삽이 어려워 소아 안전성 데이터는 여전히 필요**.
- **S11**(2020): 소아 비임상 — 성인·기존 독성 데이터로 충분한지 **weight-of-evidence**로 판단, 필요할 때만 **유약동물(juvenile animal) 시험**(연령·기관 발달 창 맞춤). 미·EU·일본 요구 조화.
- **제형**: EMA *Guideline on pharmaceutical development of medicines for paediatric use*(2013) — 연령 적합 제형(액제·분산정·미니정), **부형제 안전성**(방부제·감미료·에탄올 한도), 투여 기구, 맛; PIP에 제형 개발 포함. 미국 505B(a)(5) 연령 적합 제형.

## 8. 흔한 혼동
1. **Orphan이면 PREA 면제?** RACE Act 이후 분자 표적 항암제는 적용.
2. **iPSP는 NDA 때?** EOP2 후 60일, NDA 전 합의.
3. **BPCA 독점은 양성 결과만?** 음성이어도 부여.
4. **PIP는 Phase 3 때?** 성인 PK 완료 시(Phase 1 끝).
5. **Orphan이 SPC 연장 + 12년 둘 다?** 택일(Art 36(4)).
6. **PUMA = 특허 제품?** 특허·SPC 만료 제품.
7. **PIP 폐지?** pharma package는 기준일 이후.
8. **E11A로 안전성도 외삽?** 안전성 데이터는 여전히 필요.

## 9. 네 분야에 올려놓기
항암 세포치료는 RACE Act로 PREA가 걸리고, 신생아·BPD 대상 제품은 E11(R1) 신생아 범주·E11A 외삽 불가(신생아) → 직접 데이터가 필요하다. EU 동시 개발이면 **성인 PK 완료 시점에 PIP**부터 — 소아 전용 제품이면 PIP가 곧 개발 계획이다.
