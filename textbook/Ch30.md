# Ch.30 — 이전과 갱신: 미국엔 갱신이 없고(연간 의무), EU는 5년 뒤 한 번(그리고 sunset)

> **덱:** Ch30_1(개념·구조) + Ch30_2(세부·상황형), 40장. 이틀 분량 한 장.
> **검증 메모(2026-11-22):** 21 CFR **314.72** NDA 소유권 이전, BLA **601.12(f)(1)**; Dir 2001/83 **Art 24** 5년 → 1회 갱신 → 무기한(PV 근거 1회 추가 5년), **sunset** 24(4)–(6); **Reg 2141/96** centralised 이전 — 두 덱 메모 기준. 갱신 9개월 전, 2141/96 Commission 30일·EEA 설립, IAIN, 314.81 annual report 60일, 207 listing 6월·12월/등록 10–12월, PDUFA program fee, **506C 6개월**, 314.150/.161/.162, **Art 23a 2개월**, Art 123은 ○.

## 학습 목표
1. 미국 수명주기를 유지하는 **연간 의무**(annual report·listing·registration·fee)와 미이행 결과를 안다.
2. **314.72/601.12(f)(1)** 소유권 이전의 서류와 "이전 vs 개명"의 분기점을 적용한다.
3. **506C**(6개월), **314.150(a)/(b)/(c)·314.161/162**(철회·RLD 지위)를 쓴다.
4. EU **Art 24** 갱신(9개월 전·dossier·추가 5년), **sunset**(3년/3년·예외), **Reg 2141/96** 이전(EEA·30일), **Art 23a/123**을 쓴다.
5. 이전·인수 시 **승계 의무**(PMR/PMC·REMS·SO·PASS·PSUR)를 추적한다.

## 1. 세 축
① **누가 보유자인가**(이전·개명·합병) ② **승인이 살아 있나**(EU 갱신·sunset / 미국 연간 의무) ③ **공급을 멈추거나 철회하면**(506C·23a / 314.150·161 / Art 116·123).

## 2. 미국 — 갱신은 없다, 연간 의무가 대신한다
| 의무 | 시점 | 근거 |
|---|---|---|
| **Annual report** | 승인 기념일 **60일 내** — 변경 요약, **유통 데이터**, 현 라벨, CMC 변경(AR 카테고리), 비임상·임상 신규 데이터, **PMR/PMC 상태(506B)**, 제출 로그 | 314.81(b)(2) |
| **Drug listing 갱신** | 변경 시 + **매년 6월·12월** | 207.57 |
| **Establishment registration** | **매년 10/1–12/31** | 207.29 |
| **PDUFA program fee** | 승인 처방약 제품당 연 1회(NDA당 최대 5개) | PDUFA VII |
| Periodic safety | 314.80 | — |

왜 갱신이 없나: 미국은 승인을 **"철회될 때까지 유효한 허가"** 로 보고 안전성을 **지속 보고·사건 기반**(314.80/81, FAERS, 505(o) → SLC·REMS·철회)으로 통제. EU는 2004 개정 전 5년마다 갱신 → 1회 갱신 후 무기한으로 완화하며 PSUR·RMP로 보강. 미이행: annual report 미제출은 **314.150(b) 철회 사유** 가능; 등록 미갱신은 FD&C 510 위반 → **misbranding(502(o))**, 수입·유통 차단.

## 3. 미국 — 소유권 이전
| | 요구 |
|---|---|
| **구 소유자** | 모든 권리가 이전됐다는 **서신**(합병이면 합병 문서로 대체 가능) |
| **신 소유자** | ① 서명한 **Form 356h** ② 이전 **효력 발생일** 서신 ③ **승인 신청서(보충·기록 포함) 완전 사본 보유** 진술 — 없으면 **FDA 파일에서 사본 요청** 가능(314.72(a)(2)(iii)(b)) |
| 변경 | **314.70**로; 단 라벨의 상표·제조자·포장·유통자명 변경은 **annual report**(314.72(c)) |
| BLA | **601.12(f)(1)** 서면 통지(같은 내용 기대) → FDA가 license를 신 보유자 명의로 **재발급** |

- **승계되는 의무는 바뀌지 않는다**: PMR/PMC·REMS(505-1 수정으로 보유자 변경)·annual report 기념일·periodic 주기·기록 보존(314.81). 계약에 자료 인도·의무 승계 조항.
- **분기점 = 같은 법인인가**: X가 Y에 **흡수 합병**(X 소멸) → **314.72 이전**; Z의 **개명·본사 이전**(같은 법인) → 314.72 불요, 라벨 명칭·주소는 annual report(또는 CBE-0), **207 등록·listing 즉시 갱신**, 356h 연락처는 다음 제출 시. EU 대응: 이전 = Reg 2141/96, 개명 = Type IAIN.
- A → B 3/1 이전, B가 A 라벨로 3개월 출하: 314.72 서신 세트 + 제조자/유통자명 변경은 annual report 가능하지만 **유통 제품 라벨과 책임자 일치** 필요 → B의 registration·listing(NDC labeler code) 갱신, 기존 재고는 A 라벨로 소진(계획 명시).
- BLA 이전 + **제조소 변경** + **상표명 변경**: 601.12(f)(1) 통지 / 제조소 **PAS**(601.12(b)) + **Q5E comparability** / 새 상표명은 FDA **proprietary name 사전 심사**(OPDP/DMEPA) 후 라벨 변경, 제조자명은 annual report.

## 4. 미국 — 중단과 철회
- **506C**: **생명유지·생명구조·중증질환 예방/치료 약**(일부 API 포함)의 **단일/주요 제조자**는 **영구 중단** 또는 **공급에 중대한 영향 줄 일시 중단**(제조 문제·원료 중단)을 **최소 6개월 전**, 불가능하면 **인지 즉시** 통지(314.81(b)(3)(iii)). FDA는 shortage 목록·대체 공급원 가속·임시 수입·regulatory discretion·사찰 우선순위. 미통지는 비준수 서한 공개. 5개월 뒤 중단 예정이면 **즉시** 통지.
- **FDA 주도 철회(314.150(a)/(b))**: (a) 안전성 불충분·효능 증거 부족·허위 진술 → FR 통지 → **Part 12 청문 기회** → 결정; (b) 기록·보고 의무 불이행·라벨 위법·제조 부적합 등; 긴급 시 Commissioner 즉시 정지.
- **MAH 자발 철회(314.150(c))** → FDA가 **314.161**로 사유 판정: **상업적 사유**면 Orange Book **"Discontinued"**(314.162)로 옮기되 **RLD 유지**(ANDA 참조 가능); **안전·효능 사유**면 승인 철회 + 제네릭 철회·거부. 혁신사가 "철회"로 제네릭을 막지 못하게 하고 안전 문제는 시장 전체에서 제거하는 설계.

## 5. EU — 5년 뒤 한 번 갱신 (Art 24 / Reg 726/2004 Art 14)
- 초기 **5년** 유효(24(1)) → 갱신 신청 **만료 최소 9개월 전**(24(2)) → 갱신되면 **무기한**(24(3)) — 단 **PV 근거**(노출 환자 수 부족 등)가 정당화되면 당국이 **1회 추가 5년 갱신**을 결정 가능.
- **갱신 dossier**: 갱신 eAF, **품질**(승인 후 변경 목록·현 dossier 상태), **비임상·임상** 안전·효능 종합(참조 = **PSUR/PBRER**), **전문가 진술**(B/R 유지), 갱신 SmPC/PL, RMP 상태, PV 시스템 요약, 수수료. PSUR이 근거라 **EURD 주기와 갱신 시점을 맞추는** 게 효율적.
- CAP 승인 2023-06-15 → 만료 **2028-06-15** → 신청 **2027-09-15까지** → 결정 전 만료일이 와도 MA는 계속 유효. 국가 제품(독일) 만료 8개월 전인데 미신청이면 9개월 요건을 이미 넘김 → **지연 사유와 함께 즉시 BfArM 제출**(재량 수리; 미신청 상태로 만료되면 실효). 평가: centralised는 EMA(CHMP 의견), 국가는 NCA, MRP/DCP는 RMS 조율.

## 6. EU — Sunset clause (Art 24(4)–(6) / Reg 726/2004 Art 14(4)–(6))
| 조항 | 내용 |
|---|---|
| **(4)** | 승인 후 **3년 내 실제 시판 안 되면** 실효 |
| **(5)** | 시판됐던 제품이 **연속 3년** 어느 회원국에서도(CAP은 EU에서) 유통되지 않으면 실효 |
| **(6)** | 당국이 **공중보건상 예외**(정당 사유) 인정 가능 — **만료 전 신청** |

- 계산: 2024 한 회원국 출시 → 2025-03 판매 중단, 타국 미출시 → **2028-03** 실효. 증거는 **Art 23a 시판 개시·중단 통지**, 회원국별 도매 출하·판매 기록. 희귀질환 CAP, 급여 실패로 32개월 무판매 → 4개월 남음 → **Art 14(6) 예외 신청**(유일 치료, 급여 지연은 MAH 통제 밖) 또는 한 회원국에서라도 **실제 유통**(명명환자·소량) 입증.
- 왜 생겼나: 2004 개정이 갱신을 1회로 줄이자 **쓰지 않는 MA가 무기한 살아 있는 문제**(경쟁 차단용 "sleeping MA", 정보 노후화) → 승인만 받고 시판 안 하기·조용히 사라지기를 벌하고, 공중보건상 필요한 제품은 예외로 보호. "승인 = 공급 약속".

## 7. EU — MA 이전 (Reg (EC) 2141/96)
- CAP 이전은 **variation이 아니라 별도 절차**: 현 MAH가 EMA에 신청(신 MAH 정보, 효력일, **PV·QPPV·제조 책임 인수 증명**, 갱신 PI) → EMA 검토 → **Commission 결정 30일 내**. 조건: 신 MAH **EEA 내 설립**(Reg 726/2004 Art 2) — 보유자는 PV·품질·법적 책임의 EU 내 수신자여야 집행(사찰·제재·소송)이 가능하기 때문. **Brexit**로 영국 MAH·QPPV·PSMF·배치 출하가 2021-01-01부터 제3국이 되자 수백 CAP이 2141/96 이전 + QPPV·PSMF·배치 출하지 EEA 이전 variation(IAIN)을 일괄 수행.
- **이전 vs 개명**: 보유 법인이 **다른 법인**으로 → 2141/96(CAP) / 국가 절차(NAP); **같은 법인** 명칭·주소 → **Type IAIN**.
- **책임 전환**: 효력일 전 구 MAH, 효력일부터 신 MAH가 PSUR·SO·PASS·RMP 전부 승계(신청에 인수 진술) → 효력일을 **PSUR DLP·제출일과 겹치지 않게**, EudraVigilance·QPPV 등록을 효력일에 전환. CMA를 SO 진행 중·갱신 4개월 전에 이전하면: 이전 신청에 SO 인수 진술, 갱신은 **현 MAH 명의로 즉시**(지연 사유) 제출하고 결정 전 이전되면 EMA 통지, SO 진척·기한 variation은 갱신과 묶고, PSUR·RMP 책임 전환일 명시 — 갱신·이전 결정이 **같은 EC 결정 사이클**에 걸리지 않게.

## 8. EU — 중단과 철회
- **Art 23a**: MAH는 **실제 시판 개시**를 통지하고, **일시·영구 시판 중단**을 **최소 2개월 전**(예외 제외) 사유와 함께 통지 — 공급 부족 대응·sunset 계산 근거(CAP은 Reg 726/2004 Art 13(4)).
- **Art 123**: MAH가 **철회·정지 결정**을 하거나 당국이 MA 정지·철회·공급 금지 조치를 할 때의 **당국 간·EMA 통지**(사유 포함) — 23a는 공급, 123은 규제 조치.
- 안전성 사유 자발 철회(CAP): Art 123(2) 즉시 통지(사유) → EMA **공개 withdrawal 문서** → DHPC·recall 조율 → EC 결정 → 환자 안전 조치. 상업적 사유도 Art 123·공개는 같되 안전 조치는 없음.

## 11. 흔한 혼동
1. **미국 annual report = EU renewal?** 아니다.
2. **갱신 신청은 만료 전이면 OK?** 9개월 전.
3. **Sunset 3년은 승인일부터만?** (4) 승인 후 3년 미시판 / (5) 유통 중단 후 연속 3년.
4. **MAH 개명 = 이전?** 같은 법인이면 IAIN / annual report.
5. **이전은 variation?** EU CAP은 Reg 2141/96 별도 절차.
6. **506C는 모든 약?** 생명유지·중증, 단일/주요 제조자.
7. **자발 철회하면 제네릭 RLD도 사라진다?** 상업적 사유면 Discontinued로 RLD 유지.
8. **이전하면 PMR·SO도 사라진다?** 전부 승계.

## 12. 네 분야에 올려놓기
세포·EV 분야는 **MAH·제조소가 자주 바뀐다**(스타트업 → 라이선스). 스타트업이 승인 BLA·EU CMA를 대기업에 넘기고 제조도 이전하면 — 미국: 601.12(f)(1) 이전·license 재발급, 제조소 **PAS + Q5E**, 라벨 제조자명, registration·listing, **REMS 보유자 변경**, **PMR/PMC 승계(506B)**; EU: Reg 2141/96(EEA·QPPV·PSMF 인수), 제조소 **Type II**(+ DDC면 Art 117 재의견), **CMA SO 승계**, Annex II.A 제조자, GMP 인증. **인수 실사 체크리스트**: 미국 — 승인서·보충 이력, PMR/PMC·REMS 기한, annual report 기념일, periodic 주기, 특허·독점(Orange Book), 미해결 483/WL, listing·registration, 506C 노출; EU — Annex II 조건(SO·PASS·PAES), 갱신 상태·만료일, **sunset 노출(판매 기록)**, RMP·PSUR 주기(EURD), QPPV·PSMF, EudraGMDP, pending variations, 데이터 보호 잔여; 공통 — CCDS·라벨 비동기, 이전 비용·일정. **12개월 달력**(안전성 보고 제외): 미국 기념일+60일 annual report(PMR/PMC) · 6/12월 listing · 10–12월 registration · program fee · 314.70 · 506C 이벤트; EU 갱신 연도면 9개월 전 갱신 · PSUR(EURD) · variation·IA 연간 보고 · sunset 모니터링(유통 증빙) · 23a 통지 · RMP · EudraGMDP 유효성. EU sunset은 "승인 후 3년 안에 실제 시판"을 압박한다.
