# Ch.12 — Global registration of active substances

**달력:** 2026-12-09 (수) · Task: II-1, I-6

## 검증 메모 (2026-11-22)
- ✔ FDA DMF 유형: **Type II**(원료의약품·중간체·그 제조 원료, 또는 완제), **Type III**(포장재), **Type IV**(부형제·착색·향료), **Type V**(FDA 승인 참조정보); **Type I(제조소·시설) 폐지** — FDA DMF 페이지

## 핵심 요약
- 원료의약품 등록의 핵심 문제는 **"제조자의 영업비밀을 신청자에게 안 보여주면서 당국은 보게 하는 방법"** 이다. 세 지역이 각자 답을 만들었다: 미국 **DMF**(Type II; 승인 없음, 참조 시 심사), EU **ASMF**(Applicant's Part 공개 + Restricted Part 비공개) 그리고 EU **CEP**(EDQM이 Ph. Eur. 모노그래프 적합성을 인증해 3.2.S를 대체).
- DMF는 **승인되지 않는다**. ANDA/NDA가 참조할 때 그 신청의 일부로 심사되고, GDUFA 이후 Type II API DMF는 **Completeness Assessment**(60일 목표)를 통과해야 "참조 가능 목록"에 오른다. Type I(시설)은 없어졌다 — 시설 정보는 등록·사찰로 간다.
- CEP는 **5년 후 1회 갱신**하면 무기한이고, 2023-09부터 **CEP 2.0** 체계다. CEP가 있으면 ASMF를 안 내도 되지만, 완제 제조자는 여전히 **QP declaration**으로 API GMP를 책임진다.
- EU는 **Art 46b written confirmation**(2013-07-02~)으로 제3국 API 수입에 수출국 당국의 GMP 동등성 확인서를 요구한다 — 단 한국은 EU가 동등성을 인정한 Art 111b listed 국가라 **확인서가 면제**된다(목록 밖인 중국·인도 등은 확인서 필요).
- 글로벌 공통어는 **ICH Q7**(API GMP, starting material부터 적용)과 **Q11**(starting material 선정·공정 개발), 불순물 **Q3C(R9)·Q3D(R2)**, 그리고 **M4Q 3.2.S** 구조다. WHO는 **APIMF** 절차로 PQ 체계에 같은 개념을 넣었다.
- 네 분야 연결: MSC-EV 제품은 "원료의약품"이 세포 은행·EV 중간체라 DMF/ASMF 개념이 **공정 재료(배지·시약·용기)** 쪽에 적용된다 — Type IV/III DMF 참조와 공급자 변경 관리가 실무다.

## 플래시카드 20장

**1. [R][Domain II]**
*Front:* List the current FDA Drug Master File types and state what happened to Type I.
*Back:* **Type II** 원료의약품·중간체·제조 원료(또는 완제), **Type III** 포장재, **Type IV** 부형제·착색제·향료, **Type V** FDA가 승인한 참조정보. **Type I**(제조소·시설·절차·인력)은 **폐지**됐어 — 시설 정보는 등록·사찰로. (FDA DMF, 21 CFR 314.420)

**2. [R][Domain II]**
*Front:* Is a DMF "approved" by FDA? When is it reviewed?
*Back:* **승인되지 않아**. DMF는 참조하는 **신청(NDA/ANDA/IND)의 심사와 함께** 검토되고, 결론은 그 신청에 대해 내려져. 보유자는 **LOA(letter of authorization)** 로 신청자에게 참조 권한을 주고, 신청자는 LOA 사본을 신청서에 넣어. (21 CFR 314.420)

**3. [A][Domain II]**
*Front:* An API supplier's Type II DMF has not yet passed the GDUFA Completeness Assessment. An ANDA referencing it is submitted. What happens?
*Back:* GDUFA 하에서 Type II API DMF는 **CA 통과 후 "Available for Reference" 목록**에 올라야 ANDA가 참조할 수 있어. 미통과면 ANDA가 **refuse-to-receive** 위험이 있어. CA는 FDA 목표 **60일**(90%)이고, DMF 수수료(1회) 납부가 선행돼. CA는 과학적 적정성 심사가 아니라 완결성 점검이야. (GDUFA, FDA CA guidance)

**4. [An][Domain IV]**
*Front:* Why does GDUFA charge a one-time DMF fee and run a completeness assessment, when DMFs are not approved?
*Back:* ANDA 심사 지연의 큰 원인이 **불완전한 DMF**였어. 수수료로 DMF 심사 자원을 확보하고, CA로 **참조 전에 기본 완결성을 걸러** ANDA 심사 사이클을 줄이려는 거야. "승인"을 만들지 않으면서도 품질 문턱을 세운 설계고, 참조 가능 목록이 제네릭 업계에 공급자 정보를 주는 부수 효과도 있어. (GDUFA, FDA DMF guidance)

**5. [R][Domain II]**
*Front:* Describe the structure of an EU Active Substance Master File (ASMF).
*Back:* **Applicant's Part(AP, Open Part)** — 신청자에게 공개되는 정보(규격, 분석법, 안정성 요약 등) + **Restricted Part(RP, Closed Part)** — 제조 공정 상세 등 영업비밀, 당국만 열람. ASMF 보유자가 **Letter of Access**를 신청자에게 주고, 당국에는 전체를 제출해. (CHMP/QWP/227/02 Rev 4)

**6. [R][Domain II]**
*Front:* What is a Certificate of Suitability (CEP) and what does it replace in the dossier?
*Back:* **EDQM**이 발급하는 인증서로, 해당 API(또는 TSE 위험 물질)가 **Ph. Eur. 모노그래프로 품질 관리가 적절히 됨**을 확인해. MAA에서 **3.2.S 상당 부분의 데이터를 대체**해(ASMF 불요). 완제 제조자는 여전히 QP declaration으로 API GMP를 확인해야 해. (EDQM Certification, EMA CEP Q&A)

**7. [A][Domain V]**
*Front:* Your API supplier's CEP was first issued in March 2022. What lifecycle events should your regulatory tracker hold?
*Back:* **5년 후 1회 갱신**(2027-03 전후, EDQM은 약 4.5년 시점 신청 권고) → 이후 **무기한**(dossier 최신 유지 조건). 갱신 때 **CEP 2.0** 요건으로 dossier 갱신·CEP 2.0 발급. 그 사이 공급자의 **CEP 개정(revision)** 이 나오면 MAA 변경(variation) 연동. (EDQM CEP 2.0 FAQ, PA/PH/CEP 04 2 8R)

**8. [A][Domain I]**
*Front:* A Korean API manufacturer wants to export to the EU for the first time. Which Directive 2001/83 requirement applies at import, and what document is needed?
*Back:* **Art 46b** — 2013-07-02부터 제3국 API는 **수출국 당국의 written confirmation**(제조소별·물질별)이 있어야 수입돼: EU 동등 GMP, 정기·엄격 사찰, 부적합 정보 신속 통보를 확인하는 문서야. 다만 EU가 동등성을 인정한 **Art 111b listed 국가는 면제**인데 **한국이 목록에 있어** — 그래서 한국 API는 확인서 없이 수입돼(목록 밖인 중국·인도는 확인서 필요). (Dir 2001/83 Art 46b, 111b; Implementing Decision 2012/715 통합본)

**9. [An][Domain I]**
*Front:* Compare DMF, ASMF, and CEP on (a) who assesses, (b) whether a conclusion stands alone, (c) renewal.
*Back:* **DMF**: FDA가 참조 신청과 함께 심사, **독립 결론 없음**(승인 아님), 갱신 없음(annual report). **ASMF**: 회원국/EMA가 MAA와 함께 평가, 독립 결론 없음(단 EU-ASMF worksharing으로 평가 공유), 갱신 없음. **CEP**: **EDQM이 독립적으로 평가·인증**, MAA 밖에서 유효, **5년 후 1회 갱신 후 무기한**. (21 CFR 314.420, CHMP/QWP/227/02, EDQM)

**10. [R][Domain I]**
*Front:* From which point in the synthesis does ICH Q7 GMP apply, and who decides it?
*Back:* **API starting material 도입 시점부터** 공정에 GMP가 적용되고 단계가 진행될수록 엄격해져(Q7 표 1). starting material 지정은 **신청자가 제안하고 당국이 평가**하며, Q11이 선정 원칙(합성 단계 수, 불순물 운명·제거, 구조적 특성)을 줘. (ICH Q7 §1.3, Q11 §5)

**11. [A][Domain III]**
*Front:* A process chemist proposes a commercially available compound two steps before the API as the starting material. What Q11 arguments must the dossier make?
*Back:* Q11은 "**상업적 입수 가능**"만으로 부족하다고 봐. 보여야 할 것: ① 충분한 **합성 단계 수**가 GMP 하에 있어 불순물이 **제거·통제**됨 ② 그 starting material의 **불순물 프로파일·규격**이 API 품질에 미치는 영향 ③ 구조적으로 **API의 의미 있는 조각**인지 ④ 공급자 변경 시 통제. 두 단계는 보통 **짧다고 판단**돼 당국 질문이 와. (ICH Q11 §5, Q11 Q&A)

**12. [R][Domain I]**
*Front:* What is the current ICH residual solvent guideline revision, and what did the latest change add?
*Back:* **Q3C(R9)** — Step 4 **2024-01-24**. 분석법에서 **용매 휘발성**을 고려하도록 한 minor revision이야. 용매 Class 1(피할 것)/2(PDE 제한)/3(저독성, 5,000 ppm 또는 50 mg/day) 체계는 유지. Q3C(R10) 유지보수가 진행 중. (ICH Q3C(R9))

**13. [A][Domain II]**
*Front:* An API dossier reports lead at 0.4 ppm in the drug substance. Which ICH guideline governs and where is compliance actually demonstrated?
*Back:* **Q3D(R2)** 원소불순물이야 — 납은 **Class 1**. 준수는 원료 농도가 아니라 **완제의 1일 노출이 PDE 이하**인지로 보여 — 위험평가(원료·부형제·장비·용기 기여)를 **3.2.P**에 쓰고, 필요시 통제. 원료 규격 한도는 그 위험평가의 결과로 정해. (ICH Q3D(R2))

**14. [A][Domain II]**
*Front:* The MAA uses a CEP for the API. The assessor still asks for a "QP declaration." Why, and who signs it?
*Back:* CEP는 **품질(Ph. Eur. 적합)** 을 인증하지 **GMP 준수를 보증하지 않아**. Dir 2001/83 Art 46(f)·Art 8(3)(ha)는 완제 제조자의 **QP가 API 제조소가 GMP를 지킨다고 선언**(감사 근거)하도록 요구해. 서명은 **완제 제조·수입 허가 보유자의 QP**야. (Dir 2001/83 Art 46(f), 8(3)(ha); EMA QP declaration template)

**15. [An][Domain I]**
*Front:* Explain why the EU created both ASMF and CEP routes, and when a supplier chooses one over the other.
*Back:* **ASMF**는 모노그래프가 없는 신규·특수 API에도 쓰는 **일반 비밀보호 경로**이고, **CEP**는 **Ph. Eur. 모노그래프가 있는 물질**에 대해 EDQM이 한 번 평가해 **모든 MAA에서 재사용**하는 효율 경로야. 모노그래프가 있고 다수 고객이면 CEP(평가 1회·갱신 간단), 신규 물질·모노그래프 없음·공정이 모노그래프 범위를 벗어나면 ASMF. (EDQM, CHMP/QWP/227/02)

**16. [A][Domain IV]**
*Front:* A US applicant wants to use an API with an EU CEP but no US DMF. What is the US path?
*Back:* FDA는 **CEP를 인정하지 않아**. 공급자가 **Type II DMF**를 제출하거나(GDUFA면 수수료·CA), 신청자가 **3.2.S 전체를 직접 제출**해야 해. CEP 평가 보고서는 참고가 될 뿐 규제 효력이 없어. 공급자 협상 시 DMF 제출 의무를 계약에 넣어. (21 CFR 314.420)

**17. [R][Domain I]**
*Front:* What is the WHO APIMF procedure?
*Back:* WHO **Prequalification**에서 API 제조자가 비공개 정보를 **APIMF**(Active Pharmaceutical Ingredient Master File)로 직접 WHO에 제출하고, 완제 PQ 신청이 이를 참조하는 절차야 — EU ASMF를 본뜬 구조이고, WHO API prequalification과 연결돼. (WHO PQ APIMF guidelines)

**18. [A][Domain III]**
*Front:* For your MSC-EV product, the CMC team asks whether "DMF" concepts apply. Where do they actually apply?
*Back:* 세포·EV 제품엔 전통적 API DMF 개념이 직접 맞지 않지만, **공정 재료**에 적용돼 — 배지·성장인자·시약의 **Type IV/II DMF**, 일회용 백·용기의 **Type III DMF**, 세포 은행 시험 CRO의 정보 등을 LOA로 참조해. EU는 공급자 ASMF·CEP(예: 동물 유래 물질 TSE CEP)로 대응하고, 공급자 변경은 comparability·variation 이슈가 돼. (21 CFR 314.420, EDQM TSE CEP)

**19. [A][Domain V]**
*Front:* A DMF holder changes a synthesis step. What must the holder and the referencing applicant each do?
*Back:* **보유자**: DMF 개정 제출, 영향받는 **모든 참조자에게 통지**(LOA 관계), 연 1회 annual report. **신청자**: 변경이 자기 제품에 미치는 영향을 평가해 **314.70 보고 카테고리**(PAS/CBE-30/AR)로 보충 — DMF 개정 자체가 신청자 의무를 대신하지 않아. (21 CFR 314.420(c), 314.70)

**20. [An][Domain IV]**
*Front:* A sponsor sourcing API from a single Chinese site asks what regulatory risks differ between US and EU supply. Analyse.
*Back:* **EU**: Art 46b written confirmation(중국 당국 발급), MAH의 **Art 46(f) 감사 책임**, EudraGMDP 비준수 성명 위험. **미국**: FDA 해외 사찰(사전승인·감시) + **Import Alert** 위험, DMF CA·수수료. 공통: 단일 공급원은 **공급 중단 보고**(미국 506C) 위험이 있어 이중 공급원 자격화·CEP/DMF 병행이 전략이야. (Dir 2001/83 Art 46b/46(f), FD&C 506C, FDA Import Alerts)
